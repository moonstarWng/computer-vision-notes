# 1 为什么有这些章节

> **M0 计算机视觉导论 · 第 1 篇**
>
> **一句话**：每一章都不是"知识点清单"，而是**上一个问题解决不了时，不得不引入的工具**。
> **读完**：你应该能对任意一章说出"它解决什么问题、不学会怎样"。

---

## 0. 一条主线

```
图像（S0）
  │  图像在计算机里是什么？
  ▼
数学与几何（M1）
  │  3D 世界怎么用数表示？带噪声的观测怎么求解？
  ▼
相机（M2）
  │  3D 点怎么变成像素？像素怎么反推 3D？
  ▼
点云（M3）
  │  相机没有深度、怕光，怎么直接拿 3D？
  ▼
识别（M4 / M5）
  │  场景里有什么？在哪？
  ▼
融合（M6）
  │  单个传感器都有短板，怎么合？
  ▼
位姿（M7）
  │  知道"有物体"不够，还要知道"怎么摆"
  ▼
落地（M8 / M9）
  │  实验室能跑 ≠ 产线能用
  ▼
系统（M10）
  │  每个模块都对，系统仍可能错
```

**注意**：这条线是"依赖顺序"，不是"必须按顺序学"。实际学习是**按项目倒推**（见 §13）。

## 1. S0 图像基础与工具链

- **它回答**：图像在计算机里到底是什么？（数组、通道、像素值、坐标系）
- **不学会怎样**：后面所有"特征点、滤波、预处理"都是黑箱；连一张图为什么会糊都说不清。
- **典型内容**：卷积、滤波、边缘、直方图、形态学、颜色空间。
- **一个小例子**：Canny 边缘检测 = 高斯平滑 + 求梯度 + 非极大值抑制 + 双阈值。

## 2. M1 数学与几何基础

- **它回答**：
  - 位置和朝向怎么用数表示？（旋转矩阵 / 四元数 / 旋转向量）
  - 带噪声的观测，怎么求出最可能的参数？（最小二乘、GN、LM）
  - 参数有多准？误差怎么传？（协方差、马氏距离）
- **不学会怎样**：看到 `R, t, J, Σ` 就卡住；所有标定/配准/位姿的代码都读不懂。
- **典型内容**：旋转表示、最小二乘、SVD、协方差。
- **一个小例子**：PnP 的残差是"重投影误差"，求解就是"用 LM 调 R,t 让残差最小"。

## 3. M2 相机模型与标定

- **它回答**：3D 点怎么变成像素？反过来，像素怎么推出 3D？相机自己的参数（内参、畸变）是多少？
- **不学会怎样**：
  - 不知道 `fx, fy, cx, cy` 是什么；
  - 像素换不成毫米，测不了尺寸；
  - 畸变没校，边缘测量系统性偏。
- **典型内容**：针孔模型、畸变、张正友标定、PnP、双目/结构光。
- **一个小例子**：标定 RMSE < 0.3 px，才敢拿它做 0.1 mm 级测量。

## 4. M3 激光雷达与点云处理

- **它回答**：相机没有深度、怕光照；点云直接给 3D，但它无序、稀疏、有噪声。怎么清洗、配准、分割？
- **不学会怎样**：拿到 `.pcd` 只会看，不会去噪、不会拼、不会找平面和物体。
- **典型内容**：滤波（体素/统计）、地面分割、聚类、ICP 配准。
- **一个小例子**：两视角扫描拼一起，靠 ICP + Kabsch。

## 5. M4 3D 检测与点云深度学习

- **它回答**：点云无序、稀疏、旋转不变，怎么让网络"看懂"并输出 3D 框？
- **不学会怎样**：只能用传统几何方法，遇到堆叠/遮挡就束手无策。
- **典型内容**：PointNet 系列、体素/柱状编码、3D 检测头、损失与评价（IoU/AP）。
- **一个小例子**：料箱里堆叠的工件，传统分割切不开，需要学习式检测。

## 6. M5 2D 检测与图像处理

- **它回答**：图像里有什么、在哪、什么形状？这是工业视觉里最常见的任务。
- **不学会怎样**：缺陷检测、字符识别、定位都做不了；也不会评估 mAP/漏检率。
- **典型内容**：YOLO 系列、分割、传统图像处理、评价指标。
- **一个小例子**：表面缺陷分割 + 面积阈值 → 判定 OK/NG。

## 7. M6 多模态融合

- **它回答**：相机怕光、雷达稀疏、IMU 漂移——单个都不够，怎么合成一个更可靠的结果？
- **不学会怎样**：只会"二选一"，不会按可靠性加权；时间同步、外参误差也处理不了。
- **典型内容**：前融合/特征融合/后融合、协方差加权、时间同步。
- **一个小例子**：相机 3D 框 + 雷达点云 → 用协方差决定信谁。

## 8. M7 6D 位姿估计

- **它回答**：知道"有个物体"还不够，机器人要知道它**怎么摆**（6 自由度）。
- **不学会怎样**：抓取时位置对、姿态错，夹爪直接撞上去；对称物体更是灾难。
- **典型内容**：对应点法、模板/渲染法、点云配准、评价（ADD/ADD-S）。
- **一个小例子**：料箱抓取，位置误差 2 mm、角度误差 5° 就可能抓空。

## 9. M8 工业视觉与机器人

- **它回答**：实验室算法怎么变成产线设备？手眼怎么标？节拍够不够？环境变了怎么办？
- **不学会怎样**：算法指标好看，现场天天停线；不会算节拍、不会做失败恢复。
- **典型内容**：手眼标定、抓取规划、焊缝跟踪、缺陷检测、现场调试。
- **一个小例子**：手眼标定没做好，视觉坐标转成机器人坐标后整体偏 5 mm。

## 10. M9 工程与部署

- **它回答**：模型能不能在目标硬件上、在时限内、长期稳定地跑？
- **不学会怎样**：实验室 30 FPS，产线 5 FPS；模型一升级就全线回归。
- **典型内容**：ONNX/TensorRT、量化/剪枝、延迟预算、内存、回归测试、监控。
- **一个小例子**：200 ms 节拍里，预处理 40 ms、推理 120 ms、后处理 40 ms，几乎没余量。

## 11. M10 系统设计

- **它回答**：每个模块单独都对，为什么整条线还是错？怎么分工、降级、验收？
- **不学会怎样**：出了问题只能"挨个模块试"，没有故障树、没有指标链。
- **典型内容**：系统架构、误差预算、降级策略、验收标准、故障排查。
- **一个小例子**：标定 0.3 px + 位姿 1 mm + 手眼 2 mm，合成后整体精度是多少？

## 13. 怎么用这条路线（不要死磕顺序）

| 你的目标 | 最少要学的 |
|---|---|
| 做 2D 尺寸测量 | S0 + M1（最小二乘）+ M2（标定） |
| 做 3D 抓取 | S0 + M1 + M2 + M3 + M7 + M8 |
| 做点云检测 | S0 + M1 + M3 + M4 |
| 做整线方案 | 全部，重点 M8/M9/M10 |
| 只做算法研究 | S0 + M1 + M2 + M5/M4 + M7 |

**每个模块的"够用线"**：能说清输入输出、能跑通一个最小例子、能解释残差/误差从哪来，就算过关。
