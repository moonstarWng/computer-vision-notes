## 1. 从"噪声假设"到"损失函数"

所有估计都可以写成最大似然：

```
观测：z_i = h_i(x) + ε_i
似然：L(x) = Π p(ε_i)
负对数：−log L = Σ [−log p(z_i − h_i(x))]
```

**所以"损失函数 ρ(r)"就是"−log p(r)"。** 你选什么分布，就得到什么损失。

| 噪声假设 | 分布 | 损失 ρ(r) | 等价做法 | 典型场景 |
|---|---|---|---|---|
| **高斯** | N(0,σ²) | `r²` | 平均、最小二乘 | 热噪声、读出噪声 |
| **拉普拉斯** | exp(−abs(r)/b) | `abs(r)` | **中位数** | 重尾、稀疏误差 |
| **重尾混合** | (1−ε)N + εH | Huber / Cauchy | 截尾平均 | 有离群点 |
| **泊松** | 计数 | 加权 `r²/μ` | 加权最小二乘 | 光子散粒 |
| **均匀** | 量化 | 近似 `r²` | 最小二乘 | A/D 量化 |
| **无假设** | — | 秩统计 | 中位数、RANSAC | 完全不知道 |

> 一句话：**平方 = 高斯，绝对值 = 拉普拉斯，Huber = 近高斯加重尾。**

## 2. 高斯：为什么它是默认

```
p(x) = 1/(√(2π)·σ) · exp( −(x−μ)² / (2σ²) )
```

只有两个参数：均值 μ、方差 σ²。

### 四个关键特性

| 特性 | 含义 | 工程意义 |
|---|---|---|
| **中心极限定理** | 大量独立小因素相加 → 高斯 | 电子热噪声天然是高斯 |
| **线性封闭** | 高斯 + 高斯 = 高斯；高斯 × 矩阵 = 高斯 | 误差传播 `Σ_y = JΣ_xJᵀ`、KF 有闭式解 |
| **最大熵** | 固定均值方差时最"不确定" | 不知道分布时，选它 = 最少假设 |
| **尾部极快衰减** | 6σ 外约 1e-9 | "大误差几乎不可能"——平方损失的前提 |

| 范围 | 落在外面的概率 |
|---|---|
| ±2σ | 4.6% |
| ±3σ | 0.27% |
| ±4σ | 0.0063% |
| ±6σ | 0.0000002% |

**记住**：高斯不是"真理"，是"**最少假设 + 数学最方便**"的折中。

## 3. 正交投影：平方损失的几何解释

```
         b
         │╲
         │ ╲   残差 r = b − p
         │  ╲
─────────●────╲──────► 子空间 S（A 的列空间）
         p
```

**定义**：把 b 投到子空间 S 上，使残差 `b − p` 垂直于 S。

### 五条性质

| 性质 | 写法 | 直觉 |
|---|---|---|
| 最近点 | `‖b−p‖ ≤ ‖b−s‖` | 影子是平面上离你最近的点 |
| 残差正交 | `Aᵀ(b−Ax)=0` | 正规方程的来源 |
| 幂等 | `P² = P` | 投两次等于投一次 |
| 对称 | `Pᵀ = P` | 这是"正交"投影（斜投影不对称） |
| 勾股 | `‖b‖² = ‖p‖² + ‖r‖²` | 能量可分解 |

### 和最小二乘的关系

```
min ‖Ax − b‖²
   ↓ 求导
Aᵀ(Ax − b) = 0
   ↓
Aᵀ r = 0            ← 残差垂直于 A 的每一列
```

**"最小化平方" ⇔ "残差正交于模型空间"**。

推论：模型里若有截距（A 有一列全 1），则 `Σ r_i = 0` —— **残差和为 0**。

> ⚠️ 这套几何**只在 L2 下成立**。L1 的"最近点"不是正交投影，也没有 `Aᵀr=0`。

## 4. 重尾：平方损失什么时候崩

```
p(r) = (1−ε)·N(0,σ²) + ε·H(r)
       └ 主体 ┘          └ 重尾 ┘
       ε 小（5%）         拉普拉斯/宽高斯/均匀
```

```
概率密度
  │      ╱╲                 ╱╲
  │     ╱  ╲               ╱  ╲
  │    ╱    ╲             ╱    ╲
  │   ╱      ╲           ╱      ╲
  └─┴─────────┴──────────┴────────┴──► 残差
     纯高斯（尾部干净）    重尾（两边翘起来）
```

**特征**：峰更尖、尾更厚（峰度 > 3）。

### 为什么平方失效

高斯下 6σ 概率 1e-9，你会觉得"不可能"；
重尾下 6σ 可能占 1%，而平方给它的惩罚是 1σ 的 **36 倍** → 少数坏点主导解。

### 为什么 Huber 能救

```
|r| ≤ δ  →  ρ = r²        （匹配高斯主体，保持效率）
|r| > δ  →  ρ = δ|r|      （匹配重尾，只线性惩罚）
```

**Huber 就是"近高斯 + 重尾"的最大似然近似。**

### 怎么诊断

- 残差直方图：尾部有没有"翘起来"；
- 峰度：> 3 说明重尾；
- **MAD**（中位数绝对偏差）估 σ，比标准差抗离群点：`σ ≈ 1.4826·median(|r|)`。

## 5. 噪声有哪些

### 5.1 按分布

| 噪声 | 来源 | 分布 | 影响 |
|---|---|---|---|
| 热噪声 / 读出 | 传感器电子 | 高斯 | ✅ 平方损失最优 |
| 散粒 | 光子计数 | 泊松（方差∝均值） | ⚠️ 异方差，要加权 |
| 量化 | A/D 转换 | 均匀（位深高近似高斯） | ✅ 基本无碍 |
| 椒盐 / 脉冲 | 死像素、传输 | 重尾 | ❌ 中值滤波 |
| 散斑 | 激光/超声相干 | 乘性（瑞利/伽马） | ❌ 非加性，专门处理 |
| 离群点 | 误匹配、遮挡、反光 | 重尾/混合 | ❌ 鲁棒核 / RANSAC |
| 系统偏差 | 畸变、标定、温漂 | 非随机 | ❌ 标定，不是优化 |

### 5.2 按性质（更重要）

| 类型 | 例子 | 能靠优化/平均消除吗 |
|---|---|---|
| **随机误差** | 热噪声、量化 | ✅ 可以 |
| **系统误差（bias）** | 畸变没校、标定错 | ❌ 平均消不掉，只能标定/建模 |
| **粗差（outlier）** | 反光、粉尘、误匹配 | ❌ 平均更糟，要鲁棒/RANSAC |

> **最容易犯的错**：把系统误差当随机噪声，测 100 次取平均 —— 结果还是很偏。

### 5.3 传感器清单

| 传感器 | 主要噪声 | 备注 |
|---|---|---|
| 工业相机 | 热噪声、读出、散粒、量化 | 短曝光时散粒更明显 |
| 结构光 | 反光、粉尘、散斑 | 相位解包裹易出错 |
| 线激光 | 反光、深色吸收、散斑 | 线中心提取偏差直接变深度误差 |
| 双目 | 匹配误差（重尾） | 远处视差小 → 误差 ∝ Z² |
| 激光雷达 | 雨雾、反光、多回波 | 会出现"飞点" |
| IMU | 零偏（系统）、随机游走 | 零偏要在线估计 |

## 6. 工业现场：反光、粉尘、油污

### 6.1 反光（镜面反射 / 过曝）

**现象**：局部过曝（像素饱和被截断）、激光线断裂、点云出现虚假点（ghost）。

**统计特性**：

| 特征 | 说明 |
|---|---|
| 分布 | **不是高斯**：稀疏大误差（重尾） |
| 相关性 | **空间成片**，违反 i.i.d. |
| 偏差 | 饱和会带来**系统性偏差** |

**对策**：鲁棒核（Huber/Cauchy）、RANSAC、强度/入射角滤波、多曝光融合、偏振片、显影剂/喷粉。

### 6.2 粉尘 / 油雾

**现象**：点云里出现悬浮孤立点；图像起雾（大气散射 `I = J·t + A(1−t)`）；结构光出现虚假回波。

**统计特性**：

| 特征 | 说明 |
|---|---|
| 分布 | **稀疏 + 近似均匀**（测量体积内随机），不是高斯 |
| 与真实点关系 | 通常离表面有距离 → 可被半径/统计滤波剔除 |
| 相关性 | 帧间较独立，但会持续出现 |

**对策**：统计离群点移除（SOR）、半径滤波、强度门限、多帧一致性、气帘/吹扫。

### 6.3 一张现场对照表

| 现象 | 更接近的模型 | 该用什么 |
|---|---|---|
| 热噪声 | 高斯 | 平方损失、多帧平均 |
| 散粒噪声 | 泊松 | 加权（方差∝信号） |
| 反光 | 重尾 + 相关 + 饱和偏差 | 鲁棒核 / RANSAC / 硬件 |
| 粉尘 | 稀疏离群 + 均匀 | 统计滤波 / 多帧一致性 |
| 油污 | 局部吸收 + 散射 | 强度门限 / 清洁 / 多角度 |
| 高温辐射 | 加性偏置 + 散粒 | 滤光片 / 标定补偿 |
| 振动 | 相关误差（低频） | 加固 / 短曝光 / 同步 |
| 标定误差 | 系统偏差 | 重新标定 |

## 7. 怎么选损失：决策树

```
残差分布你了解吗？
├── 不了解 ──────────────► 先用 L2，画残差直方图
└── 了解
    ├── 像高斯（尾部干净）
    │     └── 用 L2（若担心少量离群，用 Huber，几乎无损失）
    ├── 明显重尾（有离群点）
    │     ├── 离群 < 50% → Huber / Cauchy
    │     └── 离群 > 50% → RANSAC（M2/M3 再学）
    ├── 方差随信号变（泊松/散粒）
    │     └── 加权最小二乘（W = Σ⁻¹）
    └── 有系统偏差
          └── 优化救不了 → 先标定 / 建模 / 硬件
```

核心结论（跑出来会看到，真值 μ = 10）：

| 数据 | 均值 | 中位数 | Huber |
|---|---|---|---|
| 干净（高斯） | 10.081 | 10.073 | 10.073 |
| 10% 离群点 | **15.081** | **10.217** | **10.262** |

- 干净时三者都对；
- 有 10% 的坏点时，**均值被拉偏 5.08**，中位数只偏 0.22，Huber 偏 0.26。

**这就是"损失函数 = 噪声假设"的最直接证据。**

## 9. 自测

1. 为什么"平方损失"等价于"假设噪声是高斯的"？
2. 正交投影的哪条性质直接给出了正规方程？
3. 什么叫"重尾"？画残差直方图时怎么看出来？
4. 反光和粉尘分别更接近哪种分布？为什么不能用"多测平均"解决？
5. 系统误差和随机误差的处理方式有什么本质不同？

### 参考答案

1. 高斯密度取负对数后，`(x−μ)²/(2σ²)` 是唯一的非恒定项，最小化它 ⇔ 最小化平方和。
2. **残差正交于列空间**：`Aᵀ(b−Ax)=0`，展开就是 `AᵀAx=Aᵀb`。
3. 峰更尖、尾更厚（峰度>3）：小残差概率更高，但大残差出现得远比高斯频繁。
4. 反光 ≈ 重尾（稀疏大误差、成片相关）；粉尘 ≈ 稀疏均匀离群。它们的误差**不是零均值独立同分布**，平均不会抵消，反而可能被"摊"进结果。
5. 随机误差可以用平均/最小二乘压小；系统误差是**确定性偏差**，只能靠标定、建模或改硬件消除。
