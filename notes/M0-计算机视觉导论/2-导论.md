## 0. 先解开两个疑惑

**疑惑一：为什么笔记一上来就讲旋转矩阵、四元数、李代数？**

因为后面所有任务 —— 相机标定、点云配准、机械臂手眼、SLAM、6D 位姿 —— 最后都归结成同一句话：

```
已知一堆观测，求一个旋转 R 和一个平移 t
```

而"旋转"是整个链条里**唯一一个不能直接加减、不能直接求平均、还不能用 3 个数全局表示**的量。
所以不先把"旋转怎么表示"讲清楚，后面每个公式都会看不懂（尤其是 `R ← R·exp(δ^)`）。

**疑惑二：为什么第二章突然讲"迭代优化"？**

因为一旦残差里有除法（`u = fx·X/Z + cx`）、有 sin/cos（投影、旋转），**方程就没有闭式解**。
没有闭式解 = 不能一步算出来 = 只能"猜一个初值 → 算误差 → 改一点 → 再算"，循环到收敛。

**这就是"迭代"的全部含义。** 它不是某个算法，而是所有非线性问题的共同解法。

## 1. 所有任务都是同一个套路

```
   ┌────────┐    ┌──────────────┐    ┌───────────┐    ┌──────────┐
   │ 观测   │───►│ 模型 + 残差   │───►│ 优化/求解  │───►│ 参数     │
   │ 数据   │    │ r(x)=预测−观测│    │ GN/LM/SVD │    │ R,t,K,点 │
   └────────┘    └──────────────┘    └───────────┘    └──────────┘
```

| 任务 | 观测 | 残差 | 参数 |
|---|---|---|---|
| 相机标定 | 棋盘格角点像素 | 重投影误差 | 内参、畸变、外参 |
| PnP | 3D 点 + 对应像素 | 重投影误差 | R, t |
| 点云配准 | 两组点云 | 点到点/点到面距离 | R, t |
| Bundle Adjustment | 多视角图像 | 重投影误差 | 所有位姿 + 3D 点 |
| 手眼标定 | 机器人位姿 + 相机位姿 | AX=XB 残差 | 手眼变换 X |

**你会发现：换的只是"残差"和"参数"，求解器是同一个。**

### 1.1 三个词：观测、模型、残差

| 词 | 一句话 | 例子 |
|---|---|---|
| **观测** | 你**实际测到**的数据，带噪声，不能改 | 角点的像素坐标 `(721, 519)`；点云里的一个点 `(1.2, -0.3, 2.8)` |
| **模型** | 你**假设**"世界怎么产生这些观测"的公式 | 针孔相机：`u = fx·X/Z + cx` |
| **残差** | **模型预测**与**观测**的差 | `r = u_观测 − u_预测`（单位：像素） |

三者的关系：

```
参数 x ──模型──► 预测值 ──与观测比较──► 残差 r
                                            │
                                     优化器改 x，让 r 变小
```

**注意两个容易混的词**：

| | 误差 (error) | 残差 (residual) |
|---|---|---|
| 相对谁 | 相对**真值** | 相对**模型预测** |
| 你能算吗 | ❌ 真值未知 | ✅ 可以直接算 |
| 用途 | 评价（理论上） | 优化（实际上） |

> 优化只能最小化**残差**；残差小通常意味着误差小，但**前提是模型对**（模型错了，残差再小也没用）。

**一个能算的例子**：三个观测点 `(1, 2.1) (2, 3.9) (3, 6.2)`，模型 `y = a·x + b`。

```
残差：r_i = a·x_i + b − y_i
最小二乘解：a = 2.05, b = −0.033
三个残差：−0.083, +0.167, −0.083      ← 加起来≈0，平方和最小
```

### 1.2 任务清单（每个任务只换"残差"）

| 任务 | 输入（观测） | 输出（参数） | 残差 | 典型场景 |
|---|---|---|---|---|
| **相机标定** | 多张棋盘格图像 | 内参 + 畸变 + 每张外参 | 重投影误差 | 相机装好后标一次 |

| **Bundle Adjustment** | 多视角图像 + 匹配 | 所有位姿 + 3D 点 | 重投影误差 | SfM、航测、AR |

## 2. 三层全景图（重要）

### 第 1 层：一次求解任务

```
观测数据 ──► 定义残差 r(x) ──► 给初值 x₀ ──► 优化器 ──► 参数 x* + 残差
                                                ▲
                                          这一章（M1 第 2 篇）
```

### 第 2 层：优化器内部（迭代就发生在这里）

```
x ← x₀
while 没收敛:
    ① r = residual(x)          # 当前误差
    ② J = jacobian(x)          # 线性化
    ③ H = JᵀJ ;  g = Jᵀr       # 组装方程
    ④ δ = solve(H + λD, −g)    # 解线性方程
    ⑤ x ← x ⊕ δ                # 更新参数（旋转：R ← R·exp(δ^)）
    ⑥ if ‖δ‖ < ε: break        # 收敛判断
```

**"迭代"就是 ①~⑥ 一圈一圈地转。** 观测不变，只有参数在变。

### 第 3 层：在真实系统里的位置

```
传感器 → 预处理 → 前端（找对应/给初值） → 后端（优化） → 输出
                        ↑ RANSAC                ↑ M1 第 2 篇
```

## 4. 为什么"旋转"要单独讲一篇

三个反直觉的事实：

1. **3 个自由度，但没有任何 3 个数能全局无歧义地表示它**（拓扑决定的，3 个数铺不满一个封闭曲面）；
2. **它不能加**：`R + Δ` 立刻不再是旋转（正交性被破坏）；
3. **它不能直接求平均**：`(R₁+R₂)/2` 没有几何意义。

所以工程上必须用**多种表示 + 一套转换规则**：

```
R（结果）  q（存储）  ω/δ（优化）  欧拉角（显示）
```

这一篇讲的不是"多背几个定义"，而是**每种表示该在什么时候用**。

## 5. 为什么 M1 第 2 篇讲"迭代优化"

因为非线性问题没有闭式解。唯一的路是：

```
在当前点把曲线当直线（线性化） → 解一个线性问题 → 走一小步 → 重新线性化
```

三件事必须理解：

| 概念 | 一句话 | 为什么重要 |
|---|---|---|
| **雅可比 J** | 残差对所有参数的偏导 | 它决定"往哪走" |
| **`JᵀJ`** | Hessian 的近似 | 它决定"走多远" |
| **阻尼 λ（LM）** | 步长的刹车 | 它决定"会不会飞出去" |

## 6. 两个容易"凭空出现"的概念

### 6.1 李代数 —— 不是新表示，是"切空间"

```
李群 SO(3)  = 装 R 的弯曲流形
李代数 so(3) = 它在单位元处的切平面，装 ω 的平直空间
exp / log   = 两者之间的往返
```

**它为什么出现**：因为优化只能在平直空间里做加减和求导，所以要把旋转"临时搬"到切空间里。
详见 [`../M1-数学与几何基础/1-旋转.md`](../M1-数学与几何基础/1-旋转.md) §2.5。

### 6.2 RANSAC —— 不在 M1，属于"鲁棒估计"

| | 鲁棒核（M1 第 2 篇） | RANSAC |
|---|---|---|
| 做法 | 按残差加权 | 随机采样 + 数内点 |
| 初值 | 需要 | 不需要 |
| 容忍离群点 | < 50% | 可以 > 50% |
| 用在哪 | 精化 | 粗筛（M2 的 PnP、M3 的配准） |

**结论**：现在不用学它；等学到 M2 的 `solvePnPRansac` 再补。
它和M1 第 2 篇的鲁棒核是"近亲"，不是同一章的内容。

## 8. 术语表（读笔记时随手查）

### 几何与表示

| 中文 | 英文 | 一句话 |
|---|---|---|
| 位姿 | pose | 旋转 + 平移，共 6 自由度 |
| 内参 | intrinsic | 相机自己的 `fx, fy, cx, cy` 和畸变 |
| 外参 | extrinsic | 相机在世界中的 `R, t` |
| 刚体变换 | rigid transform | 只转不移形，属于 SE(3) |
| 齐次坐标 | homogeneous coordinates | 用 4 维表示 3 维点，把平移写成乘法 |
| 手性 | handedness | 左手系/右手系，看叉乘或 det |

### 优化

| 中文 | 英文 | 一句话 |
|---|---|---|
| 残差 | residual | 预测 − 观测 |
| 雅可比 | Jacobian | 残差对所有参数的偏导矩阵 |
| 最小二乘 | least squares | 最小化残差平方和 |
| 高斯牛顿 | Gauss-Newton (GN) | 用 `JᵀJ` 近似 Hessian 的牛顿法 |
| LM | Levenberg-Marquardt | 给 GN 加阻尼，防止步子太大 |
| 鲁棒核 | robust kernel | 降低大残差（离群点）的权重 |
| 离群点 | outlier | 错匹配、误检测 |
| 收敛 | convergence | 参数不再明显变化 |
| 闭式解 | closed-form solution | 能一步算出来，不用迭代 |

### 配准与概率

| 中文 | 英文 | 一句话 |
|---|---|---|
| 配准 | registration | 求两组点之间的刚体变换 |
| ICP | Iterative Closest Point | 交替"找最近点 + 求变换" |
| SVD | singular value decomposition | 奇异值分解，Kabsch 用它求 R |
| 协方差 | covariance | 误差的"形状" |
| 马氏距离 | Mahalanobis distance | 按不确定度归一化的距离 |
| 信息矩阵 | information matrix | 协方差的逆，权重 |
| 卡尔曼滤波 | Kalman filter (KF) | 预测 + 更新，递归的加权平均 |
| EKF | extended KF | 非线性版，用雅可比线性化 |

### 任务

| 中文 | 英文 | 一句话 |
|---|---|---|
| 重投影误差 | reprojection error | 3D 点投到图像后与观测像素的差 |
| PnP | Perspective-n-Point | 已知 3D 点和像素，求相机位姿 |

| RANSAC | RANdom SAmple Consensus | 随机采样 + 数内点，抗大量离群点 |

## 附录 A：十个任务的模型与残差

> §1.2 只给了"观测 / 残差"的速查；这里补上**模型**（每个任务真正的核心）和参数。

### A.0 通用模板

所有任务都能写成同一个形式：

```
观测：    z
模型：    z = h(x) + ε        （h 是几何/物理关系，ε 是噪声）
残差：    r = z − h(x)
优化：    min Σ ‖r‖²_Σ         （Σ 是噪声协方差，没有就先当单位阵）
```

**模型 h 决定这个任务长什么样；残差只是 h 的副产品**（把观测代进去减一下）。
下面每个任务按 **观测 / 模型 / 参数 / 残差 / 例子 / 坑** 六项写。

### A.1 相机标定

**观测**：n 张标定板图像里每个角点的像素 `(u,v)`，以及板子上角点的 3D 坐标（已知）。

**模型**（针孔 + 畸变）：

```
3D 点 → 相机系：   X_c = R·X_w + t
归一化：          x = X_c/Z,   y = Y_c/Z
畸变：            r² = x² + y²
                  x_d = x(1 + k1r² + k2r⁴ + k3r⁶) + 2p1xy + p2(r²+2x²)
                  y_d = y(1 + k1r² + k2r⁴ + k3r⁶) + p1(r²+2y²) + 2p2xy
像素：            u = fx·x_d + cx,    v = fy·y_d + cy
```

**参数**：`fx, fy, cx, cy, k1, k2, p1, p2 (, k3)` + 每张图的外参 `R_i, t_i`。

**残差**：`r = [u_obs − u_pred, v_obs − v_pred]`，单位像素。

**例子**：9×6 棋盘、方格 10 mm、20 张图 → 约 2160 个残差分量；目标 RMSE < 0.3 px。

**坑**：标定板要"张得开"（多角度、覆盖四角），否则参数相关；畸变项选少/选多都不好。

### A.2 PnP

**观测**：若干 3D 点 `X_w` 及其像素 `(u,v)`；内参已知。

**模型**：和标定**完全一样**的投影模型，只是把内参当常数：

```
(u,v) = π(K, R, t, X_w)      ← 未知的只有 R, t
```

**参数**：`R, t`（6 自由度）。

**残差**：重投影误差（同标定）。

**流程**：P3P/EPnP 闭式解 → RANSAC → LM 精化。

**例子**：`fx=800, cx=640`，`P=(0.1,0.2,1.0)`，若 `R=I,t=0`，预测 `u=720,v=520`；观测 `(721,519)` → 残差 `(1,−1)` px。

**坑**：点共面/共线退化；误匹配必须 RANSAC；点太少解不唯一。

### A.3 点云配准 / ICP

**观测**：两片点云 `P={p_i}`、`Q={q_j}`，以及对应关系（ICP 里由最近邻给出）。

**模型**：

```
刚体变换：  q ≈ R·p + t
对应关系：  q_{c(i)} 是 p_i 在 Q 里的对应点
```

**参数**：`R, t`。

**残差**：

```
点到点：  r_i = R·p_i + t − q_{c(i)}             （3 维向量）
点到面：  r_i = n_{c(i)}ᵀ (R·p_i + t − q_{c(i)})  （标量，通常更准）
```

**流程**：找最近点 → Kabsch/最小二乘求 `R,t` → 变换 → 重复。

**例子**：两视角扫描拼接、扫描件与 CAD 比对。

**坑**：初值差陷局部最优；对称件多解；重叠率低导致对应错。

### A.4 Bundle Adjustment

**观测**：多视角图像、特征匹配（哪个像素与哪个像素是同一个 3D 点）。

**模型**：

```
第 i 个相机看第 j 个点：
    u_ij = π(K_i, R_i, t_i, X_j)
```

**参数**：所有相机的 `R_i, t_i` + 所有 3D 点 `X_j`。

**残差**：`r_ij = u_obs,ij − π(...)`。

**例子**：SfM、航测、AR；几万参数、几十万残差。

**坑**：必须利用稀疏性；误匹配要鲁棒核；单目尺度不可观。

### A.5 手眼标定

**观测**：机器人末端位姿 `A_i`（base←ee）+ 相机看固定标定板的位姿 `B_i`（cam←target），多组。

**模型**：

```
标定板在机器人基座里不动：
    A_i · X · B_i = 常数
两次相减：
    (A_j⁻¹ A_i) · X = X · (B_j B_i⁻¹)
记 A_ij = A_j⁻¹A_i, B_ij = B_j B_i⁻¹：
    A_ij · X = X · B_ij        ← 这就是 AX = XB
```

**参数**：`X`（相机↔末端的 6 自由度）。

**残差**：`‖A_ij X − X B_ij‖`（旋转用角度、平移用米，分开加权）。

**例子**：机械臂抓取前必做，通常 10~20 组姿态。

**坑**：只做纯平移 → 旋转不可观；姿态差太小 → 噪声放大。

### A.6 6D 位姿估计

**观测**：RGB / RGB-D / 点云 + 物体 CAD 模型。

**模型**（两种常见写法）：

```
(a) 对应点：  q_k ≈ R·p_k + t            （p_k 模型点，q_k 场景点）
(b) 渲染比对：u = π(K, R, t, X_model)     （把模型投到图像上比）
```

**参数**：`R, t`。

**残差**：点对点 `‖R p_k + t − q_k‖`，或重投影 `u_obs − π(...)`。
评价指标：`ADD = mean‖(R p + t) − (R_gt p + t_gt)‖`。

**例子**：料箱抓取、装配对位；对称物体用 ADD-S。

**坑**：对称、反光、遮挡；评价指标和训练损失常不一致。

### A.7 SLAM

**观测**：连续帧的图像/点云（+ IMU）。

**模型**（两个方程）：

```
运动模型：x_k = f(x_{k−1}, u_k) + w_k      （u 是里程计/IMU）
观测模型：z_kj = h(x_k, L_j) + v_kj        （L 是地图点）
```

**参数**：所有位姿 `x_k` + 地图点 `L_j`（+ 回环约束）。

**残差**：

```
里程计：r = x_k − f(x_{k−1}, u_k)
观测：  r = z_kj − h(x_k, L_j)
回环：  r = T_ij − T_i⁻¹ T_j
```

**例子**：AGV、扫地机器人。

**坑**：累积漂移（靠回环）；纯旋转不可观；时间同步。

### A.8 多模态融合

**观测**：每个传感器各自的 `z_s`。

**模型**：每个传感器有自己的观测模型 `z_s = h_s(x) + ε_s`，噪声协方差 `Σ_s`。

**融合（后融合，信息形式）**：

```
Λ = Σ_s Λ_s,        Λ_s = Σ_s⁻¹
x̂ = Λ⁻¹ Σ_s Λ_s x_s
```

**参数**：统一状态 `x`。

**残差**：每个传感器的残差，按 `Σ_s⁻¹` 加权。

**例子**：相机 + 雷达 + IMU；工业上相机 + 激光轮廓仪。

**坑**：时间同步；外参误差；传感器间相关时不能当独立。

### A.9 结构光 / 线激光三角测量

**观测**：相机图像里激光线/条纹中心的位置 `(u,v)`。

**模型**（射线与激光平面求交）：

```
相机射线：X = λ · K⁻¹ [u, v, 1]ᵀ
激光平面：nᵀ X = d
交点：    λ = d / (nᵀ K⁻¹ [u,v,1]ᵀ)
          X = λ · K⁻¹ [u,v,1]ᵀ
```

**参数**：相机内参 + 激光平面 `(n, d)`（需标定）。

**残差**：提取到的线中心与"平面投影回图像"的偏差；或平面拟合残差。

**例子**：焊缝跟踪、切割定位；单帧一条剖面，随运动扫描成点云。

**坑**：反光/深色表面丢线；平面标定误差直接变深度误差；运动方向要正交。

### A.10 视觉测量（尺寸/位置）

**观测**：图像上的边缘/角点像素。

**模型**（工作平面假设）：

```
像素 → 归一化：x = (u−cx)/fx,  y = (v−cy)/fy
平面上的 3D 点：X = Z₀ · [x, y, 1]ᵀ        （Z₀ 是工作距离）
两点距离：d = ‖X₁ − X₂‖
```

**参数**：内参 + 工作距离 `Z₀`（或单应矩阵）。

**残差**：测量值与标准件/理论值的差（这是验收偏差，不是优化残差）。

**误差**：`σ_d ≈ σ_px · Z₀ / f` —— 距离翻倍，误差翻倍。

**例子**：零件尺寸全检、装配间隙。

**坑**：工作距离变了必须重标；畸变没校干净 → 边缘偏；被测物不在同一平面 → 比例尺错。
