## 笔记约定

- **结构**：任务 → 名词卡片 → 直觉 → 公式 → 代码 → 自测 → 面试题纲 → 坑清单（详见 [`STYLE.md`](STYLE.md)）
- **缩写**：首次出现必须写全称，例如 `SVD（Singular Value Decomposition，奇异值分解）`
- **代码**：Python 3 + numpy / scipy，独立可运行，正文里贴的是真实输出
- **自测**：每篇末尾有"未懂清单"，学完一项划掉一项
- **命名**：`模块编号-模块名/序号-主题.md`，序号保证顺序
