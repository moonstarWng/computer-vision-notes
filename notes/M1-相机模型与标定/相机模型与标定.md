# M1 相机模型与标定

> **目标**：看到一张图能说出它在哪个坐标系；给你一组标定板照片，能自己算出内参并解释每个残差的来源。
> **前置**：M0（最小二乘、李代数、误差传播）。
> **建议用时**：2 周 / 约 25 h。
> **学完能做什么**：独立完成一次相机内参标定 + 一次手眼标定，并给出可解释的误差报告。

## 核心概念（要能自己默写）

- 坐标系链条：世界 → 相机 → 归一化平面 → 像素；每个变换谁提供。
- 针孔模型与内参：fx = f/dx 的物理意义，主点为什么不在正中心。
- 畸变：径向（桶形/枕形）与切向，**先去畸变再乘内参**的顺序为什么不能反。
- 张正友标定：平面靶标 → 单应 H = K[r1 r2 t] → 旋转列正交等长 → 解 B = K⁻ᵀK⁻¹ → Cholesky。
- PnP：P3P 的多解、EPnP 的控制点表示、RANSAC + LM 的标准组合。
- 对极几何：E = [t]×R、F = K₂⁻ᵀEK₁⁻¹、自由度（5 / 7）、极线约束的用途。
- 双目：Z = fb/d，ΔZ ≈ Z²Δd/(fb)，误差随距离**平方**增长。
- 手眼标定：AX = XB 的推导，为什么纯平移退化。
- 相机-雷达外参四类方法：靶标 / 平面边缘 / 互信息 / 运动法。
- 时间同步与滚动快门：ms 级误差在 1 m/s 下就是 1 cm。
- 标定质量评价四件套：残差分布、独立数据验证、闭环一致性、物理合理性。
