# M9 系统设计

> **目标**：拿到一个模糊需求，能在 10 分钟内给出分层方案：任务拆解 → 传感器 → 模块 → 指标 → 兜底 → 验证。
> **前置**：M1–M8 至少各过一遍（开卷也行，但要能自己组织）。
> **建议用时**：1 周 / 约 10 h。
> **学完能做什么**：白板上画出一个感知系统的完整框图，并用数字说明"为什么这么选"。

## 核心概念（要能自己默写）

- 万能回答框架：**任务拆解 → 传感器选型 → 模块链路 → 鲁棒性 → 指标 → 验证方式**。
- 传感器选型的话术：激光雷达（抗光照、测距准）/ RGB（语义纹理）/ IMU（运动补偿）；先问场景的难点在哪。
- 指标必须可量化：成功率、单次耗时 P95、误抓率、MTBF、跨场景一致性；样本少要给置信区间。
- 精度 vs 实时：分级（粗检 + 精定位）、ROI、异步流水线、按需降频、模型分级。
- 数据闭环：失败帧自动捕获是核心，否则永远在优化已知场景。
- 兜底分层：感知（低置信 → 多帧确认/换视角）→ 决策（超时重试/降级）→ 执行（急停）→ 人机（报警 + 接管）；**任何模块不能静默失败**。
- 技术选型表达：指标约束 → 候选对比表（精度/速度/数据需求/部署难度/可解释性）→ 为什么当前方案够用 → 风险与回退。
