## 0. 开始之前：任务与名词

### 0.1 任务：传感器测出来的点，怎么变成机床坐标

场景：一台切管机的切割头上装了一支线激光传感器，跟着机床平移。它测出一个点时，给的是**自己坐标系**里的 `(X, 0, Z)`。机床要拿这个点去修正轨迹，就必须知道「传感器相对法兰装在哪」—— 这就是手眼矩阵 `X`（Hand-Eye）。

**痛点**：

- 用卡尺量安装尺寸只能到 mm 级；实际安装面还会有 0.1~1° 的倾斜，在 170 mm 的力臂上是 0.3~3 mm。
- 每台机器装配都不同，必须逐台标；换传感器、撞过机、拆过法兰之后都要重标。
- 标完凭什么说「对了」？没有残差、没有独立验证，就只能切一刀试试。

**本篇解决哪一步**：从「8 组对应点」到「4×4 手眼矩阵」这一步，以及它**为什么能解、为什么必须两个高度、误差从哪来、怎么验收**。

### 0.2 名词卡片

**手眼标定（hand-eye calibration）**
- 一句话：求「相机/传感器 ↔ 机器人末端」那个固定不变的位姿 `X`。
- 数学：`X ∈ SE(3)`，4×4 齐次矩阵，6 个自由度。
- 不是：不是相机内参，也不是工件坐标系的标定。
- 别名：相机-机器人标定、eye-in-hand 标定。

**线激光传感器（line laser scanner / 激光三角测量）**
- 一句话：投一条激光线到工件上，用相机看这条线的变形，反推一个**截面**的深度。
- 关键限制：一次只给一个截面 → 输出点永远落在一个平面里，**两个坐标是测的，第三个必须靠运动或假设**。
- 不是：不是面阵 3D 相机，不能一帧给一整片点云。

**切割圆方案（cut-circle hand-eye）**
- 一句话：用切割头在管材上真实切出 4 个圆孔，圆心在机床坐标里是**已知真值**，再让线激光去测这 4 个圆心在传感器坐标里的位置，两两配对解手眼。
- 为什么用它：真值来自「真出光」，不受喷嘴和光斑不同轴的影响；不依赖标定球、标定板这些容易丢的东西。
- 代价：必须能动刀切孔，而且孔位要「张得开」（见 §5）。

**对应点（correspondence）**
- 一句话：两组点里指同一个物理点的一对。
- 本章的对应点由**切割程序**保证（第 i 个孔就是第 i 个孔），不需要最近邻搜索。
- 不是：ICP 里的最近邻只是「临时猜的」对应。

**Kabsch 算法**
- 一句话：对应点已知时，用一次 SVD 解出 `R, t` 的闭式方法。
- 用在哪：本章的求解内核（M1 第 3 篇）。
- 局限：要求对应正确、无离群点、无缩放，且点分布不能退化。

**退化（degeneracy）**
- 一句话：数据提供的信息不足以唯一确定参数。
- 本章的典型：4 个圆心在传感器平面里**排成一条线**（含「只扫一个高度」这种必然情形）。

**残差（residual）与 RMS**
- 一句话：把解出来的矩阵套回原始数据，预测点与真值点差多少。
- 单位：mm；`RMS = sqrt(mean(‖r_i‖²))`。

### 0.3 本篇解决什么

1. 传感器只给 2 个坐标，凭什么解 6 个自由度？
2. 它和 M2 第 4 篇的 `AX = XB` 到底什么关系？为什么这里「纯平移不退化」？
3. 为什么现场流程是「4 个圆 × 2 个高度」？只扫一个高度会怎样？
4. 什么时候残差很小、解却是错的？怎么提前发现？
5. 一张 4×4 矩阵交出去之前，怎么给出可解释的误差报告？

## 1. 坐标系与数据链

四个坐标系，一条链：

```
基坐标 B ──A_i（机器人位姿，已知）──▶ 法兰/TCP E ──X（要标）──▶ 传感器 C
   │                                                                 │
   │ P_i（切割真值，已知）                            p_i（激光测量，已知）
   └────────────── 同一个圆孔：P_i = A_i · X · p_i ──────────────────┘
```

| 记号 | 含义 | 谁给的 | 单位 |
|---|---|---|---|
| `B` | 基坐标（机床坐标、WCS） | 机床 | mm |
| `E` | 法兰 / TCP | — | mm |
| `C` | 传感器坐标 | — | mm |
| `X = T_{E←C}` | **手眼矩阵，要求的未知量** | 标定得到 | — |
| `A_i = T_{B←E,i}` | 第 i 次扫描的机器人位姿 | 机床/编码器 | — |
| `P_i` | 第 i 个圆心的基坐标真值 | 切割程序 | mm |
| `p_i` | 同一圆心的传感器坐标 | 线激光 | mm |

于是：「标定手眼」= 找一个固定的 `X`，让所有 `A_i · X · p_i` 都落在 `P_i` 上。

**注意 `p_i` 的形状**：一次扫描只给一个截面，所以 `p_i` 的第二个坐标恒为 0：

```
p_i = (X_i, 0, Z_i)
```

这个「0」是整篇所有结论的根源。

## 2. 它不是 `AX = XB`

M2 第 4 篇的模型是：靶标在基坐标里的位姿 `T` **未知**，只能靠两次运动把它差分消掉：

```
A_i · X · B_i = T（常数）
⇒ (A_j⁻¹ A_i) · X = X · (B_j B_i⁻¹)        ← AX = XB
```

差分的代价是：旋转信息只能从**运动**里取。两次运动是纯平移时，`A_ij` 和 `B_ij` 的旋转部分都是单位阵，旋转方程变成恒等式 `R_X = R_X`，只剩平移方程对 `R_X` 的一个方向约束 —— 这就是「纯平移退化」。

切割圆方案把这一步反过来：**靶标的点真值是已知的**（孔是机床自己切的）。不需要差分，一次就把 `X` 写出来：

```
A_i · X · p_i = P_i
⇒ X · p_i = A_i⁻¹ · P_i  ≜  q_i          （把真值搬到 TCP 系）
⇒ q_i = R · p_i + t                       （标准 Kabsch，M1 第 3 篇）
```

| | 经典 `AX = XB` | 切割圆方案 |
|---|---|---|
| 靶标位姿 | 未知，靠差分消掉 | **点真值已知** |
| 观测 | 相机位姿 `B_i`（要 PnP） | 相机点 `p_i`（不需 PnP） |
| 求解 | Kronecker / 李代数 / 非线性 | Kabsch（SVD 闭式） |
| 状态多样性 | **必须绕不同轴转动** | 不需要（纯平移即可） |
| 退化条件 | 纯平移、姿态差太小 | 圆心在传感器平面里共线 |

**数字证据**（`demo_pure_translation_axxb`，同一组纯平移数据）：

```
两次扫描的姿态差：单位阵（纯平移）
纯平移（本项目）  : RMS=0.0000 mm  旋转误差=0.0000°  平移误差=0.0000 mm
AX=XB 残差：真值 X            = 9.50e-16 mm
AX=XB 残差：绕平移轴差 5°      = 8.42e-16 mm  <- 完全不敏感
AX=XB 残差：绕垂直轴差 5°      = 3.49 mm      <- 只有一个方向有约束
本项目（对应点已知）：同一个 5° 误差 -> RMS = 6.98 mm
```

一句话：**信息来自 8 个点的空间分布，不是来自机器人姿态差异。**

> 这条很重要，面试时容易讲反。切割圆方案能标，不是因为「机床动了」，而是因为「孔在哪、切在哪个坐标」这件事本身是已知的。

## 3. 现场怎么采这 8 组数据

| 步 | 谁做 | 做什么 |
|---|---|---|
| 1 | 机床 | 在管材上切 4 个圆孔（真出光），记录圆心 `P_1..P_4`（基坐标） |
| 2 | 上位机 → 视觉软件 | 下发 4 个圆心 + 步骤号（第 1 次 / 第 2 次） |
| 3 | 机床 | 移到 `Z2` 高度，逐个孔位停稳 |
| 4 | 每次到位 | 上位机把当前位姿 `A_i` 发给视觉软件 |
| 5 | 视觉软件 | 开扫 / 停扫；对每次扫描，从截面轮廓里找孔的两个边缘点 → 拟合出圆心 `p_i` |
| 6 | 机床 | 抬到 `Z1`（与 `Z2` 相差几十 mm），重复 3~5 |
| 7 | 视觉软件 | 8 组 `(p_i, P_i, A_i)` → 解 `X` → 回传结果与误差 |
| 8 | 视觉软件 | 存盘 `X`，立即替换运行时的坐标变换，下一帧检测就用新矩阵 |

**为什么两个高度的相机点会「重复」**：孔都在同一个平面上，传感器又在每个孔位被摆到「激光面正好过圆心」的位置。于是孔 1 和孔 3（同一个 x、不同 y）在传感器里给出的点几乎完全一样 —— 只有 x 和深度，y 测不到：

```
单高度时 4 个相机点：
  (  80.448,   -0.000, -169.791)
  ( -79.556,   -0.000, -170.209)
  (  80.448,    0.000, -169.791)     <- 与第 1 行重复
  ( -79.556,    0.000, -170.209)     <- 与第 2 行重复
```

这就直接引出下一节：4 个点只剩 2 个不同位置，是**一条线**。

## 4. 数学内核

### 4.1 第一步：真值搬到 TCP 系

```
q_i = A_i⁻¹ · [P_iᵀ, 1]ᵀ 的前三维
```

- `A_i` 是 4×4 齐次矩阵（含旋转和平移），单位 mm；
- 这一步必须用**完整位姿**，不能只减平移（孔在斜面上、或切割头带倾角时，减平移会引入系统误差）。

### 4.2 第二步：Kabsch（M1 第 3 篇）

要最小化的就是「预测 vs 真值」的平方和：

```
min  Σ ‖ R·p_i + t − q_i ‖²
```

闭式解：

```
p̄ = mean(p_i),   q̄ = mean(q_i)
p̃_i = p_i − p̄,   q̃_i = q_i − q̄
H = Σ p̃_i q̃_iᵀ                     （3×3）
H = U Σ Vᵀ                          （SVD）
R = V · diag(1, 1, det(VUᵀ)) · Uᵀ    （det 修正，防镜像）
t = q̄ − R p̄
X = [R t; 0 1]
```

符号说明：

- `p_i, q_i`：单位 mm；
- `H`：3×3，量纲 mm²；
- `Σ = diag(σ1, σ2, σ3)`：`σ1 ≥ σ2 ≥ σ3 ≥ 0`，用来判断退化（§5）；
- `R`：无量纲、`det(R)=+1`；
- `t`：单位 mm。

> **`H` 的定义和 `R` 的公式必须配套。** `H = Σ p̃ q̃ᵀ` 配 `R = V diag(1,1,d) Uᵀ`；如果写成 `H = Σ q̃ p̃ᵀ` 却还用同一个公式，解出来是 `Rᵀ`。它照样是正交矩阵、行列式也是 +1，**看起来完全正常**，但方向是反的。

数字（`demo_transpose`，无噪声）：

```
正确解 vs 真值：   旋转误差 0.0000°
转置解 vs R_trueᵀ：旋转误差 0.0000°      <- 确实是 Rᵀ
用正确 t 时：正确解 RMS=0.000 mm，转置解 RMS=1.696 mm
```

1.7 mm 的残差在 0.1 mm 的验收标准下能被抓住；但如果同时把 `t` 也解错，残差会被部分抵消，就看不出问题了。**所以工程上永远要独立检查「`R` 是否接近单位阵、`t` 是否接近安装尺寸」**。

### 4.3 第三步：残差

```
r_i = q_i − (R p_i + t)
RMS = sqrt( Σ‖r_i‖² / N )
```

`N = 8`。这个 RMS 就是回传给界面的「标定误差」，也是 0.1 mm 阈值的比较对象。

## 5. 可观测性：这一节是全篇的重点

### 5.1 `σ3` 恒等于 0，它不是退化信号

因为 `p_i` 的 y 恒为 0，去质心后 `p̃_i` 张成的只是传感器平面内的 **二维** 子空间：

```
rank(H) ≤ 2  ⇒  σ3 ≡ 0
```

实测：`σ(H) = [51204.96, 3199.72, 2.27e-16]`。

所以：

> **不能用「σ3 很小」当失败判据**，它会永远成立。
> 同理，「4 个点共面」在这套方案里是**物理必然**，不是异常。

### 5.2 真正决定能不能解的是 `σ2/σ1`

`H` 的秩等于「圆心在传感器平面里的张开程度」：

| 圆心在传感器平面里的分布 | rank | `σ2/σ1` | 现象 |
|---|---|---|---|
| 张开（面积 > 0） | 2 | ~0.06 | 唯一解 |
| 共线（含全部重合） | 1 | ≈ 0 | 绕这条线旋转不可观 |

实测两种情形（`demo_collinear`，无噪声）：

```
共线（4 圆 × 2 高度）: RMS=0.0000 mm  旋转误差=90.3999°  平移误差=0.0000 mm  σ2/σ1=0.0000
张开（4 圆 × 2 高度）: RMS=0.0000 mm  旋转误差=0.0000°   平移误差=0.0000 mm  σ2/σ1=0.0625
```

**残差 0、平移全对、旋转错 90°** —— 这就是 M1 第 3 篇说的「残差小 ≠ 解唯一」在产线上的样子。

### 5.3 为什么必须扫两个高度

平板/方管的 4 个孔都在**同一个平面**上。只扫一个高度时，每个孔的深度测量值几乎相同，4 个点退化成一条线（§3 的实测），`σ2/σ1 = 0`：

```
单高度（4 组）: RMS=0.0000 mm  旋转误差=90.1005°  平移误差=240.6275 mm  σ2/σ1=0.0000
双高度（8 组）: RMS=0.0000 mm  旋转误差=0.0000°   平移误差=0.0000 mm    σ2/σ1=0.0625
```

抬到第二个高度后，同一批孔的深度测量值整体平移（实测 `-169.791 → -209.791`），8 个点被撑成二维，`σ2/σ1` 从 0 变成 0.0625，解就唯一了。

> 结论：**双高度不是「多测几次更稳」，而是可观测性的必要条件**（对共面孔而言）。

### 5.4 让点「张开」的三种工装

只要能让 4 个圆心在传感器平面里张成二维，都行。三种经典摆法：

| 摆法 | 怎么让点张开 | 代价 |
|---|---|---|
| **双高度扫描**（本章） | 同一批孔，两次不同深度 | 多一次运动，节拍 +1 |
| 四面靶（不同面开孔） | 孔天然落在不同深度/不同朝向 | 需要管材转动，引入 B 轴误差 |
| 台阶靶（每个孔不同高度） | 一次扫描就拿下 4 个不同深度 | 需要加工台阶，工装复杂 |

### 5.5 工程上的退化清单

- 4 个孔排在同一条母线上（x 全相同）→ 共线，**两个高度也救不了**；
- 只扫一个高度（方管/平板）→ 必然共线；
- 孔位太挤（间距 < 20 mm）→ `σ2/σ1` 很小，角度误差被放大；
- 某个孔切歪/有挂渣 → 单点残差大，先看逐点残差再决定重标还是重切。

## 6. 误差预算

### 6.1 误差从哪来

| 源头 | 机制 | 典型量级 | 怎么压 |
|---|---|---|---|
| 圆心真值 `P_i` | 切割精度、机床 XZ 定位、孔圆度 | 0.02~0.1 mm | 标定前先验机床定位精度 |
| 传感器圆心 `p_i` | 边缘提取、光斑宽度、截面倾斜使圆变椭圆 | 0.02~0.1 mm | 激光面过圆心、尽量垂直管轴；拟合椭圆而非圆 |
| 位姿 `A_i` | TCP 标定、编码器、到位误差、时间同步 | 0.02~0.2 mm | **停稳再扫**（运动中扫要额外补滞后） |
| 模型 | 激光平面假设、内参、温度漂移 | 0.01~0.05 mm | 热稳定后标；固定工况复标 |

### 6.2 角度误差被力臂放大

一行公式把「角度」换算成「毫米」：

```
δ ≈ θ · r
θ = 1 arcmin = 2.9e-4 rad,  r ≈ 170 mm  ⇒  δ ≈ 0.05 mm
```

本章的 4 个孔分布半径约 `√(80² + 150²) ≈ 170 mm`，所以 0.05° 的旋转误差就是 0.15 mm —— 已经吃掉 0.1 mm 阈值。**手眼标定里角度比平移金贵。**

### 6.3 噪声线性传播（实测）

`demo_noise_sweep` 把传感器 2D 噪声从 0.005 mm 加到 0.2 mm：

```
噪声(mm) |    RMS(mm) | 旋转误差(°) | 平移误差(mm)
0.005    |    0.0038 |    0.0015   |    0.0046
0.010    |    0.0077 |    0.0030   |    0.0092
0.020    |    0.0153 |    0.0060   |    0.0185
0.050    |    0.0383 |    0.0150   |    0.0462
0.100    |    0.0767 |    0.0300   |    0.0924
0.200    |    0.1533 |    0.0600   |    0.1849
```

三点观察：

1. **线性**：噪声 ×40，三种误差都 ×40 —— 不像双目的 `ΔZ ∝ Z²`，Kabsch 是线性传播；
2. `RMS ≈ 0.77 σ`（本组数据），`平移误差 ≈ 0.92 σ`；
3. 噪声到 0.2 mm 时，平移误差 0.18 mm，已经超过 0.1 mm 阈值 —— 这就是「现场要停稳、要擦保护罩」的定量理由。

## 7. 验收：四件套

| 验收项 | 本章怎么做 | 判据 |
|---|---|---|
| **残差分布** | 看 8 个逐点残差，不只看均值 | 单点残差 > 3×RMS 就查那个孔 |
| **独立数据验证** | 另扫几个平面，比较「同姿态」与「绕轴异姿态」下的平面平行度/距离误差 | 误差 < 0.5 mm 且两种姿态一致 |
| **闭环一致性** | 连续重标 3 次 | 平移抖动 < 0.05 mm、旋转抖动 < 0.05° |
| **物理合理性** | `R` 与单位阵的夹角、`t` 与安装尺寸 | `R` 偏离 < 1°、`t` 与实测相差 < 2 mm |

第 4 条最容易被跳过，但它是**唯一能一眼抓出镜像解/轴符号错误**的检查。

### 8.3 代码骨架

```python
def kabsch(p, q):
    p_bar, q_bar = p.mean(0), q.mean(0)
    H = (p - p_bar).T @ (q - q_bar)          # 3×3 = Σ p̃ q̃ᵀ
    U, S, Vt = np.linalg.svd(H)
    V = Vt.T
    d = np.sign(np.linalg.det(V @ U.T))      # det 修正
    R = V @ np.diag([1.0, 1.0, d]) @ U.T
    t = q_bar - R @ p_bar
    return R, t, S

def solve_handeye(p_cam, P_base, A_poses):
    q = [(inv_T(A) @ [*P, 1.0])[:3] for P, A in zip(P_base, A_poses)]
    R, t, S = kabsch(p_cam, np.array(q))
    return make_T(R, t), S
```

## 9. 自测

**Q1**：传感器只测到 `(X, 0, Z)` 两个坐标，为什么还能解出 6 自由度的手眼？

**Q2**：切 4 个孔、扫两个高度。如果只扫一个高度，会发生什么？为什么？

**Q3**：判断对错并说明原因：「这次标定 RMS 只有 0.001 mm，说明结果一定对。」

**Q4**：如果现场只能切 4 个孔、但机械臂可以绕 X 轴转 30°，你会怎么改这个方案？为什么？

**Q5**（换场景）：把同一个方案搬到「相机看标定板」的抓取场景，需要改什么？

### 答案

**A1**：因为传感器只测 2 个坐标这件事，丢的是「传感器系下的第三个坐标」，不是「手眼的自由度」。8 组对应点里，`P_i`（基坐标真值）是三维的，`A_i` 也是完整位姿，两条链一合，`X` 的三个旋转轴都被约束住了。前提是这 8 个点在传感器平面里**张开**（非共线）——旋转矩阵由它对两个正交方向的像加上 `det=+1` 唯一确定（§5.2）。

**A2**：单高度时，同平面的 4 个孔在传感器里只有 2 个不同的位置（x 相反、深度相同），点集退化成一条直线，`σ2/σ1 = 0`。此时绕这条线的旋转完全不可观：实测残差 0.0000 mm，但旋转误差 90.1005°、平移误差 240.6 mm。双高度把点撑成二维，`σ2/σ1` 变成 0.0625，解才唯一（§5.3）。

**A3**：错。残差小只说明「模型能解释这 8 个点」，不说明「解唯一」。同一组数据在共线时会给出残差 0、旋转错 90° 的结果（§5.2）。正确做法：看 `σ2/σ1`、看独立验证、看 `R` 是否接近单位阵。

**A4**：可以不切第二个高度，改成「让机床绕 X 轴转 30° 后重扫同一批孔」。这样 8 个点的深度和朝向都变了，点集在传感器平面里是张开的。但要注意：转动会引入 B 轴/回转精度误差，而且切割头带倾角时孔边缘容易测偏 —— 所以工业上更常用「抬高度」而不是「转姿态」。

**A5**：核心公式不变（`P = A X p`），变的是数据来源：孔的圆心真值换成标定板角点的世界坐标（或标定板位姿 `T` 已知），`p` 从「激光截面拟合圆心」换成「角点的相机坐标」；如果不给真值、只给标定板位姿，就退回 `AX = XB`，必须转姿态。验收标准也从「残差 < 0.1 mm」换成「重投影 < 0.5 px + 抓取闭环」。

## 10. 面试题纲

**Q1. 手眼标定有哪几种做法？** ★

**一句话**：两条路 —— 靶标姿未知就用 `AX = XB`，靶标真值已知就直接 Kabsch。

**讲开**：

- 因为 `AX = XB` 是靠「两次观测把未知靶标位姿差分掉」，所以信息只从运动里来；
- 如果不这样、而是靶标的世界坐标已知（切割孔、标定板位姿已知），就不需要差分，直接 `P = A·X·p` 解；
- 如果不这样而硬用 `AX = XB` 去套已知真值，会白丢掉一半信息，还可能被纯平移卡死。

**数字锚点**：同一组纯平移数据，`AX = XB` 对「绕平移轴转 5°」的残差是 `8.4e-16 mm`（完全不敏感），而 Kabsch 在 5° 误差下 RMS 是 `6.98 mm`。

**追问**：「那 `AX = XB` 是不是没用了？」→ 不是，标定板位姿未知、相机只能看板时才必须用它。

**Q2. 为什么手眼标定怕纯平移？** ★★

**一句话**：纯平移时旋转方程退化成恒等式，只有平移方向那一个方向能约束旋转。

**讲开**：

- 因为 `AX = XB` 的旋转部分是 `R_A R_X = R_X R_B`，纯平移时 `R_A = R_B = I`；
- 所以方程变成 `R_X = R_X`，对 `R_X` 零信息；平移方程里只剩 `a = R_X Rᵀa`，只约束了旋转在 `a` 上的分量；
- 如果不绕不同轴转动，绕平移轴的旋转就永远标不出来，而 170 mm 力臂上 1° 就是 3 mm。

**数字锚点**：绕平移轴差 5° 时 `AX = XB` 残差 `8.42e-16 mm`，绕垂直轴差 5° 时残差 `3.49 mm` —— 前者完全不可见。

**追问**：「有没有例外？」→ 有，靶标真值已知时（本篇的切割圆）纯平移完全没问题。

**Q3. 线激光只能给一个截面，怎么标 6 自由度？** ★★

**一句话**：靠「多组对应点」把缺失的第三个坐标补出来，但必须让点在平面里张开。

**讲开**：

- 因为一次扫描只给 `(X, 0, Z)`，所以 `p_i` 永远在传感器平面里，`H` 的秩最多是 2；
- 因为 `P_i` 是三维真值、`A_i` 是完整位姿，所以 `q_i = A_i⁻¹P_i` 也是三维的，两组点一配就把旋转定住了；
- 如果点退化成一条线，`H` 的秩变成 1，绕这条线的旋转就不可观。

**数字锚点**：`σ(H) = [51204.96, 3199.72, 2.27e-16]`，第三维恒为 0；`σ2/σ1 = 0.0625` 时可解，`= 0` 时旋转误差 90.4°。

**追问**：「`σ3 = 0` 说明数据有问题吗？」→ 不，是物理必然，不能当失败判据。

**Q4. 为什么切 4 个孔要扫两个高度？** ★★

**一句话**：共面的 4 个孔在单高度下退化成一条线，双高度才把点撑成二维。

**讲开**：

- 因为孔都在同一个平面，传感器在每个孔位都摆到「激光面过圆心」，所以 4 个点的深度值几乎相同；
- 所以单高度时 4 个点只剩 2 个不同位置（x 相反、深度相同），是共线；
- 抬到第二个高度后，深度整体平移 40 mm，8 个点才真正张开；如果不这样做，残差会是 0，但旋转可以错 90°。

**数字锚点**：单高度 `σ2/σ1 = 0`、旋转误差 `90.10°`；双高度 `σ2/σ1 = 0.0625`、旋转误差 `0.0000°`。

**追问**：「还有别的办法让点张开吗？」→ 四面靶、台阶靶（§5.4），代价分别是转轴误差和工装复杂度。

**Q5. 手眼标定里哪个误差最贵？** ★★

**一句话**：角度 —— 它被力臂放大成毫米。

**讲开**：

- 因为 `δ ≈ θ·r`，170 mm 力臂上 1 arcmin 就是 0.05 mm；
- 所以同样「看起来很小」的 0.05°，在孔位边缘已经是 0.15 mm，直接吃掉 0.1 mm 阈值；
- 如果不控制角度（安装面倾斜、TCP 标定误差），平移标得再准也没用。

**数字锚点**：噪声 0.02 mm 时旋转误差 0.0060°，换算到 170 mm 是 0.018 mm；噪声 0.2 mm 时旋转 0.0600°、平移误差已到 0.1849 mm。

**追问**：「怎么压角度误差？」→ 双高度拉大深度差、加大孔间距、停稳再扫。

**Q6. 标完怎么证明是对的？** ★★

**一句话**：残差 + 独立验证 + 重复性 + 物理合理性，四条都要。

**讲开**：

- 因为残差只说「这 8 个点能被解释」，共线时残差 0 但解错；
- 所以要用**没参与求解的数据**验证（另扫几个平面看平行度/距离）；
- 还要看重复性（重标 3 次抖多少）和物理合理性（`R` 是否接近单位阵、`t` 是否符合安装尺寸）。

**数字锚点**：本篇 8 点的逐点残差最大 0.0301 mm、RMS 0.0165 mm；共线情形 RMS 0.0000 mm 但旋转错 90.3999°。

**追问**：「只做一个验证，选哪个？」→ 物理合理性，它最快能抓出镜像/轴符号这种致命错误。

**Q7. 如果矩阵解出来方向是反的，最可能是哪里错了？** ★★★

**一句话**：`H` 的定义和 `R` 的公式不配套，解成了 `Rᵀ`。

**讲开**：

- 因为 Kabsch 有两套等价写法（`H = Σp̃q̃ᵀ` 配 `VDUᵀ`，或 `H = Σq̃p̃ᵀ` 配 `UDVᵀ`），转置是最常见的笔误；
- 而 `Rᵀ` 同样是正交矩阵、`det = +1`，所有「检查是不是旋转」的断言都会通过；
- 如果不检查，实机上表现为运动方向整体反了，而不是「稍微不准」。

**数字锚点**：转置解与 `R_trueᵀ` 的夹角是 `0.0000°`（确认就是转置），固定 `t` 后 RMS 从 `0.000` 涨到 `1.696 mm`。

**追问**：「光看残差能发现吗？」→ 只有在对同一批点重算残差时能；如果同时把 `t` 也解错，会被部分抵消，所以必须看 `R` 是否接近单位阵。

**Q8. 换一根更长的管、孔间距变大，精度会变好吗？** ★

**一句话**：会，角度误差按 1/间距 下降，平移基本不变。

**讲开**：

- 因为旋转是靠点的分布定出来的，分布越大、同一个测量噪声对应的角度误差越小；
- 而平移由质心决定，和分布大小无关；
- 所以孔要么铺开，要么多测几个高度，别都堆在中间。

**数字锚点**：本篇分布半径 ~170 mm，噪声 0.02 mm 对应旋转误差 0.0060°（≈0.018 mm 力臂误差）。

**追问**：「那孔越大越好？」→ 受管材宽度和传感器视场限制，且孔边缘拟合误差会随直径变差。

> **只背 4 道**：Q2（纯平移）、Q3（2D 观测）、Q4（双高度）、Q6（验收）。

## 11. 坑清单（写代码时对照）

1. **用 `σ3` 判断退化** —— 它在本题里恒为 0，永远看不出问题；看 `σ2/σ1`。
2. **`H` 与 `R` 公式混搭** —— 解出 `Rᵀ`，一切正交性检查都通过。
3. **只扫一个高度**（共面孔）—— 残差 0，旋转错 90°。
4. **只做一次标定就完事** —— 没有重复性数据，无法区分「偶然标好」和「真稳」。
5. **只减平移不减旋转** —— 切割头带倾角时，`q_i` 算错，误差进 `t`。
6. **运动中扫描** —— 位姿与点云不同步，误差随速度增长；到位停稳再扫。
7. **拿 RMS 当唯一指标** —— 共线时 RMS 最好，结果最差。
8. **孔位全在同一条母线** —— 双高度也救不了，`σ2/σ1` 还是 0。
