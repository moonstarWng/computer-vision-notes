## 0. 开始之前：任务与名词

### 0.1 任务：8 张棋盘格照片，要交出内参和误差报告

场景：产线要上线一台新相机，需要给出 `fx, fy, cx, cy` 和畸变系数，并要求重投影 RMSE < 0.5 px。

**痛点**：

- 内参不是印在镜头上的，也不等于「焦距 8 mm」——它是像素单位的。
- 直接调 `cv2.calibrateCamera` 也能出结果，但出了问题（RMSE 1.2 px）你不知道错在哪。
- 标定板怎么拍？拍几张？为什么有的姿态必须拍？没人讲清楚。
- 「RMSE 0.3 px 就是好吗？」——不一定，可能是过拟合。

**本篇解决哪一步**：把「一张张照片 → K + 外参 + 畸变」这条链路完整走一遍，重点讲**为什么需要多个姿态**和**怎么判断标定靠不靠谱**。手眼标定、相机-雷达外参不在这篇（在 M8 和本篇之后的外参专题）。

### 0.2 名词卡片

**单应（homography）**
- 一句话：两个平面之间的 3×3 射影变换，8 个自由度（差一个尺度）。
- 用在哪：`s·[u,v,1]ᵀ = H·[X,Y,1]ᵀ`，把靶标平面映射到图像平面。
- 不是：不是相似变换，也不是仿射——它允许「近大远小」的透视。

**DLT（Direct Linear Transform，直接线性变换）**
- 一句话：把单应/投影矩阵的求解变成「齐次线性方程组 + SVD」。
- 关键：先用 Hartley 归一化（平移+缩放），否则条件数差到解不出来。

**张正友标定（Zhang's method）**
- 一句话：平面靶标多姿态 → 单应 → 用旋转列的正交/等长约束解 K → LM 精化。
- 不是：不是「找一个标定板型号就行」，拍法是标定质量的一半。

**重投影误差（reprojection error）**
- 一句话：用估出来的参数把 3D 点再投一次，和检测到的角点差多少像素。
- 用在哪：标定的**唯一**通用验收指标（但要配合独立验证）。

**退化（degeneracy）**
- 一句话：数据提供的信息不足以唯一确定参数，方程满秩但条件数极差，或直接不满秩。
- 典型：所有姿态都是纯平移、靶标始终在画面中心、只拍 2 张。

**交叉验证（cross-validation）**
- 一句话：留出一部分数据不参与求解，只用它算误差。
- 用在哪：判断「RMSE 小」是真准，还是参数把噪声拟合了。

## 1. 平面靶标：把 3D 问题降成 2D

### 1.1 关键一步：令 `Z = 0`

靶标是平的，世界坐标写成 `(X, Y, 0)`。投影公式：

```
s·[u, v, 1]ᵀ = K · [r1 r2 r3 t] · [X, Y, 0, 1]ᵀ
             = K · [r1 r2 t] · [X, Y, 1]ᵀ
             = H · [X, Y, 1]ᵀ
```

`r3` 那一列被 `Z=0` 乘没了。于是「3D 点的标定」变成了「两个平面之间的单应」：

```
H = K · [r1 r2 t]        （3×3，8 个自由度）
```

**这一步是整篇的地基**：它把「求 6 个外参」变成「求 8 个单应参数」，而单应只需要 ≥4 个对应点就能解。棋盘格有 35 个内角点，绰绰有余。

### 1.2 单应里藏了什么

```
H = [h1 h2 h3] = λ · K · [r1 r2 t]
```

- `h1`、`h2` 是 **K 乘旋转列**；
- `h3` 是 **K 乘平移**。

所以：
- 从 `h1, h2` 能反推 `r1, r2`（前提是知道 K）；
- 从 `h3` 能反推 `t`；
- `r3 = r1 × r2` 补全旋转。

**这就是为什么单应能同时给出外参**：它把旋转的前两列和平移都编码进去了。

## 2. 求单应：DLT 只有两步

### 2.1 方程

把 `H` 的 9 个元素当未知数，每个点对给 2 个齐次方程：

```
[-X, -Y, -1,  0,  0,  0,  uX, uY, u] · h = 0
[ 0,  0,  0, -X, -Y, -1,  vX, vY, v] · h = 0
```

≥4 个点 → 8 个方程 → `A` 的零空间（SVD 最小奇异向量）就是 `h`。

### 2.2 必须归一化

像素坐标动辄 `+600`，靶标坐标 `0~180`，量级差 4 倍；直接解会让 `A` 的条件数差到 `1e12`。

**Hartley 归一化**：把点平移到质心、缩放到「平均距离 = √2」，解完再乘回去。

```
s_h = T_src · src
d_h = T_dst · dst
H   = T_dst⁻¹ · H_norm · T_src
```

### 2.3 实测

35 个点、8 个姿态、角点噪声 σ=0.3 px：

```
单应重投影 RMSE = 0.253 px
```

单应自身的误差已经接近噪声水平，说明 8 个自由度"够用"，没有欠拟合。

## 3. 从单应到内参：两个约束，六元一次方程

### 3.1 约束从哪来

`[r1 r2 t]` 是旋转+平移，所以 `r1`、`r2` 有两条硬性质：

```
r1ᵀr2 = 0        （正交：旋转矩阵的列互相垂直）
|r1| = |r2| = 1  （等长：每个列都是单位向量）
```

把 `r1 = K⁻¹h1/λ`、`r2 = K⁻¹h2/λ` 代进去：

```
h1ᵀ K⁻ᵀ K⁻¹ h2 = 0
h1ᵀ K⁻ᵀ K⁻¹ h1 = h2ᵀ K⁻ᵀ K⁻¹ h2
```

令 `B = K⁻ᵀK⁻¹`（3×3 对称），就得到两个**关于 B 的线性方程**。

### 3.2 B 长什么样

对 `K = [[fx,0,cx],[0,fy,cy],[0,0,1]]`：

```
B = [[1/fx²,      0,      -cx/fx²     ],
     [   0,    1/fy²,      -cy/fy²     ],
     [-cx/fx², -cy/fy²,  cx²/fx²+cy²/fy²+1]]
```

对称 → 6 个独立元素 `b = (B11,B12,B22,B13,B23,B33)`。每个姿态给 2 个方程，所以：

```
3 个姿态 → 6 个方程 ≥ 6 个未知数（实际 5 个自由度，因为 b 只定到尺度）
```

### 3.3 解出 B 再拆 K

```
b  = A 的零空间（SVD 最小奇异向量）
cy = (B12·B13 − B11·B23) / (B11·B22 − B12²)
λ  = B33 − (B13² + cy·(B12·B13 − B11·B23))/B11
fx = √(λ/B11)
fy = √(λ·B11/(B11·B22 − B12²))
cx = −B13·fx²/λ
```

这就是「Cholesky 分解」那一步的公式化版本：`K` 是 `B` 的 Cholesky 因子（差一个缩放）。

### 3.4 实测（8 姿态，噪声 0.3 px）

```
真值:  fx=1800.0  fy=1800.0  cx=640.0  cy=512.0
线性:  fx=1798.94 fy=1796.93 cx=648.07 cy=509.84
偏差:  fx −0.06%  fy −0.17%  cx +8.07 px  cy −2.16 px
线性解重投影 RMSE = 0.367 px
```

**读法**：

- `fx, fy` 已经很准（千分之一），因为焦距主要由「目标在图上多大」决定，信息量大。
- `cx, cy` 差了 8 px 和 2 px——主点和焦距是**强耦合**的：把焦距调大一点、主点移一点，投影几乎不变。这就是为什么主点最难估准。
- 8 px 的主点误差，在 500 mm 处相当于 `8 × 0.216 ≈ 1.7 mm` 的系统偏移。测绝对位置时必须在意。

## 4. 外参：从 H 里拆出 R 和 t

```
λ  = (|K⁻¹h1| + |K⁻¹h2|)/2
r1 = K⁻¹h1/λ
r2 = K⁻¹h2/λ
t  = K⁻¹h3/λ
r3 = r1 × r2
```

数值上 `R = [r1 r2 r3]` 不会严格正交（噪声 + 线性解），用 SVD 投影回 `SO(3)`：

```
R = U·Vᵀ        （对 R 做 SVD：R = UΣVᵀ，把 Σ 换成 I）
```

如果 `det(R) = −1`，说明解到了"镜像"，把最后一列取反。

---

## 5. 非线性精化：为什么线性解还不够

### 5.1 线性解的三个近似

1. **忽略了畸变**（本篇先不估，第 2 篇的 `k1,k2` 要一起进非线性优化）。
2. **最小化的是代数误差**，不是像素误差——`A·h = 0` 的残差没有物理单位。
3. **假设单应无噪声**，但单应本身是从带噪声的角点解出来的，误差会传进 K。

### 5.2 精化：最小化重投影误差

```
minimize  Σ_i Σ_j | uv_obs(i,j) − π(K, R_i, t_i, X_j) |²
参数:     fx, fy, cx, cy + 每个姿态 6 个（rvec, tvec）
```

用 LM（Levenberg–Marquardt，M1 第 2 篇）迭代。实测：

```
线性解:  fx=1798.94  fy=1796.93  cx=648.07  cy=509.84   RMSE 0.367 px
精化后:  fx=1798.33  fy=1797.62  cx=645.19  cy=510.59   RMSE 0.258 px
```

**改善在哪**：`cx` 从 +8.07 px 收到 +5.19 px，RMSE 从 0.367 降到 0.258。主点仍然有 5 px 偏差，这不是算法问题，而是**这组数据本身对主点不敏感**（见 §6 的拍法建议）。

### 5.3 每个姿态的残差

```
视角 1: 0.253 px    视角 5: 0.251 px
视角 2: 0.250 px    视角 6: 0.261 px
视角 3: 0.251 px    视角 7: 0.264 px
视角 4: 0.296 px    视角 8: 0.236 px
```

八个姿态都在 0.24~0.30 之间，**没有哪个特别差**——说明没有某张图糊了、或者某个姿态解错了。这是标定报告里必须看的一张表：如果某个视角 1.5 px，其余 0.25 px，先去看那张图。

## 6. 姿态怎么拍：这一节决定成败

### 6.1 三个必须

| 必须 | 为什么 | 不做的后果 |
|---|---|---|
| **倾斜**（15°~35°） | 只有倾斜才能让 `fx` 和 `Z` 解耦 | 全正对时 `fx` 与距离强耦合，K 偏差大 |
| **覆盖画面四角** | 主点和畸变只在边缘有信息 | `cx,cy` 估不准（本篇就是例子，偏 5 px） |
| **不同方位**（左/右/上/下） | 让旋转列的信息各向同性 | 某个方向的焦距估不准 |

### 6.2 三个不要

- **不要纯平移**：`R` 不变时，所有姿态给的是同一组约束，等于只有一个姿态。
- **不要只拍 2 张**：2 个姿态只有 4 个方程，B 有 6 个未知数 → 不满秩。
- **不要让靶标出画**：完整的棋盘才有点，缺角会让单应病态。

### 6.3 实测：2 个姿态会怎样

```
方程数 4，未知数 6 → rank = 4
最小奇异值 5.03e-03（接近 0 说明解不唯一）
```

`rank < 6` 意味着 K 不可唯一确定。**注意它不会报错**：SVD 照样给你一个 `b`，只是那个 `b` 是任意挑的一个零空间方向。

## 7. 怎么判断标定好不好：四件套

| 检查 | 怎么看 | 不合格的表现 |
|---|---|---|
| **重投影 RMSE** | 总体 + 每个姿态 | 总体 < 0.5 px，但**单个视角不能是总体的 3 倍** |
| **残差方向性** | 画残差向量场 | 残差都朝一个方向 → 模型缺项（畸变/主点偏） |
| **独立验证** | 留一组图不参与求解，只用它算 RMSE | 训练 0.25 px、验证 1.2 px → 过拟合 |
| **物理合理性** | `fx·dx ≈ f`、`cx,cy` 离中心不太远、`k1` 量级合理 | `fx·dx = 15 mm` 但镜头标 8 mm → 单位/分辨率错 |

### 7.1 RMSE 小 ≠ 标定好

本篇 RMSE 0.258 px，噪声 0.30 px——**比噪声还小**。这不是"超神"，而是：52 个参数拟合 560 个观测，参数吃掉了一部分噪声（自由度消耗）。

判断方法只有一个：**换一组没参与标定的图，重算 RMSE**。如果验证误差明显大于训练误差，就是过拟合（通常是姿态太少 / 姿态太像）。

### 7.2 主点为什么总是最难

回到 §3.4：`cx` 偏 5 px。因为「把 K 整体平移一点 + 外参补偿一点」几乎不改变投影。要让它可辨识，唯一办法是**让靶标出现在画面各个位置**——信息来自「同一块板在不同位置时的透视差异」。

## 9. 自测

**Q1**：为什么平面靶标能简化问题？`Z=0` 到底消掉了什么？

**Q2**：单应 `H = K[r1 r2 t]` 里，`h1/h2/h3` 分别对应什么？

**Q3**：「正交 + 等长」这两个约束是怎么变成线性方程的？每个姿态提供几个？

**Q4**：为什么至少要 3 个姿态？2 个姿态在数学上发生了什么？

**Q5**：线性解 RMSE 0.367 px，精化后 0.258 px。既然线性解已经够用，为什么还要精化？

**Q6**（换场景）：一组标定图全是正面拍摄、靶标始终在画面中心。RMSE 可能很好，但哪个参数最不可信？为什么？

### 答案

**A1**：靶标是平面，世界坐标 `Z=0`；`r3` 那一列被乘没了，于是 `K[r1 r2 r3 t]` 退化成 `K[r1 r2 t]`——一个 3×3 的单应，只需 ≥4 个对应点。

**A2**：`h1 = λKr1`、`h2 = λKr2`、`h3 = λKt`。前两个给出旋转的前两列（第三列叉乘补全），第三个给出平移。

**A3**：把 `r = K⁻¹h/λ` 代入 `r1ᵀr2=0` 和 `|r1|=|r2|`，得到两个关于 `B=K⁻ᵀK⁻¹` 的线性方程（`v12·b=0`、`(v11−v22)·b=0`）。每个姿态 2 个方程，`B` 有 5 个自由度 → 至少 3 个姿态。

**A4**：2 个姿态只有 4 个方程，少于 `B` 的 6 个未知数（5 自由度），方程组不满秩（实测 rank=4）。SVD 仍会返回一个解，但那个解是任意的，K 不可信。

**A5**：线性解最小化的是**代数误差**（`A·h=0` 的残差，没有物理单位），而且假设单应无噪声。精化直接最小化**像素重投影误差**，能把主点从 +8.07 收到 +5.19，RMSE 从 0.367 降到 0.258。

**A6**：`cx, cy`（主点）最不可信。全部正面、居中时，主点与焦距、外参强耦合；移动主点可以用平移外参补偿，投影几乎不变。要让它可辨识，必须让靶标出现在画面各个位置。

## 10. 面试题纲

> **怎么用**：★ 秒答；★★ 讲满 2 分钟、带因果链；★★★ 画图 + trade-off。第一遍只要求 ★ 全过，讲不出来的记进 §13 未懂清单。
> **题量规则**：`n = 1 主干 + 对比 + 坑 + 手算`，封顶 12。本篇 `1 + 3 + 5 + 1 = 10`。
> **脉络**：一条主线（单应）→ 三个对比 → 五个坑 → 一个手算。

### 10.1 主干（1 题）

**Q1. 张正友标定的完整思路是什么？** ★

**一句话**：平面靶标 → 单应 → 用「旋转列正交且等长」解 K → LM 最小化重投影误差。

**讲开**：

- 靶标平面取 `Z=0`，投影退化成单应 `H = K[r1 r2 t]`，≥4 个点就能解。
- 单应里藏着 `K·r1`、`K·r2`、`K·t`；旋转列必须正交且等长，这两条给每个姿态 2 个关于 `B=K⁻ᵀK⁻¹` 的线性方程。
- 3 个以上姿态 → 解出 `B` → 拆出 `fx, fy, cx, cy`（数值上就是 Cholesky）。
- 再用 LM 最小化重投影误差，把内参、外参、畸变一起精化。

**数字锚点**：本篇 8 姿态、35 角点、噪声 0.3 px：单应 0.253 px → 线性 K `fx=1798.94`（真值 1800）→ 精化后 RMSE `0.258 px`。

**追问**：「为什么不用 3D 靶标？」→ 3D 靶标加工贵、精度难保证；平面靶标可以用高精度打印，而且 `Z=0` 让求解变成线性。

### 10.2 三个对比（3 题）

**Q2. 单应和内参是什么关系？单应能直接当内参用吗？** ★

**一句话**：单应 = K 乘外参；它包含了内参和外参的乘积，**不能直接拆出内参**，除非有多个姿态。

**讲开**：

- 一个单应 = 8 个数，混合了 `fx, fy, cx, cy` 和 6 个外参 → 欠定。
- 多个姿态共享同一个 K，才让「正交/等长」约束变成关于 K 的方程。
- 所以单姿态标定是**不可能**的；这也是为什么标定必须拍很多张。
- 反过来，外参已知时（比如机械臂带着走），单张图就能解内参的某些分量。

**数字锚点**：本篇 8 个姿态 → 16 个约束；未知数 5（`B` 的 5 个自由度）→ 超定。

**追问**：「那两个姿态够不够？」→ 不够，4 个方程 < 5 个自由度，rank=4（实测）。

**Q3. 线性解和 LM 精化，各自在优化什么？** ★★

**一句话**：线性解最小化代数误差（无单位），LM 最小化像素重投影误差（有物理意义）。

**讲开**：

- DLT/闭式解把问题变成 `A·x = 0`，残差是齐次坐标的代数残差，没有 px 单位。
- 它假设单应无噪声，但单应是从带噪声的角点解出来的，误差会传进 K。
- LM 直接最小化 `Σ|观测 − 重投影|²`，单位是 px²，物理意义明确。
- 代价：需要好的初值（线性解）和迭代；局部极小值风险靠初值控制。

**数字锚点**：线性 `RMSE 0.367 px`、`cx` 偏 +8.07 px → 精化后 `0.258 px`、+5.19 px。

**追问**：「那能不能跳过线性解，直接 LM？」→ 可以但危险：LM 对初值敏感，容易掉进局部极小；线性解给了一个「差不多对」的起点。

**Q4. 为什么平面靶标就够？3D 靶标有什么优势？** ★★

**一句话**：平面靶标靠「多姿态」补上了第三维的信息；3D 靶标用一次拍摄就提供深度。

**讲开**：

- 平面靶标的 `Z=0` 让求解线性化，但单张图无法区分「靶标倾斜」和「焦距不同」。
- 多姿态（不同倾角）提供了这种区分能力——这就是为什么必须倾斜拍。
- 3D 靶标（立体标定块）单张就能约束全部参数，适合现场快速标定，但加工精度要求高（μm 级）。
- 工业上两者都用：实验室用平面（便宜、精度靠打印），产线用 3D 靶标（快、可自动化）。

**数字锚点**：本篇倾角 15°~35°；若全部正对（0°），`fx` 与距离强耦合，`fx` 可能偏 5% 以上。

**追问**：「那为什么要倾斜 15° 以上？」→ 倾角太小，透视效应弱，`fx` 和 `Z` 仍然分不开；太大则角点模糊、检测精度下降。

### 10.3 五个坑（5 题）

**Q5. 为什么至少 3 个姿态？2 个会怎样？** ★

**一句话**：每个姿态 2 个方程，`B` 有 5 个自由度，2 个姿态只有 4 个方程——不满秩。

**讲开**：

- `B = K⁻ᵀK⁻¹` 对称，6 个元素、只定到尺度 → 5 个自由度。
- 每个姿态给 2 个约束（正交 + 等长），3 个姿态刚好 6 个 ≥ 5。
- 2 个姿态时方程数 4 < 5，SVD 仍会给一个「零空间方向」，但那个方向不唯一。
- **不会报错**，只会给你一组看起来正常的错参数。

**数字锚点**：实测 2 姿态：4 个方程、`rank=4`、最小奇异值 `5.03e-03`（相对于最大奇异值接近 0）。

**追问**：「3 个姿态就一定够？」→ 数学上够，但工程上建议 8~15 个：姿态越多，主点和畸变越稳。

**Q6. 标定板应该怎么拍？** ★★

**一句话**：要倾斜、要覆盖四角、要不同方位；不要纯平移、不要只拍中心。

**讲开**：

- 倾角 15°~35°：让 `fx` 与距离解耦，也是畸变参数的唯一信息来源。
- 覆盖四角：主点和 `k1,k2` 只在边缘有信息。
- 不同方位：让约束各向同性，避免某个方向偏。
- 纯平移 = 旋转不变 = 所有姿态提供同一组约束，等于只拍了一张。

**数字锚点**：本篇全部居中拍摄，结果 `cx` 偏 5 px；如果板子铺到四角，主点通常能收到 1~2 px。

**追问**：「靶标可以出画吗？」→ 不行，出画会缺点，单应病态；建议靶标占画面 1/3~2/3，且完整可见。

**Q7. 重投影 RMSE 0.25 px，能说明标定好吗？** ★★

**一句话**：不能。RMSE 小可能只是过拟合；必须用没参与标定的数据再验一次。

**讲开**：

- RMSE 是训练误差：参数越多、姿态越像，越容易把噪声拟合进去。
- 本篇 RMSE 0.258 < 噪声 0.30，就是「参数吃掉了一部分噪声」的迹象。
- 正确做法：留 1~2 组图不参与求解，用它们算 RMSE；两者差距 < 20% 才算稳。
- 还要看**残差方向**：都朝一个方向说明模型缺项，不是随机噪声。

**数字锚点**：训练 0.258 px vs 噪声 0.30 px；若验证集突然 1.2 px，说明过拟合或姿态覆盖不足。

**追问**：「那 RMSE 多少算合格？」→ 工业测量一般要求 < 0.5 px，亚像素测量 < 0.2 px；但必须同时满足「验证误差接近训练误差」。

**Q8. 标定里哪些参数最难估？为什么？** ★★

**一句话**：主点 `cx, cy` 最难，因为它和焦距、外参强耦合。

**讲开**：

- 把主点移一点、焦距调一点、外参转一点，投影几乎不变——这是**参数之间的补偿**。
- 要打破耦合，唯一办法是让靶标出现在画面各处，用不同位置的透视差异提供信息。
- 相对而言 `fx, fy` 好估：它主要由「目标在图上多大」决定，信息量大。
- 畸变参数也难：只在边缘有信息，所以标定板必须拍满画面。

**数字锚点**：本篇线性解 `cx` 偏 +8.07 px，精化后仍偏 +5.19 px；`fx` 只偏 −0.09%。

**追问**：「主点偏 5 px 影响大吗？」→ 500 mm 处约 1.1 mm 的系统偏移；测绝对位置必须在意，测相对尺寸（两点差）影响小。

**Q9. 什么时候该把畸变加进标定？顺序是什么？** ★★

**一句话**：畸变必须和 K 一起优化，但初值来自「无畸变假设下的线性解」。

**讲开**：

- 张正友的线性解假设无畸变（否则单应不成立），先得到 `K` 和姿态初值。
- 然后 LM 把 `k1,k2,p1,p2` 加进参数向量，一起最小化重投影误差。
- 顺序不能反：先估畸变再估 K，会因为畸变模型本身依赖 K 而循环。
- 判断要不要加 `k3`：看去畸变后边缘还有没有残余弯曲（第 2 篇 §7）。

**数字锚点**：本篇为了讲清线性解，暂不估畸变；加了 `k1,k2` 后，边缘残差通常能从 1~2 px 降到 0.3 px。

**追问**：「畸变和 K 会互相抢吗？」→ 会。`k1` 和 `fx` 在边缘有耦合；所以标定板必须覆盖四角，否则两者都估不准。

### 10.4 一个手算（1 题）

**Q10. 30 mm 的棋盘格，在 500 mm 处、`fx=1800` 时占多少像素？这对标定意味着什么？** ★★

**一句话**：`30 × 1800 / 500 = 108 px`；角点定位 0.3 px 就是 0.28% 的尺度误差。

**讲开**：

- 像面上一个格子的长度 = `f · X / Z`，换成像素就是 `fx · X / Z`。
- 108 px 的间距意味着：角点噪声 0.3 px → 单格相对误差 0.28% → `fx` 的统计误差同量级。
- 想提高精度：靠近拍（Z 小）、用更大格子、或提高角点定位精度（亚像素）。
- 反过来这也解释了为什么远处标定不准：同样的噪声，`Z` 越大，占的像素越少，相对误差越大。

**数字锚点**：`30×1800/500 = 108 px`；0.3/108 = 0.28%；8 个姿态平均后误差约降到 `0.28%/√8 ≈ 0.1%`，与实测 `fx` 偏差 0.09% 吻合。

**追问**：「格子越大越好吗？」→ 越大越准，但一块板能放的格子数变少，且边缘覆盖变差；通常 7×5~11×9 个内角点、占画面 1/3~2/3。

## 11. 坑清单

| # | 坑 | 症状 | 处理 |
|---|---|---|---|
| 1 | 只拍 2~3 张 | K 不可信但不报错 | ≥8 个姿态，覆盖四角 |
| 2 | 全部正对、居中 | 主点偏 5~20 px | 倾斜 15°~35°，铺满画面 |
| 3 | 纯平移 | 等价于只拍一张 | 每个姿态都要转 |
| 4 | 靶标出画/缺角 | 单应病态、残差大 | 保证完整可见，占 1/3~2/3 |
| 5 | 只报总 RMSE | 单视角坏图被平均掉 | 报每个姿态 + 验证集 |
| 6 | 不看残差方向 | 模型缺项被当成噪声 | 画残差向量场 |
| 7 | 先估畸变再估 K | 循环依赖、不收敛 | 先线性解 K，再联合优化 |
| 8 | 用训练 RMSE 当验收 | 过拟合 | 留出独立验证集 |
| 9 | 换分辨率不缩放 K | 尺寸系统性偏 | `fx,fy,cx,cy` 乘缩放 |
| 10 | 靶标打印不平行/不平整 | 系统性残差 | 用高精度打印/陶瓷靶标，贴平 |
