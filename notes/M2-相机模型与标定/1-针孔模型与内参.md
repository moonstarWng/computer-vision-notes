## 0. 开始之前：任务与名词

### 0.1 任务：量一个 2 mm 的孔，误差要小于 0.05 mm

场景：相机装在工位上方 500 mm，俯拍一个零件，要量孔径，公差 ±0.05 mm。

**痛点**：

- 你手上只有像素坐标，怎么知道「1 个像素 = 多少毫米」？
- 相机往后退 200 mm，同一个孔变成多少像素？
- 为什么换个镜头，同样的算法精度就变了？
- 图像从 1280×1024 裁成 400×300 去做 ROI，还能用原来的参数吗？

**本篇解决哪一步**：先把「3D ↔ 2D」这一个变换写清楚（针孔模型 + 内参），并算清楚精度从哪来。畸变、标定怎么求 K、外参怎么定，分别在第 2~4 篇。

### 0.2 名词卡片

**针孔模型（pinhole model）**
- 一句话：所有光线穿过一个点（光心），在像面上留下投影。
- 数学：`u = fx·(X/Z) + cx`。
- 不是：不是真实相机的全部——真实相机有镜头畸变，针孔只是**几何主干**（第 2 篇补畸变）。

**内参（intrinsic parameters）**
- 一句话：相机自己的「换算表」，与拍什么无关。
- 组成：`fx, fy, cx, cy`（+ 通常为 0 的 skew）。
- 不是：不是外参。内参不随相机移动而变，只随「换镜头、改焦距、改分辨率、改对焦」而变。

**外参（extrinsic parameters）**
- 一句话：相机在世界里的位置和朝向，`X_cam = R·X_world + t`。
- 不是：不是标定的全部。标定内参不需要知道外参，标定外参需要先有内参。

**主点（principal point，`cx, cy`）**
- 一句话：光轴与像面的交点，落在图像上的像素坐标。
- 不是：不是图像正中心 `(W-1)/2`。装配误差会让它偏几个到几十个像素。

**归一化坐标（normalized image coordinates）**
- 一句话：`x_n = X/Z`、`y_n = Y/Z`，单位是 1（等价于 tan 角度）。
- 用在哪：把「内参」和「几何」分开——归一化平面上的点与相机型号无关。
- 不是：不是像素坐标，也不是米。

**像素焦距（focal length in pixels，`fx`）**
- 一句话：`fx = f / dx`，物理焦距除以像元尺寸。
- 单位：像素（px）。
- 不是：不是镜头上标的 8 mm。8 mm 是物理焦距，2318 px 才是它在图上的作用。

**视场角（Field of View，FOV）**
- 一句话：相机能看到的张角，`FOV = 2·atan(传感器宽度 / (2f))`。
- 关系：焦距越长，FOV 越小，`mm/px` 越小（看得更细，但看得更窄）。

**反投影（back-projection）**
- 一句话：把像素变回一条**射线**。
- 关键：只得到方向，得不到距离——深度信息在投影时被除掉了。

## 1. 坐标系链条：四层，每层一个负责人

```
世界坐标 (mm)          你定的：工件坐标系 / 标定板坐标系
      │  外参 R, t       ← 标定外参、PnP、手眼标定负责
      ▼
相机坐标 (mm)          光心为原点，Z 轴朝前（光轴）
      │  除以 Z          ← 没有参数，纯几何
      ▼
归一化平面 (无量纲)     x_n = X/Z, y_n = Y/Z
      │  乘 K            ← 内参标定（张正友）负责
      ▼
像素坐标 (px)          u = fx·x_n + cx
```

**这张表要能默写。**面试时问「这个误差出在哪一环」，答案永远落在这四层之一：

| 现象 | 出问题的层 | 典型原因 |
|---|---|---|
| 整体缩放不对 | 内参 `fx` | 焦距/像元尺寸/分辨率填错 |
| 整体平移偏几个像素 | 内参 `cx, cy` | 主点被默认成图像中心 |
| 直线拍成弯的 | 畸变（第 2 篇） | 广角镜头径向畸变 |
| 物体移动位置对不上 | 外参 `R, t` | 标定板动了、相机松了 |

> 为什么强调「归一化平面」这一层？因为**它把相机型号和几何分开了**。PnP、对极几何、三角化全部在归一化坐标里做，最后才乘各自的内参。你如果一直在像素坐标里推公式，会被 `fx, cx` 反复绕晕。

## 2. 针孔模型：一次相似三角形

### 2.1 一维推导

光心到像面距离 `f`（mm），物体在光轴方向上距离 `Z`（mm），物体高度 `X`（mm）。

相似三角形立刻给出像面上的高度：

```
x / f = X / Z        =>        x = f · X / Z        （单位 mm）
```

再换成像素：像面上 1 mm 对应 `1/dx` 个像素，

```
u = x / dx + cx = (f/dx) · (X/Z) + cx = fx · x_n + cx
```

三个动作一目了然：

| 动作 | 含义 | 依赖 |
|---|---|---|
| 除以 `Z` | 透视：远处变小 | 几何，与相机无关 |
| 乘 `f/dx` | 毫米 → 像素 | 镜头 + 传感器 |
| 加 `cx` | 光轴不在图像左上角 | 装配 |

### 2.2 写成矩阵

```
u       fx   0   cx     X/Z
v   =    0  fy   cy  ·  Y/Z
1        0   0    1      1
```

齐次坐标写法（同一个式子）：

```
u = K · [X_cam / Z_cam]
K = [[fx, 0, cx],
     [0, fy, cy],
     [0,  0,  1]]
```

`fy` 通常等于 `fx`（方形像元），所以针孔模型真正要估的是 **4 个数**：`fx, fy, cx, cy`。
`skew`（K 右上角）在绝大多数工业相机上是 0，可以忽略——但要知道它存在，它描述「像元的行方向与列方向不严格垂直」。

## 3. 内参矩阵：每个数到底是什么

### 3.1 一个真实例子

8 mm 镜头、3.45 µm 像元、1280×1024 分辨率：

```
f  = 8 mm
dx = 3.45 um = 0.00345 mm
fx = f / dx = 8 / 0.00345 = 2318.84 px
cx = (1280-1)/2 = 639.5
cy = (1024-1)/2 = 511.5

K = [[2318.84,    0.00, 639.50],
     [   0.00, 2318.84, 511.50],
     [   0.00,    0.00,   1.00]]
```

顺带算出两个工程上常用的量：

```
传感器尺寸  = 1280 × 3.45 µm = 4.416 mm    （宽）
            = 1024 × 3.45 µm = 3.533 mm    （高）
水平 FOV    = 2·atan(4.416 / (2×8)) = 30.86°
垂直 FOV    = 2·atan(3.533 / (2×8)) = 24.90°
```

**为什么 `cx` 是 639.5 而不是 640？** 因为像素中心的坐标是 `0..W-1`，中心落在两个像素之间，这是 `(W-1)/2` 的由来。差 0.5 像素在粗测量里无所谓，在亚像素测量里会被当成系统误差。

### 3.2 四个参数各自管什么

| 参数 | 物理含义 | 变了会怎样 | 什么时候会变 |
|---|---|---|---|
| `fx` | 水平方向「每弧度多少像素」 | 整体缩放 | 换焦距、换分辨率、`resize` |
| `fy` | 垂直方向同上 | 纵横比例 | 像元非方形、隔行采样 |
| `cx` | 光轴在图像上的 x 坐标 | 整体左右平移 | 装配、`crop` |
| `cy` | 同上（y） | 整体上下平移 | 装配、`crop` |

**一个反直觉的点**：`fx` 不是「焦距」，是「焦距除以像元尺寸」。所以同一支 8 mm 镜头：

- 装在 3.45 µm 像元的相机上 → `fx = 2318 px`
- 装在 5.5 µm 像元的相机上 → `fx = 1455 px`

**镜头没变，`fx` 变了。** 这也是为什么「换个同规格相机，参数不能直接抄」。

## 4. 投影与反投影：能算什么、不能算什么

### 4.1 投影（3D → 2D）

边长 100 mm 的立方体放在世界原点，相机在 `t = (10, -5, 500)` mm，带一点姿态：

```
8 个角点的深度范围: 442.6 ~ 557.4 mm
角点 (-50,-50,-50) -> (464.206, 193.464)
角点 (-50,-50, 50) -> (539.576, 234.125)
角点 (-50, 50,-50) -> (367.367, 693.188)
8 个角点全部落在 1280×1024 图内
```

注意两件事：

1. **深度不是常数**：立方体有厚度 + 相机有姿态，8 个角点的 `Z` 差了 115 mm。所以「物体距离 500 mm」永远是个近似说法。
2. **近的角点像素间距更大**：`(-50,-50,-50)` 和 `(-50,-50,50)` 世界距离 100 mm，像素距离 `√(75.37² + 40.66²) ≈ 85.7 px`；而同样 100 mm 的横向长度在 `Z=500` 处约 `464 px`——这就是透视缩短。

### 4.2 反投影（2D → 一条射线）

```
像素 (900, 400) -> 射线方向 (0.1123, -0.0481, 1)

沿射线走 Z = 500 mm  -> 点 (56.17, -24.04, 500)  再投影回 (900.0, 400.0)
沿射线走 Z = 1000 mm -> 点 (112.34, -48.08, 1000) 再投影回 (900.0, 400.0)
```

**同一条射线上的所有点，投影到同一个像素。** 所以：

```
像素 + 内参  =>  射线        （方向唯一）
像素 + 内参  =>  3D 点       （❌ 不可能，缺一个数）
```

缺的那个数是**深度**。补深度只有三条路：

| 方法 | 补的是什么 | 代价 |
|---|---|---|
| 已知平面（工件台面、传送带） | 假设 `Z` 已知 | 只能测平面上的东西 |
| 双目 / 结构光 | 用第二个视角三角化 | 多一个相机或投影器 |
| 激光 / 雷达 | 直接测距 | 多一个传感器，要标外参 |

这就是「单目不能测距」的准确说法：**单目能算出方向，不能算出距离**；只要你能给一个约束（平面、已知尺寸、多视角），单目照样能测。

### 4.3 反投影的一致性检查（代码里做了）

把投影得到的像素再反投影，应该和「3D 点直接除以 Z」完全一致：

```
反投影射线 vs 真实方向 最大差 = 3.47e-17
```

这个 `1e-17` 是浮点的舍入量级。凡是「投影—反投影」往返，误差都应该在这个量级；如果出现 `1e-3`，多半是单位错了（mm 当 m）或 K 用反了。

## 5. 精度从哪来：`mm/px = Z / fx`

这是本篇最该背下来的一行：

```
一个像素代表多少毫米 = 深度 / 像素焦距
```

同一台相机（`fx = 2318.84`）：

| 深度 Z | mm/px | 100 mm 的物体占多少像素 |
|---|---|---|
| 300 mm | 0.129 | 772.9 |
| 500 mm | 0.216 | 463.8 |
| 1000 mm | 0.431 | 231.9 |
| 2000 mm | 0.863 | 115.9 |

三条推论，全是工程决策：

1. **距离翻倍，精度减半**（线性）。所以「能靠近就靠近」是最便宜的精度提升。
2. **`fx` 越大越细**：长焦（`f` 大）或小像元（`dx` 小）都能提高 `fx`。手机用 1.0 µm 像元 + 4 mm 镜头，`fx ≈ 4000 px`，所以小目标也能拍得很大。
3. **亚像素是廉价的精度**：`0.1 px` 的亚像素定位，在 500 mm 处相当于 `0.0216 mm`——比换镜头便宜得多。

回到开头的任务：2 mm 的孔在 500 mm 处约 `2/0.216 ≈ 9.3 px`。要测到 0.05 mm，需要约 `0.05/0.216 ≈ 0.23 px` 的边缘精度——**必须做亚像素**，这也是工业视觉里 Canny 之后还要拟合圆/直线的原因。

## 6. resize 与 crop：K 必须跟着改

这一节看着琐碎，但它是「同一套代码换个分辨率就测不准」的头号原因。

### 6.1 缩放 `s` 倍

```
fx' = s · fx
fy' = s · fy
cx' = s · cx
cy' = s · cy
```

代码验证（缩到一半）：

```
原图投影前 2 点 : [381.851, 253.851], [428.696, 300.696]
半尺寸 K 投影   : [190.926, 126.926], [214.348, 150.348]
是否等于原坐标的一半: True
```

### 6.2 裁剪 ROI（左上角裁掉 `x0, y0`）

```
fx' = fx          （焦距不变）
fy' = fy
cx' = cx − x0     （原点平移）
cy' = cy − y0
```

验证：裁掉 `(100, 50)` 后，所有点的像素坐标整体减 `(100, 50)`，误差为 0。

### 6.3 一个容易忽略的细节

`cv2.resize` 和 `PIL.resize` 的像素中心约定略有差别（半像素问题），在**大比例缩放 + 亚像素测量**时会差 0.5 px 左右。工程做法：要么用同一套库做缩放并标定一次，要么干脆不缩放——先裁 ROI 再处理。

## 8. 自测

**Q1**：写出针孔模型的完整链条（世界 → 像素四个坐标系），并说明每一步由谁提供参数。

**Q2**：8 mm 镜头、3.45 µm 像元，`fx` 是多少？如果换成 5.5 µm 像元呢？镜头变了吗？

**Q3**：`(900, 400)` 这个像素，能唯一确定一个 3D 点吗？如果不能，缺什么？

**Q4**：图像从 1280×1024 裁成了 400×300（左上角从 `(200, 100)` 开始），`cx, cy` 变成多少？

**Q5**：判断对错并说明原因：「主点就是图像正中心，所以可以写死成 `(W/2, H/2)`。」

**Q6**（换场景）：同一条产线，相机从 500 mm 挪到 1000 mm。同样是 2 mm 的孔，边缘定位误差 `0.2 px` 会变成多少毫米？误差翻了几倍？

### 答案

**A1**：世界 `(mm)` →（外参 `R,t`）→ 相机 `(mm)` →（除以 `Z`，无参数）→ 归一化坐标 `(无量纲)` →（内参 `K`）→ 像素 `(px)`。外参来自标定/PnP/手眼；内参来自张正友标定；中间那步是纯几何。

**A2**：`fx = 8/0.00345 = 2318.84 px`；换成 5.5 µm 后 `fx = 8/0.0055 = 1454.5 px`。镜头没变，但**像元变大 → 同样焦距覆盖的像素变少 → `fx` 变小 → `mm/px` 变大**（精度变差）。

**A3**：不能。像素只给出**方向**（一条射线），缺深度。补深度的方式：已知平面、双目/结构光、激光测距。

**A4**：`fx` 不变，`cx = 639.5 − 200 = 439.5`，`cy = 511.5 − 100 = 411.5`。如果同时 `resize`，先减偏移再乘缩放（顺序不能反）。

**A5**：错。主点是「光轴与像面的交点」，由装配决定，偏几到几十像素都正常。写死成中心会让重投影误差出现系统性偏移，长焦下换算成毫米就是零点几毫米的误差。标定必须估 `cx, cy`。

**A6**：`0.2 px × 0.431 mm/px ≈ 0.086 mm`；原来 `0.2 px × 0.216 ≈ 0.043 mm`。误差翻 2 倍（线性）。要保住精度，要么靠近、要么换长焦、要么提高亚像素精度。

## 9. 面试题纲

> **怎么用**：★ 秒答；★★ 讲满 2 分钟、带因果链；★★★ 画图 + trade-off。第一遍只要求 ★ 全过，讲不出来的记进 §12 未懂清单。
> **题量规则**：`n = 1 主干 + 对比 + 坑 + 手算`，封顶 12。本篇 `1 + 2 + 3 + 3 = 9`。
> **脉络**：一条链条 → 两组参数 → 三个坑 → 三个手算。

### 9.1 主干（1 题）

**Q1. 给你一个像素坐标，你怎么把它变成毫米？** ★

**一句话**：先乘 `K⁻¹` 得到射线方向，再乘深度——**没有深度就出不了毫米**。

**讲开**：

- 链条是四层：世界 →（外参）→ 相机 →（除 Z）→ 归一化 →（内参）→ 像素。
- 反向只有两步能确定：`K⁻¹` 给出方向；深度 `Z` 必须从外部来（平面/双目/激光）。
- 一旦有了 `Z`，一个像素对应的物理尺寸就是 `Z/fx`。
- 所以面试答题的顺序必须是「方向 → 深度 → 毫米」，顺序反了就是没理解单目。

**数字锚点**：`fx = 2318.84 px`，`Z = 500 mm` 时 `1 px = 0.216 mm`，`Z = 1000 mm` 时 `0.431 mm`。

**追问**：「如果只想知道两个像素之间的实际距离呢？」→ 同一个深度平面上，乘 `Z/fx` 即可；跨深度就必须知道两点的 `Z`。

### 9.2 两组参数（2 题）

**Q2. 内参和外参分别是什么？谁在什么情况下会变？** ★

**一句话**：内参是相机自己的换算表（换镜头/改分辨率才变），外参是相机在世界里的位姿（一动就变）。

**讲开**：

- 内参 `K`：`fx, fy, cx, cy`，把归一化坐标变成像素。
- 外参 `R, t`：把世界坐标搬到相机坐标；`R` 是朝向、`t` 是位置。
- **内参与拍什么无关**，所以标一次可以一直用（除非改焦距/对焦/分辨率/裁剪）。
- **外参随安装变化**，相机被碰一下、支架热变形、机器人换工位，都要重标。

**数字锚点**：同一支 8 mm 镜头，3.45 µm 像元 → `fx = 2318.84`；5.5 µm → `fx = 1454.5`。镜头没动，内参变了。

**追问**：「标内参需要知道外参吗？」→ 不需要；张正友标定里每个姿态的外参是**副产品**，一起解出来。

**Q3. 归一化坐标和像素坐标，为什么要有两套？** ★

**一句话**：归一化坐标只跟几何有关，像素坐标才跟相机型号有关；算法在归一化系里写，才能跨相机复用。

**讲开**：

- `x_n = X/Z, y_n = Y/Z`，无量纲（本质上是一个 tan 值）。
- 像素 = `K · [x_n, 1]`，所以 `K` 是「归一化 → 像素」的唯一桥梁。
- PnP、对极几何、三角化都在归一化坐标里推导，最后才乘各自的内参——这样公式里没有 `fx, cx`。
- 调试技巧：把重投影误差除以 `fx`，就得到「角度误差」，可以跨镜头比较。

**数字锚点**：像素 `(900, 400)` → 归一化 `((900−639.5)/2318.84, (400−511.5)/2318.84) = (0.1123, −0.0481)`，正好是反投影射线的方向。

**追问**：「归一化坐标和『角度』什么关系？」→ `x_n = tan(θ_x)`，小角度下近似等于弧度，所以除以 `fx` 就是角度误差。

### 9.3 三个坑（3 题）

**Q4. 图像 `resize` 或 `crop` 之后，内参怎么改？不改会怎样？** ★★

**一句话**：缩放四个参数全乘 `s`；裁剪只减 `cx, cy`。不改就是「图变了、参数没变」。

**讲开**：

- `resize(s)`：`fx, fy, cx, cy` 全乘 `s`。
- `crop(x0, y0)`：`fx, fy` 不变，`cx − x0`、`cy − y0`。
- 不改的后果不是「图错」，而是**所有测量系统性偏**：重投影整体缩放或平移，看起来「算法不准」，其实是参数没跟上。
- 深度学习同样中招：训练用原图、推理用 `resize` 后的图，特征尺度全变。

**数字锚点**：投影点 `381.851` 在减半图上应为 `190.926`（恰好一半）；裁掉 `(100, 50)` 后偏移恰好 `(100, 50)`，误差为 0。

**追问**：「先 `resize` 再 `crop`，顺序能换吗？」→ 结果一样，但参数更新顺序要跟着走：先乘 `s` 再减 `x0·s`，算错顺序就错位。

**Q5. 为什么单目相机不能直接测距？** ★★

**一句话**：投影时把 `Z` 除掉了，这个信息不可逆；反过来只能得到一条射线。

**讲开**：

- `u = fx·X/Z + cx` 里，`X` 和 `Z` 以比值出现——只知道比值，不知道各自大小。
- 所以像素 + 内参 = 射线；射线上的每个点都投影到同一个像素（实测 Z=500 和 Z=1000 都回落到 `(900,400)`）。
- 补深度三条路：已知平面、双目/结构光三角化、激光测距。
- 「单目不能测距」的严格说法是：**单目不能只凭一张图测距**；给了约束就能测。

**数字锚点**：反投影方向 `(0.1123, −0.0481, 1)`，`Z=500` 和 `Z=1000` 投影回来都是 `(900.0, 400.0)`。

**追问**：「那单目 SLAM 怎么工作的？」→ 靠**运动**制造视差（等价于双目），或者靠已知尺寸的物体/平面。

**Q6. 主点为什么默认不在图像正中心？写死成中心会怎样？** ★★

**一句话**：主点是光轴与像面的交点，由装配决定；写死会让结果系统性平移几个像素。

**讲开**：

- 镜头和传感器装配有公差，光轴很少正好穿过像素阵列中心；偏几像素很常见，广角/大靶面能偏几十像素。
- 标定估 `cx, cy` 的价值就在这：它把「装配误差」变成一个可补偿的参数。
- 写死成 `(W−1)/2` 的后果：所有点整体偏 `Δc`，重投影误差呈现**系统性方向性**（不是随机噪声）。
- 怎么发现：看重投影误差的**均值**是否显著不为 0——这就是标定质量评价里的「残差分布」检查。

**数字锚点**：本例 `(639.5, 511.5)`；若真实主点偏 10 px，在 500 mm 处相当于 `10 × 0.216 ≈ 2.16 mm` 的系统误差。

**追问**：「标定出来的主点离中心很远，说明什么？」→ 要么装配真有问题，要么标定数据姿态不够（主点和焦距强耦合，姿态单一时分不开）。

### 9.4 三个手算（3 题）

**Q7. 8 mm 镜头、3.45 µm 像元、1280×1024，求 `fx`、FOV、500 mm 处一个像素多少毫米。** ★

**一句话**：`fx = 2318.84 px`，FOV 约 `30.86°`，`0.216 mm/px`。

**讲开**：

- `fx = f/dx = 8 / 0.00345`。**单位换算只在这一步**：µm 先变 mm。
- 传感器宽度 `1280 × 0.00345 = 4.416 mm`；`FOV = 2·atan(4.416/(2×8)) = 30.86°`。
- `mm/px = Z/fx = 500/2318.84 = 0.216`。
- 反过来：`fx` 越大，FOV 越小、`mm/px` 越小——这就是「长焦看得细但看得窄」。

**数字锚点**：`fx = 2318.84`、FOV `30.86° / 24.90°`、`0.216 mm/px`、100 mm 的物体占 `463.8 px`。

**追问**：「想要 0.1 mm/px，怎么办？」→ 要么把 `Z` 降到 `232 mm`，要么把 `fx` 提到 `5000 px`（换长焦或更小像元）。

**Q8. 同一个相机，为什么 2 m 处测不准？** ★★

**一句话**：`mm/px` 随距离线性变大，2 m 处一个像素就是 0.86 mm。

**讲开**：

- `mm/px = Z/fx`：300 mm 处 `0.129`，2000 mm 处 `0.863`，差 6.7 倍。
- 边缘定位误差是「像素级」的，乘以 `mm/px` 才是毫米级；所以误差也随距离线性放大。
- 距离还带来另外两个问题：目标变小（同样 100 mm 只占 116 px）、景深变大（对焦更松）。
- 改善顺序（按性价比）：靠近 > 换长焦 > 提高分辨率 > 亚像素算法。

**数字锚点**：`0.2 px` 的边缘误差，在 500 mm 处 `0.043 mm`，在 1000 mm 处 `0.086 mm`——翻倍。

**追问**：「那为什么不用长焦一步到位？」→ FOV 变窄，装不下大工件；而且景深变浅，对安装精度要求更高。

**Q9. 精度、视场、工作距离，怎么权衡？** ★★★

**一句话**：三者由 `fx` 和 `Z` 绑死——`视场 ≈ 像素数 × Z/fx`，`精度 ≈ Z/fx`，你只能选两个。

**讲开**：

- 固定 `Z`：`fx` 大 → FOV 小、精度好；`fx` 小 → FOV 大、精度差。
- 固定 `fx`：`Z` 大 → FOV 大、精度差（线性变粗）。
- 像素数决定上限：`FOV/分辨率 = mm/px`，所以「加分辨率」和「加焦距」在几何上等价，但代价不同（带宽 vs 视场）。
- 工程上的标准做法：先用「目标尺寸 + 精度要求」反推 `mm/px`，再定 `Z` 和 `f`，最后选分辨率留 2~3 倍余量。

**数字锚点**：要测 2 mm 的孔到 `0.05 mm`，需要 `mm/px ≲ 0.05`；`fx = 2318.84` 时对应 `Z ≲ 116 mm`，或者换 `fx ≈ 10000 px` 的镜头。

**追问**：「为什么留 2~3 倍余量？」→ 边缘不是理想阶跃、亚像素有偏差、工件有高度公差；余量用来吸收这些误差，不然一次波动就超差。

## 10. 坑清单

| # | 坑 | 症状 | 处理 |
|---|---|---|---|
| 1 | 把 `fx` 当成物理焦距 | 单位错、量级差 1000 倍 | 记住 `fx = f/dx`，单位是**像素** |
| 2 | 忘记除以 `Z` | 点越远越偏，图整体外扩 | 投影前先算 `Z`，并检查 `Z > 0` |
| 3 | 相机背后的点也投影 | 镜像的鬼影 | `Z <= 0` 直接丢弃 |
| 4 | `resize`/`crop` 后不改 K | 系统性的缩放/平移误差 | 按 §6 更新 `fx, fy, cx, cy` |
| 5 | 主点写死成图像中心 | 残差均值不为 0 | 标定估 `cx, cy` |
| 6 | 把 `Z` 当「到物体的距离」 | 斜视时距离 > Z，精度估错 | `Z` 是光轴方向分量，不是欧氏距离 |
| 7 | mm / m 混用 | 结果差 1000 倍 | 全流程统一 mm |
| 8 | 反投影当成「3D 重建」 | 以为拿到了坐标 | 反投影只给射线，深度要另找 |
