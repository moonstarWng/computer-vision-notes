# M5 2D 检测与图像处理

> **目标**：能讲清 YOLO 这条线的三次主线演进，并独立训练、评估、导出一次检测模型。
> **前置**：S0（卷积/滤波）、S3（CNN 与训练套路）。
> **建议用时**：3 周 / 约 30 h。
> **学完能做什么**：自建小数据集训练检测模型，报出 mAP 与耗时，并解释涨点来自哪。

## 核心概念（要能自己默写）

- 卷积、感受野、步长/空洞、BN 的作用与训练/推理差异。
- 经典图像处理：均值/高斯/中值/双边/引导滤波各自适合什么噪声；直方图均衡；Canny 四步。
- YOLO 主线：v3 多尺度+FPN → v4 CSP/Mosaic/CIoU → v8 anchor-free + C2f + DFL + TAL → v11 C3k2 + C2PSA。
- 标签分配：从 anchor/IoU 阈值 → **TAL**（t = s^α·u^β 选 top-k），解决分类与定位质量不一致。
- DFL：把边界距离回归变成 [0, reg_max] 上的离散分布取期望。
- IoU 损失族：GIoU（闭包面积）→ DIoU（中心距）→ CIoU（长宽比）→ EIoU（宽高解耦）。
- NMS 家族：NMS / Soft-NMS / DIoU-NMS / Cluster-NMS；3D 上为何常用 BEV NMS。
- 特征点：SIFT（DoG + 128 维，尺度旋转不变，慢）vs ORB（FAST + BRIEF，快，尺度弱）。
- 小波 vs 傅里叶：时频局部化；DWT 用于去噪/边缘/条纹抑制/融合。
- 类别不平衡：Focal / OHEM / 重采样 / copy-paste / 分类阈值。
