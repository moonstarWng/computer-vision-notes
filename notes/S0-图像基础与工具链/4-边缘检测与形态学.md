# 4 边缘检测与形态学：从「粗边」到「能用的轮廓」

> **S0 图像基础与工具链 · 第 4 篇**
>
> **为什么学这篇**：工业视觉里「测量」的前提是「找到边界」。阈值受光照影响大，而边缘对光照变化更稳；形态学则负责把边缘/阈值结果清理成能测量的对象。

## 0. 开始之前：任务与名词

### 0.1 任务：量一个零件的宽度

场景：冲压件放在背光台上，你要量它的宽度，精度 ±0.05 mm。

**痛点**：

- 直接阈值：边缘随光照漂移半个像素，换算成 mm 就超差。
- 边缘检测：Sobel 出来的边有 3~5 像素宽，取哪一列？
- 噪声：阈值后一堆白点，连通域数出来几十个「零件」。

**本篇解决哪一步**：把「边缘」从「响应强的地方」变成「单像素、连续、可定位的轮廓」，再用形态学和连通域筛出真正的目标。

### 0.2 名词卡片

**边缘（edge）**
- 一句话：灰度发生明显突变的位置。
- 不是：不是「物体轮廓」；纹理、划痕、阴影也有边缘。

**梯度（gradient）**
- 一句话：灰度变化最快的方向和速率。
- 向量：`(Gx, Gy)`；幅值 `|G|`，方向 `θ=atan2(Gy,Gx)`。
- 单位：灰度/像素。

**非极大值抑制（Non-Maximum Suppression，NMS）**
- 一句话：沿梯度方向只保留局部最大值，把粗边压成单像素。
- 注意：NMS 比较的是**梯度方向**（垂直边缘），不是边缘走向。

**双阈值（double threshold）**
- 一句话：高阈值定「强边缘」，低阈值定「弱边缘」。
- 作用：强边可信，弱边待定。

**滞后（hysteresis）**
- 一句话：只有和强边缘连通的弱边缘才保留。
- 效果：去掉孤立噪声，接上断掉的边缘。

**Canny 边缘检测**
- 一句话：高斯模糊 → 梯度 → NMS → 双阈值 → 滞后的五步流程。
- 不是：不是单个算子，是一套流水线。

**形态学（morphology）**
- 一句话：用一个小结构元在二值图上做「集合运算」。
- 四个基本操作：腐蚀、膨胀、开、闭。

**结构元（structuring element，SE）**
- 一句话：形态学的「核」，定义邻域形状。
- 常见：3×3 方形、十字、圆盘、水平/垂直线。

**腐蚀 / 膨胀（erosion / dilation）**
- 腐蚀：窗口内**全为 1** 才保留 → 前景缩小。
- 膨胀：窗口内**有 1** 就置 1 → 前景扩大。

**开 / 闭（opening / closing）**
- 开 = 先腐蚀后膨胀 → 去小噪点、断开细连接。
- 闭 = 先膨胀后腐蚀 → 填小孔、接小缝。

**连通域（connected component）**
- 一句话：二值图里互相连通的像素集合。
- 4 连通：只看上下左右；8 连通：斜着也算。

## 1. 边缘是什么：一阶导数的峰值

### 1.1 一维看最清楚

一条竖直边缘，灰度从 50 突变到 200：

```
灰度:  50 50 50 | 200 200 200
一阶导:  0  0 150 | 150  0  0     ← 边缘处最大
```

所以「找边缘」= 「找一阶导数的局部最大值」。

**但导数会放大噪声**：噪声 ±5，相邻差分就是 ±10，可能比弱边缘还大。所以几乎所有边缘算子都**先平滑再求导**。

### 1.2 二维：梯度

```
Gx = ∂I/∂x      （左右变化）
Gy = ∂I/∂y      （上下变化）
|G| = sqrt(Gx² + Gy²)
θ   = atan2(Gy, Gx)
```

- `|G|` 大：这里是边缘。
- `θ`：灰度增长最快的方向，**垂直穿过边缘**。

## 2. 梯度算子

### 2.1 Sobel 的拆解

```
Gx = [[-1, 0, 1],      Gy = [[-1, -2, -1],
      [-2, 0, 2],            [ 0,  0,  0],
      [-1, 0, 1]]            [ 1,  2,  1]]
```

`Gx` 可以拆成：

```
Gx = [1, 2, 1]ᵀ ⊗ [-1, 0, 1]
     └ 纵向平滑 ┘  └ 横向差分 ┘
```

**为什么中间是 2**：平滑权重 `[1,2,1]` 近似高斯，比 Prewitt 的 `[1,1,1]` 更抗噪；同时差分保持一阶。

**Scharr** 是它的加强版：

```
Gx = [[-3, 0, 3],
      [-10, 0, 10],
      [-3, 0, 3]]
```

旋转对称性更好，OpenCV 在 3×3 时推荐 Scharr。

### 2.2 真实响应

x=120 处竖直阶跃（左 50，右 200），Sobel 幅值：

```
竖直阶跃在 x=120；内部 Sobel 幅值峰值在 x=119，峰值=600.0
理论上限 = 4×150 = 600（核系数绝对值之和 × 阶跃高度）
边界处的假边缘：x=0 -> 200，x=239 -> 800
（真实阶跃只有 150，补零却造出了 200/800 的梯度）
```

**两个结论**：

1. 峰值 600 = `(1+2+1) × 150`，和理论一致。
2. 边界补零造出 800 的假边缘，比真边缘还强 —— **边缘检测前必须处理边界**。

### 2.3 Laplacian：二阶导

```
∇² = [[0, 1, 0],
      [1, -4, 1],
      [0, 1, 0]]
```

- 对噪声更敏感（二阶导放大高频）。
- 不提供方向。
- 过零点（zero-crossing）对应边缘，但需要额外判断。

**锐化**：

```
sharp = original + α·(original − blur)
```

`original − blur` 是「高频细节」，近似 Laplacian。`α` 控制锐化强度，太大会出现白边（halo）。

## 3. NMS：把粗边压成单像素

### 3.1 问题

Sobel 的边缘有 3~5 像素宽：一个阶跃会在好几个位置都有响应。测量时不知道取哪一列。

### 3.2 做法

对每个像素，沿**梯度方向**比较前后两个邻居：

```
如果自己是局部最大 → 保留
否则 → 置 0
```

梯度方向先量化成 4 个箱子（因为只有 8 个邻居）：

| 方向 | 比较的邻居 |
|---|---|
| 0° | 左 / 右 |
| 45° | 左上 / 右下 |
| 90° | 上 / 下 |
| 135° | 右上 / 左下 |

**注意**：方向是「梯度方向」（垂直边缘），不是「边缘走向」。竖直边缘的梯度方向是水平的，所以比较左右邻居 —— 正好把水平方向的粗边压成一个点。

### 3.3 真实效果

```
Sobel 幅值 >30 的像素 : 7765
NMS 后 >30 的像素     : 1926 （压缩到 24.8%）
```

压掉了 75%，剩下的基本是单像素脊线。

**坑**：如果相邻两个像素值完全相等（平台），`>=` 会都保留，边缘仍然是 2 像素。工业上可以加「只保留一侧」的 tie-break，或用亚像素插值。

## 4. 双阈值 + 滞后：去噪又接边

### 4.1 规则

```
强边缘：|G| ≥ high        → 一定是边缘
弱边缘：low ≤ |G| < high  → 待定
规则：只有和强边缘 8 连通的弱边缘才保留
```

### 4.2 为什么有效

```
噪声点：孤立的，不连强边缘 → 丢掉
真边缘：中间可能衰减到弱，但两端连着强 → 整条保留
```

这就是「滞后（hysteresis）」：阈值的历史（是否连到强边）决定当前保留与否。

### 4.3 真实数字

```
阈值 low=30 / high=150（梯度幅值）
Sobel 幅值 >30 的像素 : 7765
NMS 后 >30 的像素     : 1926 （压缩到 24.8%）
强边缘像素            : 1671
弱边缘连通块数        : 5
滞后后最终边缘像素    : 1753 （是强边缘的 1.05 倍）
边缘占全图比例        : 4.06%
```

**怎么读**：

- 强边缘 1671，最终 1753，滞后只补了 82 个弱像素（5%），说明这张图对比度高，大部分边缘已经很强。
- 如果图像对比度低，`final/strong` 会明显大于 1，滞后就是「接断边」的关键。
- 弱边缘只有 5 个连通块，说明噪声少；噪声多时这个数会很大，滞后会把它们滤掉。

### 4.4 阈值怎么选

经验：

```
high : low = 2 : 1 或 3 : 1
high 取在「明显边缘」的梯度分位数上（如 90%）
low  取 high 的 1/2 ~ 1/3
```

**调参方法**：固定 `high`，逐步降 `low`，看边缘是否开始「爬」到背景上；一旦背景出现细碎边缘，就回调。

## 5. Canny 五步总结

```
1. 高斯模糊        σ=1~2        降噪，防止梯度全是噪点
2. Sobel 梯度      k=3          幅值 + 方向
3. NMS             4 方向       粗边 → 单像素
4. 双阈值          low/high     分强/弱
5. 滞后            8 连通       弱边连强边才保留
```

**每一步去掉什么**：

| 步骤 | 去掉 | 代价 |
|---|---|---|
| 高斯 | 高频噪声 | 弱边缘也被模糊 |
| NMS | 冗余的粗边 | 平台处可能留 2 像素 |
| 双阈值 | 弱噪声 | 弱边缘丢失 |
| 滞后 | 孤立弱边 | 断边可能接不上 |

**参数影响**：

- `σ` 大：噪声少，但边缘位置偏移、细边消失。
- `high` 大：只留强边，可能断。
- `low` 小：接得多，但可能连到噪声。

## 6. 形态学：二值图的「修形工具」

### 6.1 定义

设 `A` 是前景集合，`B` 是结构元：

```
腐蚀： (A ⊖ B)(x) = {x | B 平移到 x 后，完全落在 A 内}
膨胀： (A ⊕ B)(x) = {x | B 平移到 x 后，与 A 有交集}
开：   A ∘ B = (A ⊖ B) ⊕ B
闭：   A • B = (A ⊕ B) ⊖ B
```

**直觉**：

- 腐蚀：把前景「削一圈」，小点直接消失。
- 膨胀：把前景「长一圈」，小孔被填上。
- 开：先削后长 → 小噪点没了，大形状基本不变。
- 闭：先长后削 → 小孔/小缝没了，大形状基本不变。

### 6.2 真实效果

```
手写腐蚀/膨胀与 scipy 完全一致
噪声图白像素   : 11913
开运算后白像素 : 11817 （去掉孤立噪点）
闭运算后白像素 : 11876 （补回小孔，+59 像素）
真值白像素     : 11932
```

图 ⑤~⑦ 展示了过程：

- ⑤ 二值图里有大量孤立白点（椒盐噪声）和一个内部小孔。
- ⑥ 开运算（3×3）把孤立白点全部去掉，主体形状基本不变。
- ⑦ 闭运算（7×7）把小孔补上，白像素 +59。

**为什么闭运算用 7×7 而开运算用 3×3**：

- 噪声点是 1~2 像素，3×3 足够去掉。
- 孔直径约 6 像素，需要 7×7 才能填满。
- **结构元必须大于要处理的缺陷，小于要保留的结构**。

### 6.3 四个操作的用途

| 操作 | 用途 | 例子 |
|---|---|---|
| 腐蚀 | 去小噪点、断开细连接、细化 | 分离粘连零件 |
| 膨胀 | 填小孔、接断缝、加粗 | 连接断裂的划痕 |
| 开 | 去噪点、去掉毛刺 | 阈值后的清理 |
| 闭 | 填孔、接缝 | 补上反光造成的空洞 |
| 开→闭 | 先清噪点再补孔 | 最常用的组合 |
| 闭→开 | 先补孔再清噪点 | 孔多、噪点少时 |

**注意**：形态学**会改变尺寸**。腐蚀让目标变小、膨胀让目标变大。如果要做尺寸测量，要么先测量再形态学，要么用「开/闭」这种尺寸基本不变的组合，并标定偏差。

## 7. 连通域：从像素到对象

### 7.1 标记

```python
lab, n = label(binary, structure=np.ones((3, 3)))   # 8 连通
```

- `lab`：和原图同尺寸，每个像素的值是「第几个对象」。
- `n`：对象个数。
- `structure`：`3×3` 全 1 是 8 连通；十字是 4 连通。

### 7.2 真实数字

```
噪声图：92 个连通块，面积≥20 的有 1 个，最大面积 11822
开运算后：1 个连通块，面积≥20 的有 1 个，最大面积 11829

按面积排序（前 3）：
  #1 面积=11829 bbox=(y36:128, x41:198) 质心=(109.8, 83.4)
```

**怎么读**：

- 噪声图有 92 个连通块，但面积 ≥20 的只有 1 个 → 其余 91 个是噪点。
- 开运算后只剩 1 个块，说明形态学已经把噪点清干净。
- `bbox` 和质心是后续测量（宽度、位置、角度）的输入。

### 7.3 面积过滤

```python
areas = np.bincount(lab.ravel())
keep = areas >= min_area
clean = keep[lab]
```

**`min_area` 怎么定**：

- 小于「最小真实缺陷」的面积 → 噪点。
- 大于「最大噪点」的面积 → 目标。
- 两者之间取一个值，最好用一批图统计分布，而不是拍脑袋。

**坑**：8 连通会让斜对角的两块连成一个，4 连通不会。做细线/网格时，连通性的选择会改变对象个数。

## 9. 自测

**Q1**：Sobel 的 `Gx` 为什么中间一行是 `[-2, 0, 2]` 而不是 `[-1, 0, 1]`？

**Q2**：NMS 沿哪个方向比较？竖直边缘的梯度方向是什么？

**Q3**：为什么 Canny 要两个阈值，而不是一个？

**Q4**：判断对错并说明原因：「开运算和闭运算都不会改变目标的面积。」

**Q5**：二值图里有 50 个白点，面积都是 3~5 像素，还有一个 5000 像素的零件。怎么最快筛出零件？

**Q6**（换场景）：点云分割出地面后，怎么用「形态学」的思路去掉孤立的噪声点？

### 答案

**A1**：`[-2,0,2]` 等于 `[1,2,1]ᵀ ⊗ [-1,0,1]`，纵向多了一次 `[1,2,1]` 平滑，比 `[-1,0,1]` 更抗噪。这也是 Sobel 比 Prewitt 常用的原因。

**A2**：沿**梯度方向**比较。竖直边缘的灰度在水平方向变化，所以梯度方向是水平的（0°），NMS 比较左右邻居。

**A3**：一个阈值无法同时满足「去掉噪声」和「保留弱边」。双阈值把「确定是边」和「可能是边」分开，再用连通性决定弱边的去留。

**A4**：错。开运算会去掉小凸起/小噪点，闭运算会填小孔，两者都会改变面积（本例开运算少了 96 像素，闭运算多了 59 像素）；只是对「大于结构元」的结构影响很小。

**A5**：直接 `label` + 面积过滤（`areas >= 20`），不需要形态学。面积过滤是 `O(N)`，比开运算更快，也不会改变零件形状。

**A6**：对点云做「半径离群点去除」（统计每个点的 k 近邻平均距离，超过阈值就删），本质是形态学开运算的连续版本；或者体素化后用 3D 形态学。

### 10.1 主干（1 题）

**Q1. 边缘到底是什么？为什么几乎所有边缘算子都要先平滑？** ★

**一句话**：边缘是灰度的一阶导数峰值；而导数会放大噪声，所以先平滑再求导。

**讲开**：

- 灰度从 50 突变到 200，一阶差分在跨越处出现 `150` 的峰——找边缘就是找这个峰。
- 噪声 ±5，相邻差分就是 ±10，可能比弱边缘还大，所以裸求导等于放大噪声。
- 二维用梯度 `|G| = √(Gx²+Gy²)` 和方向 `θ = atan2(Gy,Gx)`；**方向垂直于边缘**。
- 工程上「先平滑再求导」有现成写法：Sobel 的 `[1,2,1]` 就是内置的一次平滑。

**数字锚点**：`50 → 200` 的阶跃，一阶差分峰值 150；Sobel 输出峰值 `600 = (1+2+1)×150`，出现在跨越边界的 `x=119`。

**追问**：「为什么峰值不在灰度最高的地方？」→ 导数看的是**变化率**，不是绝对值；变化最剧烈的位置在边界两侧之间。

### 10.2 Canny 流水线与阈值（4 题）

**Q2. Canny 五个步骤分别去掉什么？** ★

**一句话**：高斯去噪 → Sobel 求梯度 → NMS 压细 → 双阈值分类 → 滞后接边。

**讲开**：

- **高斯**（σ=1~2）去高频噪声，代价是弱边缘也被模糊。
- **Sobel** 给幅值+方向；**NMS** 沿梯度方向只留局部最大，把 3~5 像素的粗边压成单像素。
- **双阈值**把「确定是边」和「可能是边」分开：强边必留、弱边待定。
- **滞后**用 8 连通判断：连到强边的弱边保留，孤立的扔掉——这一步同时完成「去噪」和「接断边」。

**数字锚点**：本篇 `7765 → 1926 → 1671 → 1753` 个像素，最终边缘占全图 **4.06%**。

**追问**：「哪一步最容易调坏？」→ NMS 的方向（见 Q3）和双阈值的比例（见 Q4），两者都表现为「边缘断了或者满地噪点」。

**Q3. NMS 沿哪个方向比较？为什么不是「边缘方向」？** ★★

**一句话**：沿**梯度方向**比较——梯度垂直于边缘，这样才能把垂直于边缘的粗边压掉。

**讲开**：

- 竖直边缘的灰度在水平方向变化，所以梯度方向是水平的，NMS 比较左右邻居。
- 如果错用「边缘方向」（竖直），就会沿着边缘比较，粗边压不细、甚至把边压断。
- 实际实现把方向量化成 4 个箱子（0°/45°/90°/135°），因为只有 8 个邻居。
- 坑：相邻像素完全相等（平台）时 `>=` 会都保留，边缘仍是 2 像素；工业上要 tie-break 或亚像素插值。

**数字锚点**：NMS 把 `>30` 的像素从 7765 压到 1926（**24.8%**），压掉约 75%。

**追问**：「为什么不做 8 方向？」→ 8 邻居只提供 4 组对称邻居，更多方向没有像素可比较，只能靠插值。

**Q4. 为什么 Canny 要两个阈值，而不是一个？** ★

**一句话**：一个阈值无法同时满足「去掉噪声」和「保住弱边」，双阈值把「确定」和「可能」分开。

**讲开**：

- 单阈值调高：噪声干净了，但弱边断裂；调低：边接上了，噪声也全进来。
- 双阈值把像素分成三类：强边（必留）、弱边（待定）、背景（扔掉）。
- 滞后规则只保留「和强边 8 连通」的弱边——**连通性就是「这条弱边属于某条真边缘」的证据**。
- 参数经验：`high : low = 2:1 ~ 3:1`；`high` 取明显边缘的梯度分位数（如 90%），`low` 取它的 1/2~1/3。

**数字锚点**：`low=30/high=150`：强边 1671，滞后后 1753（**1.05 倍**，只补了 82 个弱像素）；弱边连通块只有 5 个——说明这张图噪声少。

**追问**：「如果对比度低，`final/strong` 会怎样？」→ 明显大于 1，滞后就是「接断边」的关键；反过来噪声多时连通块数暴涨，它们会被滞后滤掉。

### 10.3 四种「修形」手段（4 题）

**Q5. 开运算和闭运算分别解决什么问题？** ★★

**一句话**：开 = 先腐蚀后膨胀（去小噪点、去毛刺）；闭 = 先膨胀后腐蚀（填小孔、接小缝）。

**讲开**：

- 腐蚀要求结构元**完全落在**前景内，所以小点直接消失；膨胀只要有交集，所以小孔被填。
- 组合后「大形状基本不变」：开去掉小于结构元的凸起，闭填上小于结构元的凹陷。
- 顺序不能反：先开再闭 = 先清噪点再补孔，是最常用的组合；孔多噪点少时可以闭→开。
- 关键约束：**结构元要大于缺陷、小于要保留的目标**。

**数字锚点**：噪声图白像素 11913 → 开运算 11817（**去掉 96**）→ 闭运算 11876（**补回 59**）；真值 11932。

**追问**：「为什么开运算用 3×3、闭运算用 7×7？」→ 噪点 1~2 像素，3×3 足够；孔直径约 6 像素，必须 7×7 才填得满。

**Q6. 形态学会不会改变目标尺寸？做测量时怎么办？** ★★

**一句话**：会——腐蚀让目标变小、膨胀让目标变大，开/闭也只是「大体不变」。

**讲开**：

- 腐蚀削一圈、膨胀长一圈，尺寸变化量约等于结构元半径。
- 开/闭对「大于结构元」的结构影响很小，但不是零：本例开运算少了 96 像素、闭运算多了 59 像素。
- 做尺寸测量时：要么**先测量再形态学**，要么用开/闭并**标定偏差**（用标准件测一次补偿）。
- 更稳的做法：用「亚像素边缘 + 拟合」测尺寸，形态学只用来清噪声，不参与测量路径。

**数字锚点**：开运算 −96 像素、闭运算 +59 像素；对 11829 像素的零件来说约 0.5%~0.8%，但在小目标上可能超过 10%。

**追问**：「那为什么还用它清理？」→ 因为它改的是**拓扑**（去掉孤立点、填上洞），这正是面积过滤做不到的。

**Q7. 结构元大小怎么定？太大或太小会怎样？** ★★

**一句话**：大于缺陷、小于目标；两端都会翻车。

**讲开**：

- 太小：噪点去不掉（3×3 去不掉 5 像素的斑）。
- 太大：目标被吃掉、相邻零件被粘连或断开。
- 定法：先量缺陷尺寸（本例噪点 1~2 像素、孔约 6 像素），再按「缺陷尺寸 + 1~2」取奇数核。
- 还有形状：十字核接近圆形（各向同性）、方形核会偏向对角方向；圆盘核最贵但最准。

**数字锚点**：噪点 1~2 px → 3×3；孔直径 ~6 px → 7×7；两者不能共用一个核。

**追问**：「能不能自动选？」→ 可以按面积分布扫描几个核，选「噪点数降到 0 且主体面积变化最小」的那个。

**Q8. 4 连通和 8 连通有什么区别？什么时候会改变结果？** ★★

**一句话**：斜对角算不算连通；细线/网格上会直接改变对象个数。

**讲开**：

- 4 连通只看上下左右；8 连通把斜对角也算上。
- 两条斜着靠近的细线：8 连通会把它们并成一个对象，4 连通不会。
- 噪声图里 8 连通更容易把孤立点连成大块，导致「面积看起来很大」。
- 经验：细线、网格、文字用 4 连通；块状零件用 8 连通；拿不准就两种都跑，看对象数是否稳定。

**数字锚点**：噪声图 92 个连通块，开运算后剩 1 个；面积 ≥20 的只有 1 个（其余 91 个是噪点），最大面积 11829。

**追问**：「那面积过滤和形态学，先做哪个？」→ 先用面积过滤（`O(N)`、不改形状），再按需要做形态学；本例面积阈值 20 一步就把 92 降到 1。

### 10.4 用数字校验（1 题）

**Q9. 从梯度图到最终边缘，每一步掉了多少像素？这些数字能说明什么？** ★★

**一句话**：7765 → 1926 → 1671 → 1753；NMS 掉了 75%，滞后只补了 5%。

**讲开**：

- `7765` 是「幅值 >30」的像素，包含粗边和噪声；`1926` 是 NMS 后的单像素脊线（24.8%）。
- `1671` 是强边；`1753` 是滞后后的最终结果——只多了 82 个像素，说明这张图对比度高、弱边少。
- 若 `final/strong` 明显大于 1，说明弱边多（低对比度），滞后在「接断边」。
- 弱边连通块数（本例 5 个）是噪声水平的指标：噪声多时它会暴涨，滞后会把它们全滤掉。

**数字锚点**：压缩率 24.8%、`final/strong = 1.05`、边缘占全图 4.06%、弱边连通块 5 个。

**追问**：「这些数字在工程上怎么用？」→ 当验收基线：换镜头/换光源后重跑，如果 NMS 后像素暴涨或 `final/strong` 掉下来，说明对比度或对焦出了问题。

## 11. 坑清单

| # | 坑 | 症状 | 处理 |
|---|---|---|---|
| 1 | 边缘检测前不滤波 | 全是噪点 | 先高斯 σ=1~2 |
| 2 | 补零边界 | 图边出现强假边缘 | `reflect` 或裁边 |
| 3 | NMS 用边缘方向 | 边缘被压断 | 用梯度方向（垂直边缘） |
| 4 | 双阈值比例失衡 | 断边或噪点多 | high:low = 2:1~3:1 |
| 5 | 结构元比缺陷小 | 噪点去不掉 | SE > 缺陷尺寸 |
| 6 | 结构元比目标大 | 目标被吃掉 | SE < 目标尺寸 |
| 7 | 闭运算补大孔 | 补不上 | 换更大 SE，或先膨胀 |
| 8 | 形态学后直接测尺寸 | 尺寸偏大/偏小 | 标定偏差，或先测后修 |
| 9 | 连通性选错 | 对象数不对 | 细线用 4 连通，块状用 8 连通 |
| 10 | 面积阈值拍脑袋 | 漏检/误检 | 统计一批图的面积分布 |
