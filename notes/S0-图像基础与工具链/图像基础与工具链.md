# S0 图像基础与工具链 · 总览

> **这一模块回答一个问题**：一张图在计算机里到底是什么？为什么「先滤波、再阈值、后形态学」这个顺序不能反？
>
> **时间预算**：2 周 / 约 20 h（工作日晚 2 h × 3 + 周末 4 h × 2）
> **交付物**：用 NumPy 手写卷积 / 高斯滤波 / 直方图均衡，每一步能说出「在算什么、代价是什么」。
> **验收方式**：S0 不进入库题（题库从 M1 开始），用每篇末尾的自测题 + 面试题纲（★ 全过）+ 一个「从图到轮廓」的小项目验收。

## 一、五篇的位置

```
0 环境与工具链   → 让代码能跑；NumPy 五个基本功
1 图像是什么     → 形状 / 位深 / 通道 / 灰度 / 量化 / 采样
2 卷积与滤波     → 滑窗、padding、stride、高斯、Sobel、im2col
3 直方图与点运算 → 直方图、均衡、CLAHE、伽马、Otsu
4 边缘与形态学   → NMS、双阈值、Canny、开闭、连通域
```

**依赖关系**：

```
0 ──► 1 ──► 2 ──► 4
             │
             └──► 3
```

- 第 2 篇的 Sobel 是第 4 篇的输入。
- 第 3 篇的阈值是第 4 篇形态学的输入。
- 第 0 篇的 dtype / shape / 坐标贯穿全部。

## 四、验收小项目：从图到轮廓

不看答案，独立完成：

1. 用第 1 篇的方法造一张「有噪声、光照不均」的零件图（或拍一张）。
2. 用第 3 篇的方法提升对比度（均衡或 CLAHE），记录处理前后的标准差。
3. 用第 2 篇的 Sobel + 第 4 篇的 NMS / 双阈值 / 滞后，得到单像素边缘。
4. 用形态学开/闭清理，再用连通域筛出最大目标。
5. 输出一张 4 面板图：原图 / 增强 / 边缘 / 连通域着色。
6. 写 5 行结论：每步用了什么参数、为什么、数字是多少。

**通过标准**：

- [ ] 能不看代码写出 `correlate2d` 的伪代码（含 padding / stride）。
- [ ] 能解释「为什么先滤波再求梯度」，并举一个反例。
- [ ] 能说出均衡化和 CLAHE 的区别，以及各自的一个副作用。
- [ ] 能解释 Otsu 在光照不均时为什么失效。
- [ ] 能说出 NMS 比较的是梯度方向还是边缘方向。
- [ ] 能根据缺陷尺寸选形态学结构元大小。
