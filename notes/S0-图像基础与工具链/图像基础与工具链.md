# S0 图像基础与工具链

> 题库里没有这一块，但它是从 0 学 CV 的真正起点。跳过它，后面所有"为什么这样预处理"都会变成死记。
> **建议用时**：2 周 / 约 20 h。
> **学完能做什么**：不调 cv2，用 NumPy 手写卷积、高斯滤波、直方图均衡，并说清每个算子的代价。

## 核心概念（要能自己默写）

- 图像是矩阵：shape、dtype、uint8 与 float32 的差别（为什么归一化到 [0,1]）、BGR vs RGB（OpenCV 的坑）。
- 色彩空间：灰度加权系数、HSV 为什么适合做阈值分割、YUV 与压缩。
- 卷积：核、padding、stride、感受野；**im2col** 是什么；为什么说卷积是"权重共享的全连接"。
- 滤波：均值/高斯（低通）、Sobel/Scharr（一阶导）、Laplacian（二阶导）、中值（椒盐）。
- 边缘检测 Canny 四步：高斯平滑 → 梯度幅值方向 → 非极大值抑制 → 双阈值 + 滞后连接。
- 形态学：腐蚀/膨胀/开闭运算（去噪点 vs 填孔）。
- 直方图：均衡化、CLAHE、为什么要看直方图判断曝光。
- 插值：最近邻 / 双线性 / 双三次，上采样与下采样（先模糊再降采样，防混叠）。
- 坐标系约定：图像坐标 (x, y) 与矩阵索引 (row, col) 的转置关系——**这是新手第一大坑**。
- Python 工具：NumPy 广播与切片、matplotlib 显示、用 `assert` 写自测。

## 建议顺序

1. 读一张图，做通道分离、灰度化、直方图，判断是否过曝。
2. 手写 3×3 卷积（三重循环版）→ 用 stride 视图加速版 → 与 cv2.filter2D 对拍。
3. 手写高斯核（二维可分离为两个一维）→ 验证可分离性带来的加速。
4. 手写直方图均衡 → 与 cv2.equalizeHist 对拍。
5. Canny：先只用 Sobel 找梯度，再补 NMS 与双阈值，看图差在哪。
6. 形态学 + 连通域，做一个"数硬币"的小任务。

## 配套练习

- L00：卷积 / 高斯 / 直方图均衡，与 cv2 对拍，报最大像素差。
- L01：图像金字塔 + 边缘检测，观察尺度变化对边缘的影响。
