# M6 多模态融合

> **目标**：能针对一个场景选融合层级，并量化"标定误差 + 时间不同步"会让融合掉多少分。
> **前置**：M2（外参、时间同步）、M4（3D 检测）、M5（2D 检测）。
> **建议用时**：1.5 周 / 约 18 h。
> **学完能做什么**：把 3D 框投到图像上做可视化；给出"1° 角误差在 20 m 处 ≈ 35 cm"这类量化结论。

## 核心概念（要能自己默写）

- 三级融合：**前融合**（特征/BEV 层，信息多但对标定与同步极敏感）/ **后融合**（决策层，鲁棒但丢互补）/ **级联**（2D 先出视锥再 3D 搜）。
- CLOCs：任意 2D + 任意 3D 候选框 → 2D 框反投影成稀疏体素 → 与 3D 框 BEV 特征拼接融合；模块化、可插拔。
- BEVFusion：LSS 预测逐像素深度分布 → "抬"到 3D → 拍扁成 BEV；难点是深度误差与 BEV 池化效率。
- BEVFormer：BEV query 做空间交叉注意力（可变形采样）+ 时序自注意力；用 attention 替代显式深度。
- 标定误差量化：横向偏移 ≈ d·tanθ；容差设计（ROI 门限、距离相关权重、在线残差监测、退化单模态）。
- 时间同步：硬触发 / PPS / PTP / 软件时间戳；不同帧率（相机 30 Hz vs 雷达 10 Hz）以谁为基准。
- 决策级规则：加权平均、贝叶斯、D-S 证据、投票、WBF；冲突仲裁逻辑。
- 评价：消融、分场景、分距离段、鲁棒性曲线（人为加误差看性能下降）。
