# M3 激光雷达与点云处理

> **目标**：拿到一帧原始点云，能独立完成"去畸变 → 下采样 → 地面分割 → 聚类/配准"整条预处理，并说清每步的参数依据。
> **前置**：M1（SVD、LM）、M2（外参、时间同步）。
> **建议用时**：2 周 / 约 25 h。
> **学完能做什么**：手写 ICP 并解释它什么时候会失败；给一帧点云报出配准精度和耗时。

## 核心概念（要能自己默写）

- 测距原理：ToF / AMCW / FMCW（FMCW 能测径向速度）；机械 / 半固态 / 固态。
- 点云五大天然缺陷：稀疏且随距离二次稀疏、非均匀、无序、有噪声离群、无纹理。
- 运动畸变：一帧 100 ms 内载体在动；用方位角推每点时刻 + IMU/匀速模型补偿。
- 地面分割：RANSAC 单平面 / 栅格高度差 / **Patchwork 极坐标分区 + 地面似然** / 语义分割。
- 聚类：欧式（KD-tree + 半径）、DBSCAN（eps 用 k-近邻距离曲线拐点定）；细长目标会断裂。
- 配准：ICP 流程与局部极小的成因；点到面残差雅可比 = −nᵀ[Rp]×；NDT 用高斯分布免对应点搜索。
- 特征：法向 = 协方差最小特征向量，曲率 ≈ λ₀/Σλ；FPFH（33 维）用于粗配准。
- 下采样：体素（预处理）/ FPS（网络输入）/ 曲率保持（保边）。
- 评价：内点率 fitness、对应点 RMSE、位姿误差（m + °）——只报 RMSE 会掩盖"只对齐一小块"。
