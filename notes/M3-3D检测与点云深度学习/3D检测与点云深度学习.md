# M3 3D 检测与点云深度学习

> **目标**：能画出"点云 → backbone → BEV/候选框 → 检测头"的数据流，并解释每个代表方法为了解决什么而存在。
> **前置**：M2（点云特性）、S3（CNN、训练、损失）。
> **建议用时**：3 周 / 约 35 h。
> **学完能做什么**：在 KITTI/nuScenes 上跑通一个 3D 检测器，改一处设计并给出消融数字。

## 核心概念（要能自己默写）

- 点云无序性 → **对称函数**（逐点 MLP + max pool）；T-Net 的作用与代价。
- PointNet++：FPS 采样 → ball query 分组 → 组内 PointNet；MSG/MRG 解决密度不均。
- 体素路线：VoxelNet（3D 卷积，慢）→ SECOND（稀疏卷积，快）→ PointPillars（柱 + 2D 卷积，最快、丢高度细节）。
- 稀疏卷积为什么快；submanifold 版本"不扩散"的意义。
- CenterPoint：BEV 热力图 + 中心偏移/高度/尺寸/朝向（sin-cos 或 bin），anchor-free 的收益与代价。
- PV-RCNN：体素负责召回、原始点负责精度；VSA + RoI-grid pooling。
- 角度回归的周期性问题与四种解法（bin / sin-cos / IoU-SmoothL1 / 圆环损失）。
- 3D IoU 难算的根源（凸多面体裁剪）与工程近似（BEV IoU、中心距离）。
- 指标：KITTI 3D/BEV AP（IoU 0.7 车、0.5 行人）、nuScenes mAP + NDS 五类 TP。
- 远距离小目标：多尺度、ROI 放大、多帧累积、切片推理、难例重采样。
