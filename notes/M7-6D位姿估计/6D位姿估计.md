# M7 6D 位姿估计

> **目标**：能给一个工业抓取任务选出位姿方案，并说清"对称物体"和"旋转误差"这两个坑。
> **前置**：M2（PnP、对极）、M3（ICP/精配准）。
> **建议用时**：1 周 / 约 12 h。
> **学完能做什么**：粗定位 + ICP 精配准跑通，报平移 mm + 旋转 °，并用 ADD-S 评对称物体。

## 核心概念（要能自己默写）

- 五条技术路线：对应点法（PVNet）/ 整体回归（PoseCNN）/ 精配准（PPF + ICP）/ RGB-D 端到端（DenseFusion）/ 模板匹配（Linemod，工业常用）。
- 工业主流："传统几何粗定位 + ICP 精配准"，比纯深度模型可控、可解释。
- PVNet：逐像素预测指向关键点的单位向量 → RANSAC 投票，对遮挡/截断鲁棒。
- DenseFusion：逐像素融合 RGB 与几何特征再池化，逐像素融合保留局部对应关系。
- 对称性：多个位姿同外观 → 损失平均成错误解；对策 ADD-S、显式对称建模、非对称特征消歧、多假设。
- ADD vs ADD-S：最近点距离让对称物体公平评价；阈值常取模型直径 10%。
- 评价：平移 + 旋转分开报，均值 / P95 / 最大值，按距离与遮挡分档；抓取任务旋转误差常常更致命。
