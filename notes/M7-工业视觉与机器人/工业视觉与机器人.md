# M7 工业视觉与机器人

> **目标**：能从零描述一条线激光扫描 / 焊缝跟踪系统的组成、标定链路与精度边界。
> **前置**：M1（标定链路、三角测量）、M2（点云特征）。
> **建议用时**：2 周 / 约 20 h。
> **学完能做什么**：画出一条"光条中心提取 → 射线-光平面求交 → 叠位姿拼点云"的重建链路，并给出精度预算表。

## 核心概念（要能自己默写）

- 线激光系统组成：激光器 + 柱面镜、工业相机 + 窄带滤光片、运动机构、位姿反馈、重建软件；核心指标 FOV / 工作距离 / Z 分辨率 / 速度 / 点间距。
- 三角测量：表面高度变化 → 光条像面平移，非线性关系用标定查找表/多项式；精度受基线夹角、畸变、亚像素提取、反射率、环境光、散斑、曝光、标定精度影响。
- 经验式：深度分辨率 ≈ 视场/像素数 × 几何放大系数，别指望大视场做微米级。
- 高反光 / 深色 / 透明：多曝光 HDR 融合、偏振片、调整入射角、喷涂显影剂、蓝光 + 窄带滤光。
- 焊缝特征提取：ROI 分割 → 沿焊缝切片 → 切片内 2D 轮廓分析 → 特征点（V 型交点 / 角焊缝交线 / 搭接台阶）→ 拟合出路径与法向。
- 熔深：线能量 E = P/v 主导；匙孔面积与熔深强相关（同轴视觉的物理依据），但属统计相关，换工况要重标。
- 回归建模：特征标准化 + 共线性检查（VIF），交叉验证 + **跨工况测试**，报 R²/RMSE/残差漂移。
- TCP 标定：四点法求位置（球心），六点法加朝向。
- 轨迹：路径点 → 逆解 → 插补（关节/直线/圆弧）→ 速度规划（S 曲线限 jerk）；腕部/肩部奇异点要绕开。
- 碰撞检测：AABB/OBB 粗筛 → GJK/FCL 精检，留安全余量并滤波防假碰撞。
- 上位机架构：分层 + 三线程（采集/算法/UI）+ 队列解耦 + 状态机；可靠性五件套（超时重连、心跳、日志、异常不吞、配置持久化）。
