## 0. 开始之前：任务与名词

### 0.1 任务：算完参数，还得知道它有多准

标定报告写“重投影 RMSE = 0.3 px”，但客户关心的不是这个数，而是：

- 误差到现场会变成多少毫米？
- 两个传感器读数不一致时，信谁？
- 怎么把多帧观测合成一个更稳的估计？

**为什么不能只给一个数**：没有“不确定度”，就没法比较、没法加权、没法验收。

**本章解决哪一步**：误差怎么传（协方差传播）、怎么比较（马氏距离）、怎么融合（卡尔曼）。

### 0.2 名词卡片

**协方差（covariance）**
- 一句话：误差的“形状”，描述不确定度和方向。
- 不是：不是一个误差值，是一个矩阵。
- 例：`Σ = diag(σx², σy²)` 表示两个方向独立、各自有方差。

**误差传播（error propagation）**
- 一句话：输入有误差，输出误差多大：`Σ_y ≈ J·Σ_x·Jᵀ`。
- 用途：像素误差 → 毫米误差。

**马氏距离（Mahalanobis distance）**
- 一句话：按不确定度归一化后的距离：`d² = eᵀ·Σ⁻¹·e`。
- 用途：异常检测、残差加权。

**信息矩阵（information matrix）**
- 一句话：协方差的逆 `Σ⁻¹`，表示“这条信息有多值钱”。
- 别名：精度矩阵。

**卡尔曼滤波（Kalman Filter，KF）**
- 一句话：预测 + 更新，递归地融合“模型”和“观测”。
- 本质：线性高斯下的加权最小二乘。

**EKF（Extended Kalman Filter，扩展卡尔曼滤波）**
- 一句话：非线性版 KF，用雅可比做线性化。
- 代价：线性化点选得不好会发散。

**新息（innovation）**
- 一句话：观测 − 预测的观测。
- 用途：KF 的更新量、异常检测。

### 0.3 三个真实场景

| 场景 | 你要回答的问题 |
|---|---|
| 标定 | 像素误差 0.3 px，到 10 m 外变成多少毫米？ |
| 融合 | 相机说 1.00 m、雷达说 1.05 m，信谁？ |
| 跟踪 | 上一帧的位置 + 这一帧的观测，怎么合成一个“更好的估计”？ |

三个问题的答案都是同一套东西：**协方差 + 它的逆（信息矩阵）+ 加权平均**。

## 1. 随机变量：均值与协方差

### 1.1 定义

```
均值      μ = E[x]                     （你猜它大概是多少）
协方差    Σ = E[(x−μ)(x−μ)ᵀ]          （你有多不确定、往哪个方向不确定）
```

- 对角元 `Σᵢᵢ = σᵢ²` —— 每个分量的方差；
- 非对角元 `Σᵢⱼ` —— 两个分量**一起变**的趋势（相关性）。

### 1.2 几何：协方差是一个椭球

二维高斯 `N(μ, Σ)` 的等高线是椭圆：

```
特征向量 → 椭圆的轴方向
特征值   → 轴长度的平方（σ 意义下）
```

**正交对角化** `Σ = R·diag(σ₁², σ₂²)·Rᵀ` —— 协方差本身就带着一个旋转，这一点在标定误差链里非常重要。

### 1.3 独立 vs 不相关

| 说法 | 含义 |
|---|---|
| 独立 | 联合分布 = 边缘分布之积（强） |
| 不相关 | `Σᵢⱼ = 0`（弱，只说明没有线性关系） |
| 高斯分布下 | **两者等价**（这就是为什么大家都假设高斯） |

## 2. 误差传播：一阶泰勒

### 2.1 公式（要会写）

```
y = f(x)          Σ_y ≈ J · Σ_x · Jᵀ          J = ∂f/∂x
```

标量特例（`y = f(x₁, x₂)`，且 x 各分量独立）：

```
σ_y² = (∂f/∂x₁)² σ₁² + (∂f/∂x₂)² σ₂² + …
```

**直觉**：每个输入的不确定度，按"它对输出的敏感程度"的平方加权，再叠加。
**它是一阶近似**：f 非线性强、σ 大时不准（要用蒙特卡洛验证）。

### 2.2 例子：双目深度，误差随 Z² 爆炸

```
Z = f·B / d          f 焦距(像素), B 基线(米), d 视差(像素)
∂Z/∂d = −f·B/d² = −Z²/(f·B)
→ σ_Z = Z²/(f·B) · σ_d
```

取 `f = 800 px`、`B = 0.12 m`（fB = 96 m·px）、`σ_d = 0.1 px`：

| 距离 Z | 视差 d | 深度误差 σ_Z |
|---|---|---|
| 5 m | 19.2 px | 2.6 cm |
| 10 m | 9.6 px | 10.4 cm |
| 20 m | 4.8 px | 41.7 cm |
| 50 m | 1.9 px | 2.6 m |

> **距离翻倍，误差涨 4 倍。** 这就是 `labs/L50` 要你算的那张表，也是"远距离目标为什么不能只靠双目"的定量答案。

### 2.3 位姿链上的传播

多个变换串起来 `T = T₁·T₂·…·Tₙ` 时：

```
Σ_T ≈ J₁ Σ₁ J₁ᵀ + J₂ Σ₂ J₂ᵀ + …          （各段独立时直接相加）
```

其中 `Jᵢ` 是"第 i 段的小扰动怎么传到最终位姿"，涉及伴随矩阵 `Ad(T)`。
**工程结论**：标定链越长，误差越难收敛 —— 所以能少一节就少一节，且要把最不确定的那段放在**末端**（影响最小）。

## 3. 马氏距离与信息矩阵

### 3.1 为什么不能直接用欧氏距离

两个误差：

```
A: 预测偏 10 cm，但那台传感器本来就 ±20 cm     → 很正常
B: 预测偏 10 cm，但那台传感器是 ±1 mm          → 出大事了
```

欧氏距离分不出这两者。**马氏距离把"不确定度"除掉**：

```
d² = eᵀ · Σ⁻¹ · e            e = 观测 − 预测
```

- `Σ` 大（本来就不准）→ `Σ⁻¹` 小 → 同样的误差罚得轻；
- `Σ` 小（号称很准）→ 罚得重。

**d² 服从 χ²(k)**（k 是残差维数）→ 可以直接当**异常检测门限**：
`χ²(2, 95%) = 5.99`，即 `d > 2.45` 就判为离群。

### 3.2 信息矩阵

```
Λ = Σ⁻¹            （信息矩阵 / 精度矩阵）
```

- `Σ` 大 = 不确定 = 信息少；`Λ` 大 = 确定 = 信息多；
- 优化里的 `H = JᵀΣ⁻¹J` 就是**Fisher 信息矩阵** —— 所以"H 越大，这个参数越可信"；
- 加权最小二乘的 `W = Σ⁻¹`，和它是同一个东西。

**一句话**：`Σ⁻¹` 是"每条观测值几分钱"的汇率。

## 4. 卡尔曼滤波：把两团高斯乘起来

### 4.1 模型

```
状态方程   xₖ = F·xₖ₋₁ + B·uₖ + wₖ        w ~ N(0, Q)
观测方程   zₖ = H·xₖ + vₖ                  v ~ N(0, R)
```

- `F` 怎么演化、`H` 怎么观测 —— 这两个是**模型设计**；
- `Q`、`R` 是**噪声强度** —— 这两个是**调参**（但有时物理可测）。

### 4.2 五个公式（背下来）

```
预测（Predict）
  x⁻ = F·x + B·u
  P⁻ = F·P·Fᵀ + Q

更新（Update）
  K  = P⁻·Hᵀ·(H·P⁻·Hᵀ + R)⁻¹
  x  = x⁻ + K·(z − H·x⁻)
  P  = (I − K·H)·P⁻
```

### 4.3 K 到底在权衡什么（标量看最清楚）

一维、`H = 1`：

```
K = P⁻ / (P⁻ + R)          ← 预测方差 ÷ 总方差
x = K·z + (1−K)·x⁻         ← 观测与预测的加权平均
```

| 情况 | K | 结果 |
|---|---|---|
| `R → 0`（观测极准） | K → 1 | 完全信观测 |
| `R` 适中 | 0 < K < 1 | 按方差比例融合 |
| `R → ∞`（观测不可信） | K → 0 | 完全信预测 |
| `Q` 大（模型不可信） | `P⁻` 变大 → K 变大 | 更信观测 |

**实测**（先验 N(0,1)，观测 z = 2）：

| R（观测方差） | K | 融合结果 |
|---|---|---|
| 0.01 | 0.9901 | 1.980 |
| 0.1 | 0.9091 | 1.818 |
| 1 | 0.5 | 1.000 |
| 10 | 0.0909 | 0.182 |
| 100 | 0.0099 | 0.020 |

> **K = "观测占了多大话语权"。** Q 大 / R 小 → 更信观测；Q 小 / R 大 → 更信预测。

### 4.4 它和优化是什么关系

KF 的更新就是解一个**加权最小二乘**：

```
min  (x−x⁻)ᵀ(P⁻)⁻¹(x−x⁻) + (z−Hx)ᵀ R⁻¹ (z−Hx)
```

- 第一项 = 先验（上一帧的信息）；
- 第二项 = 观测（本帧的信息）；
- 解出来正好是那五个公式。

**所以：KF = 线性高斯假设下的递归 MAP = 带先验的加权最小二乘。**
非线性时 → EKF / 迭代 EKF / 因子图（也就是 BA 的思路）。

## 5. EKF 与旋转

状态里有 R 时，**不能直接对 R 求协方差**（9 个数 6 个约束）。做法是：

```
状态：  R, t, …                    （存全量）
误差：  δ = [δφ, δt, …] ∈ ℝ⁶        （优化/滤波只作用在 6 维误差上）
更新：  R ← R·exp(δφ^)              t ← t + δt
协方差：P 是 6×6（或 6+内参 的块）
```

这和 [`1-旋转.md`](1-旋转.md) §4.2 的"状态 vs 增量"是**同一件事**：
卡尔曼的 `P` 描述的是**切空间里的误差分布**，不是旋转矩阵本身的分布。

EKF 的线性化点选在**当前估计**处；估计误差大时线性化失效 → 这就是 EKF 会发散、而 BA（反复重线性化）更稳的原因。

## 6. 代码

### 6.1 协方差传播 vs 蒙特卡洛

```python
import numpy as np

mu  = np.array([2.0, 4.0])
Sig = np.array([[0.04, 0.01],
                [0.01, 0.09]])

def f(v):                                 # y₁ = x₁x₂,  y₂ = x₁/x₂
    return np.array([v[0] * v[1], v[0] / v[1]])

# 解析：一阶传播
J = np.array([[mu[1], mu[0]],
              [1 / mu[1], -mu[0] / mu[1] ** 2]])
Sig_y = J @ Sig @ J.T
print("propagated cov\n", Sig_y.round(5))

# 数值：抽 20 万次
rng = np.random.default_rng(2)
smp = rng.multivariate_normal(mu, Sig, 200000)
fy = np.array([f(s) for s in smp])
print("MC cov\n", np.cov(fy.T).round(5))
```

**输出**：

```
propagated cov
 [[1.16    0.0175 ]
 [0.0175  0.00328]]
MC cov
 [[1.16436 0.01714]
 [0.01714 0.00337]]
```

两者吻合到 1% 量级 → **一阶传播在这个非线性程度下够用**。
（如果 `σ` 再大，或 f 的曲率再强，就会开始分叉 —— 这时候要么二阶项，要么蒙特卡洛。）

### 6.2 两个高斯的融合 + K 扫参

```python
def fuse(m1, s1, m2, s2):                 # 一维：先验 N(m1,s1) + 观测 N(m2,s2)
    K = s1 / (s1 + s2)
    return m1 + K * (m2 - m1), (1 - K) * s1, K

print("先验 N(0,1)，观测 z=2, R=1 →", [round(v, 4) for v in fuse(0, 1, 2, 1)])

for R in [0.01, 0.1, 1, 10, 100]:
    m, p, K = fuse(0, 1, 2, R)
    print(f"R={R:<6} K={K:.4f}  x={m:.3f}  P={p:.3f}")
```

**输出**：

```
先验 N(0,1)，观测 z=2, R=1 → [1.0, 0.5, 0.5]
R=0.01   K=0.9901  x=1.980  P=0.010
R=0.1    K=0.9091  x=1.818  P=0.091
R=1      K=0.5000  x=1.000  P=0.500
R=10     K=0.0909  x=0.182  P=0.909
R=100    K=0.0099  x=0.020  P=0.990
```

### 6.3 常速度模型的 KF（可运行，能看到收敛）

```python
import numpy as np

F  = np.array([[1.0, 1.0], [0.0, 1.0]])   # 位置 += 速度
Q  = np.diag([0.01, 0.04])                # 模型噪声
Hm = np.array([[1.0, 0.0]])               # 只测位置
Rk = np.array([[0.5]])                    # 测距方差

x = np.array([0.0, 0.0])                  # [位置, 速度]
P = np.eye(2)
for z in [1.0, 2.1, 2.9, 4.2, 5.1]:
    x = F @ x                             # 预测
    P = F @ P @ F.T + Q
    K = P @ Hm.T @ np.linalg.inv(Hm @ P @ Hm.T + Rk)
    x = x + (K @ (np.array([[z]]) - Hm @ x)).ravel()   # 更新
    P = (np.eye(2) - K @ Hm) @ P

print("KF final x", x.round(3))            # 位置、速度
print("P\n", P.round(4))
```

**输出**：

```
KF final x [5.063 1.015]
P
 [[0.2946 0.1079]
 [0.1079 0.1189]]
```

**读法**：5 次观测（步长 1）后，位置 5.06、速度 1.02 —— 速度是从"位置增量"里**估出来**的（模型的作用），这就是 KF 在做"用模型补观测里没有的量"。

## 7. 坑清单

| # | 坑 | 后果 | 解法 |
|---|---|---|---|
| 1 | 把 `Σ` 当"权重"直接用 | 量纲错、越优化越偏 | 用 `Σ⁻¹`（信息矩阵） |
| 2 | Q/R 当纯调参 | 结果看着好、实际不可信 | 尽量从传感器规格/标定残差估 |
| 3 | 假设独立 | 相关传感器重复计票 | 用完整协方差，别只取对角 |
| 4 | 角度直接相减 | 179° 与 −179° 差 358° | 用旋转向量/四元数，或 wrap 到 ±180° |
| 5 | 协方差失去对称正定 | 数值发散 | `P=(P+Pᵀ)/2`，更新用 Joseph 形式 |
| 6 | 深度误差当常数 | 远处点权重过大 | 用 `σ_Z ∝ Z²` 的协方差 |
| 7 | EKF 线性化点太旧 | 大误差时发散 | 迭代 EKF / 因子图重线性化 |

## 9. 参考答案

**1.**

```
x⁻ = Fx + Bu,          P⁻ = FPFᵀ + Q
K  = P⁻Hᵀ(HP⁻Hᵀ + R)⁻¹
x  = x⁻ + K(z − Hx⁻),  P = (I − KH)P⁻
```

K 的物理意义：**观测在最终估计里占的权重**（也是"新息 `z−Hx⁻` 被采纳的比例"）。一维时 `K = P⁻/(P⁻+R)`，即"预测方差 ÷ 总方差"：观测越准（R 小）K 越大，越信观测；模型越不准（Q 大 → P⁻ 大）K 也越大，同样更信观测。

**2.** 马氏距离 `d² = eᵀΣ⁻¹e` 是"按不确定度归一化后的误差"，用它做残差 → 不同精度、不同单位（像素/米）的观测可以放进同一个代价函数。`Σ⁻¹` 就是信息矩阵，也是加权最小二乘的权重 `W`、GN 里的 `H = JᵀΣ⁻¹J`（Fisher 信息）。信息矩阵越大 = 越确定 = 话语权越大。

**3.** `Σ_y ≈ JΣ_xJᵀ`（一阶泰勒）。它决定链路设计是因为：**误差是按"敏感度平方"逐级累加的**，串联的每一节都会放大/旋转上游的不确定度。所以要①减少串联环节、②把最不确定的放在末端、③在关键节点做联合优化（而不是各段独立标定再串起来）。

**4.** `Z = fB/d`，`∂Z/∂d = −Z²/(fB)` → `σ_Z = Z²/(fB)·σ_d`，因为视差在分母上，距离越远视差越小、同样的视差误差对应越大的深度误差。例：`fB = 96 m·px`、`σ_d = 0.1 px` 时，10 m 处 σ_Z ≈ 10.4 cm，20 m 处 ≈ 41.7 cm。

**5.** `Q` 大 = 认为**模型**不可信 → 预测方差变大 → K 变大 → 更依赖观测（跟踪更"跳"）。`R` 大 = 认为**传感器**不可信 → K 变小 → 更依赖预测（跟踪更"肉"、更平滑但可能滞后）。
