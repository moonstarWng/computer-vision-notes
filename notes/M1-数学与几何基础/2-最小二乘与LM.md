## 0. 这一篇解决什么问题

上一篇把"旋转怎么放进取优化变量"讲完了，但还没讲**优化器本身**。三个问题：

1. 为什么残差要平方？换成绝对值会怎样？
2. 高斯牛顿里的 `JᵀJ` 是什么？为什么它一接近奇异就爆炸？
3. LM 加的阻尼 `λ` 为什么能同时"稳"和"快"？

**全篇骨架只有一行**：

```
写出残差 r(x)  →  在 x 附近线性化 r + Jδ  →  解一个线性最小二乘  →  x ← x + δ  →  重来
```

高斯牛顿、LM、梯度下降的区别，全在**最后一步怎么走**（走多远、往哪走）。

## 1. 最小二乘：为什么是平方

### 1.1 三条理由

| 理由 | 说明 |
|---|---|
| **概率** | 假设观测噪声是零均值高斯、且相互独立，最大似然估计 ⇔ 最小化残差平方和（见下） |
| **数学** | 平方是二次型 → 求导是线性的 → **有闭式解**（正规方程）；绝对值在 0 点不可导 |
| **几何** | 平方和 = 欧氏距离的平方 → "找离所有观测最近的点"有明确的投影解释 |

**从最大似然推一遍**（30 秒，值得会）：

```
rᵢ ~ N(0, σ²) 独立 → L = Π 1/(√(2π)σ) · exp(−rᵢ²/(2σ²)) 
− log L = 常数 + (1/2σ²) Σ rᵢ²
```

**最大化似然 = 最小化 Σ rᵢ²**（σ 只是缩放，不影响最优解）。

> 想弄清"为什么偏偏是高斯""L1 为什么也可解""反光/粉尘算什么噪声"，看 [`../M0-计算机视觉导论/3-噪声与误差模型.md`](../M0-计算机视觉导论/3-噪声与误差模型.md)。

### 1.2 平方的代价：一个离群点能毁掉整次拟合

残差 2 的点，贡献 4；残差 10 的点，贡献 100 —— **误差被平方放大**。
所以只要有一个错匹配/误检，它就会把整条曲线拉过去。这就是第 4 节鲁棒核要解决的问题。

| 损失 | 对大残差的态度 | 结果 |
|---|---|---|
| L2（平方） | 越错越罚，且罚得越来越重 | 被离群点拉歪 |
| L1（绝对值） | 线性罚，错 10 倍只罚 10 倍 | 抗离群，但 0 点不可导、解不唯一 |
| Huber | 小残差用 L2、大残差用 L1 | 两者折中（工程默认） |

## 2. 线性最小二乘：一次就能解

### 2.1 正规方程

```
min ‖Ax − b‖²        →        AᵀA · x = Aᵀb
```

推导一行：对 x 求梯度（`∇‖Ax−b‖² = 2Aᵀ(Ax−b)`），令其为 0。

**几何意义**：残差 `b − Ax` 必须**垂直于 A 的列空间** —— 也就是"b 在列空间上的投影"。
这就是为什么最小二乘解总是"最接近的那个"。

### 2.2 加权最小二乘

不同观测的可靠程度不一样（近处点比远处点准、内参比外参可信）：

```
min (Ax−b)ᵀ W (Ax−b)      →      AᵀWA · x = AᵀWb
```

`W = Σ⁻¹`（协方差的逆）时，这个量就是**马氏距离的平方** —— 第 4 篇会把它和卡尔曼接上。
一句话：**W 是"每条观测值几分钱"的权重表**。

### 2.3 数值上的坑（重要）

`cond(AᵀA) = cond(A)²` —— **正规方程会把病态程度平方**。

```
np.linalg.solve(A.T @ A, A.T @ b)    # ❌ 条件数差时精度掉光，甚至 Singular
np.linalg.lstsq(A, b)                # ✅ 内部用 QR/SVD
```

- 只有几十个参数、条件数还好时，正规方程够用（SLAM 里也用它，因为要拼稀疏 H）；
- 但**显式求逆 `inv(AᵀA)` 永远不要写**，用分解（Cholesky / QR / SVD）。

**秩亏 = 解不唯一**。比如两列完全相关：

```
A = [x, 2x], b = 3x
det(AᵀA) = 0        cond(AᵀA) ≈ 2.1e16       solve → Singular matrix
lstsq → [0.6, 1.2]  ← 最小范数解：a + 2b = 3 的任何解都行
```

工程上遇到这种情况，要么**加先验/正则**（`+λI`，就是 LM 干的事），要么**换参数化**（把不可观的自由度去掉）。

## 3. 非线性最小二乘：高斯牛顿 **Gauss-Newton**

### 3.1 残差、雅可比

```
r(x) = [r₁(x), …, r_m(x)]ᵀ      m 个残差
J(x) = ∂r/∂x                    m × n 雅可比（n 个参数）
目标：min ½‖r(x)‖²
```

### 3.2 一步推导（要会写）

在当前点线性化：

```
r(x + δ) ≈ r(x) + J·δ
```

代进目标：

```
min ½‖r + Jδ‖²
∂/∂δ = Jᵀ(r + Jδ) = 0
→  (JᵀJ) δ = −Jᵀr          ← 高斯牛顿方程
→  x ← x + δ
```

| 记号 | 名字 | 是什么 |
|---|---|---|
| `JᵀJ` | **H**（近似 Hessian） | n×n，对称半正定 |
| `−Jᵀr` | **g** 或 **b** | n 维梯度方向 |

**为什么叫"近似"**：真正的 Hessian 还有一项 `Σ rᵢ·∂²rᵢ/∂x²`。GN 把它扔了 —— 残差小的时候这项也小，所以**收敛到最优附近时 GN 非常快（二阶收敛）**；残差大时近似就不可靠了。

### 3.3 两个致命问题

| 问题 | 表现 | 原因 |
|---|---|---|
| **H 奇异 / 病态** | 步长爆炸、参数乱飞、NaN | 参数不可观（单目尺度、纯平移手眼、共线点）；`cond(JᵀJ) = cond(J)²` |
| **步长无控制** | cost 反而上升，越迭代越差 | δ 大 → 线性近似失效，但 GN 仍然照单全收 |

> 第 2 个问题很隐蔽：**GN 不检查"这一步有没有变好"**。它算出来就走，走错了也走。

## 4. LM（**Levenberg-Marquardt,莱文贝格–马夸特法**）：给 GN 装一个"刹车"

### 4.1 公式

```
(JᵀJ + λ·diag(JᵀJ)) δ = −Jᵀr          ← Marquardt 版（工程常用）
(JᵀJ + λ·I)         δ = −Jᵀr          ← Levenberg 版
```

只在**对角**加阻尼，是因为参数尺度不同（像素 / 米 / 弧度）：对角项正好是每个参数的"量纲"，加 `λI` 会让大尺度参数被过度压制。

### 4.2 λ 在做什么（信任域直觉）

| λ | 方程变成 | 行为 |
|---|---|---|
| λ → 0 | 高斯牛顿 | 快，但可能飞出去 |
| λ 适中 | 介于两者之间 | **稳** |
| λ → ∞ | `δ ≈ −g/(λ·diag)` | 变成很小的梯度下降步 |

**λ 的倒数 ≈ 允许走多远（信任域半径的平方）**：

```
这一步变好  →  λ ← λ/3     （信任 GN，放开走）
这一步变差  →  λ ← λ×5     （不信任，缩小步长，重解）
```

**所以 LM 同时"稳"和"快"**：顺利时退化成 GN（快），要飞时退化成小步梯度下降（稳）。

| | 梯度下降 GD | 高斯牛顿 GN | LM |
|---|---|---|---|
| 更新式 | `x ← x − α·g` | 解 `JᵀJ·δ = −Jᵀr` | 解 `(JᵀJ + λD)·δ = −Jᵀr` |
| 用到的信息 | 一阶梯度 `g` | 二阶近似 `JᵀJ` | 二阶 + 阻尼 |
| 超参 | 学习率 α | **无** | λ（每步自适应） |
| 单步成本 | `O(mn)` | `O(n³)`（稠密求解） | `O(n³)`，失败还要重解 |
| 内存 | `O(n)` | `O(n²)`（存 `JᵀJ`） | `O(n²)` |
| 收敛速度 | 线性（慢） | 二阶（快） | 近二阶，且稳 |
| 抗病态 | 一般（靠小步硬扛） | ❌ 差 | ✅ 好 |
| 初值要求 | 低 | 高 | 中 |
| 适用损失 | 任意可导 | 仅平方（+ IRLS 可加权） | 同 GN |
| 典型场景 | 深度学习、初值极差 | 残差小、H 良态 | **标定 / BA / ICP 默认** |

> **“贵”指什么**：GN / LM 每步要组装并求解一个 `n×n` 的线性方程。
> 稠密求解是 `O(n³)`、内存 `O(n²)` —— 参数 `n=1000` 时约 10⁹ 次运算、8 MB；
> `n=10000` 时就是 10¹² 次运算、800 MB，直接不可行，**所以 BA 必须用稀疏性（Schur 补）**。
> 梯度下降每步只算梯度 `O(mn)`、内存 `O(n)`，所以“便宜”。
>
> 另外：**LM 不是“更快的 GN”**。它每步更贵（可能要试几次 λ），只是**更不容易发散**；
> GN 本来就能收敛的问题，LM 反而更慢。

### 4.3 收敛判据（别只看 cost）

```
‖δ‖ < 1e-8              参数不再动
‖Jᵀr‖∞ < 1e-10         梯度到 0
|Δcost| / cost < 1e-6   代价不再降
迭代次数 > 上限          兜底
```

> ⚠️ **残差小 ≠ 解对**。参数退化时（第 3 篇的共线点），残差可以接近 0，但解在一整条直线上都成立。判据之外还要看 **H 的条件数 / 奇异值**。

## 5. 带上旋转：雅可比长什么样

状态里既有 R 又有 t，更新用右扰动（`1-旋转.md` §4）：

```
R ← R·exp(δφ^)        t ← t + δt        ξ = [δφ, δt] ∈ ℝ⁶
```

以重投影残差 `e = u_obs − π(K, R·p + t)` 为例（p 是 3D 点）：

```
∂e/∂δφ = −(∂π/∂P) · R · [p]×          ← 就是上一篇那个 −R[p]×，再串一个投影雅可比
∂e/∂δt = −(∂π/∂P)
∂π/∂P  = [[fx/Z, 0, −fx·X/Z²],
          [0, fy/Z, −fy·Y/Z²]]
```

- 这个 2×6 的块，把"点怎么动"翻译成"像素怎么动"；
- 所有 BA / 标定 / PnP 精化的雅可比都是它的变体；
- **残差对 R 的导数永远是 `−[Rp]×` 结构**，记不住就现场用 `R·exp(δ^)·p ≈ Rp − R[p]×δ` 推。

## 6. 鲁棒核：让离群点"闭嘴"

> **为什么需要它**：`r²` 假设噪声是高斯的（尾部极快衰减）。反光、粉尘、误匹配会让残差出现"重尾"，平方损失就被少数坏点带偏。噪声假设与损失的对应关系见 [`../M0-计算机视觉导论/3-噪声与误差模型.md`](../M0-计算机视觉导论/3-噪声与误差模型.md) §1、§4。

### 6.1 核心手法：IRLS（迭代重加权最小二乘）

把损失从 `r²` 换成 `ρ(r)`，然后**每一轮按当前残差给每个点一个权重**，退回到加权最小二乘：

```
wᵢ = ρ′(rᵢ) / rᵢ                ← 影响函数除以残差
(Jᵀ W J) δ = −Jᵀ W r            W = diag(w₁ … w_m)
```

**残差越大，权重越小** —— 这就是"鲁棒"的全部秘密。

### 6.2 常用核（工程四件套）

| 核 | ρ(r) | 权重 w = ρ′/r | 特点 |
|---|---|---|---|
| L2 | r²/2 | 1 | 无鲁棒性，基准 |
| L1 | abs(r) | 1/abs(r) | 最鲁棒，但在 0 附近病态 |
| **Huber** | r²/2 (r≤δ)；δ(r−δ/2) (否则) | 1 (r≤δ)；δ/abs(r) (否则) | 默认首选，凸、可导 |
| Cauchy | (c²/2)·log(1+(r/c)²) | 1/(1+(r/c)²) | 更狠，残差再大权重也趋 0 |
| Tukey | 见库文档 | (1−(r/c)²)² (r≤c)；0 (否则) | **直接删点**，非凸，需好初值 |

**阈值怎么定**（Huber 的 δ）：

- 已知噪声：`δ = 1.345σ`（高斯下 95% 渐近效率）；
- 未知噪声：用残差的 MAD 自适应 `δ = 1.4826 · median(|r|)` —— **工程里更常用**，因为噪声水平事前不知道。

### 6.3 三个使用注意

1. **别一上来就开核**：初值差时残差全都"很大"，核会把所有点都压掉 → 先用 L2 跑几步，再切 Huber。
2. **尺度要一致**：残差单位不同（像素 vs 米）时，同一个 δ 含义不同 → 先白化（除以 σ）再算。
3. **鲁棒核不是万能**：>50% 是离群点时，任何 M 估计都会选错（断点 0.5）→ 得靠 RANSAC。

### 6.4 库里的名字

| 库 | 接口 |
|---|---|
| Ceres | `problem.AddResidualBlock(cost, new ceres::HuberLoss(1.0), ...)` |
| g2o | `edge->setRobustKernel(new g2o::RobustKernelHuber())` |
| scipy | `least_squares(..., loss='huber', f_scale=1.0)` |

## 7. 代码：把上面全部跑一遍

```python
import numpy as np

# ---------- 造数据：y = 2·exp(0.5x)，加 3 个离群点 ----------
rng = np.random.default_rng(0)
x = np.linspace(0, 2, 40)
y_true = 2.0 * np.exp(0.5 * x)
y = y_true + rng.normal(0, 0.05, x.size)
y[[5, 20, 33]] += np.array([2.0, -2.5, 3.0])

def residual(p, x, y):
    a, b = p
    return a * np.exp(b * x) - y

def jac(p, x):
    a, b = p
    e = np.exp(b * x)
    return np.column_stack([e, a * x * e])       # [∂r/∂a, ∂r/∂b]

# ---------- 高斯牛顿 ----------
def gn(p, x, y, iters=50):
    for k in range(iters):
        r = residual(p, x, y)
        J = jac(p, x)
        dp = np.linalg.solve(J.T @ J, -J.T @ r)  # (JᵀJ)δ = −Jᵀr
        p = p + dp
        if np.linalg.norm(dp) < 1e-10:
            break
    return p, k

# ---------- LM ----------
def lm(p, x, y, lam=1e-3, iters=300):
    r = residual(p, x, y); cost = r @ r
    for k in range(iters):
        J = jac(p, x)
        A = J.T @ J + lam * np.diag(np.diag(J.T @ J))   # 只在对角加阻尼
        dp = np.linalg.solve(A, -J.T @ r)
        p_new = p + dp
        r_new = residual(p_new, x, y); cost_new = r_new @ r_new
        if cost_new < cost:                     # 变好：接受，放开 λ
            p, r, cost = p_new, r_new, cost_new
            lam = max(lam / 3.0, 1e-12)
            if np.linalg.norm(dp) < 1e-10:
                break
        else:                                   # 变差：拒绝，收紧 λ
            lam *= 5.0
    return p, k, lam

# ---------- Huber + IRLS ----------
def huber_w(r, delta=0.5):
    a = np.abs(r)
    return np.where(a <= delta, 1.0, delta / np.maximum(a, 1e-12))

def irls(p, x, y, delta=0.5, iters=100):
    for k in range(iters):
        r = residual(p, x, y)
        w = huber_w(r, delta)
        J = jac(p, x)
        H = J.T @ (w[:, None] * J)              # JᵀWJ
        g = J.T @ (w * r)                       # JᵀWr
        dp = np.linalg.solve(H, -g)
        p = p + dp
        if np.linalg.norm(dp) < 1e-12:
            break
    return p, k

p0 = np.array([1.0, 0.0])
print("真值 a=2.0 b=0.5")
print("GN   ", gn(p0.copy(), x, y))
print("LM   ", lm(p0.copy(), x, y))
print("Huber", irls(p0.copy(), x, y))
```

**真实输出**（`py -3` 跑出来的）：

```
真值 a=2.0 b=0.5
GN    (array([1.97737971, 0.52298589]), 10)
LM    (array([1.97737971, 0.52298589]), 18, 9.80039803728605e-06)
Huber (array([1.99213678, 0.50527807]), 11)
```

**怎么读这组数**（这是本篇最重要的一张表）：

| 方法 | a | b | 内点 RMSE | 总 L2 |
|---|---|---|---|---|
| GN | 1.9774 | 0.5230 | 0.0903 | 0.695 |
| Huber | **1.9921** | **0.5053** | **0.0420** | 0.698 |
| 无离群点时 GN | 2.0151 | 0.4972 | 0.0450 | 0.699 |

**三个结论**：

1. 噪声 σ = 0.05，所以"内点 RMSE ≈ 0.045"就是噪声底线；
2. **GN 被三个离群点拖偏了**（内点 RMSE 0.09，是底线的两倍）；
3. **Huber 的总 L2 反而更大（0.698 > 0.695），但参数更准** —— 因为 L2 之和本来就不是有离群点时的正确指标。

> 这就是"残差小 ≠ 解对"的最直观版本。

## 8. 坑清单

| # | 坑 | 后果 | 解法 |
|---|---|---|---|
| 1 | `+λI` 而不是 `+λ·diag(JᵀJ)` | 小尺度参数被过度压制，收敛慢 | 用对角归一化 |
| 2 | 一上来就开鲁棒核 | 初值差时全被当离群点，卡死 | 先 L2 跑 3~5 步，再切 Huber |
| 3 | 残差没白化 | 像素与米混在一起，权重失真 | 除以各自 σ（= 马氏距离） |
| 4 | 显式 `inv(AᵀA)` | 病态时精度崩、甚至报错 | Cholesky / QR / lstsq |
| 5 | 只看 cost 判断收敛 | 退化时"完美"收敛到错误解 | 加参数变化 + 梯度 + 条件数 |
| 6 | 用 L2 的 cost 评价鲁棒结果 | 误判"鲁棒核变差了" | 用内点残差 / 参数误差评价 |
| 7 | 忘了更新流形 | R 直接加，慢慢不正交 | `R ← R·exp(δ^)` |

## 9. 自测（对应题库 Q4、Q5）

1. **Q4**：高斯牛顿和 LM 的区别？什么时候**必须**用 LM？
2. **Q5**：鲁棒核函数解决什么问题？为什么它能"自动降低离群点的权重"？
3. `JᵀJ` 是什么？为什么它接近奇异时步长会爆炸？
4. 为什么"总 L2 更小"不代表"参数更准"？举本篇的例子。
5. LM 里 λ 变大时，方程退化成什么？为什么这能救命？

## 10. 参考答案（先自己写）

**1.** GN 解 `JᵀJ δ = −Jᵀr`，无条件接受；LM 解 `(JᵀJ + λdiag)δ = −Jᵀr`，并按 cost 升降调 λ。
**必须用 LM** 的场景：初值离最优较远、H 病态/秩亏、残差较大（线性化不可靠）、参数尺度差异大。一句话：**只要"一步走错就发散"的风险存在，就要 LM**。

**2.** 解决**离群点/误匹配把解拉歪**的问题。因为它把二次损失换成增长更慢的 ρ(r)，等价于每轮给残差大的点一个小权重 `w = ρ′(r)/r` —— 离群点"说话声音"被自动调小。

**3.** `JᵀJ` 是目标函数 Hessian 的高斯牛顿近似（也是信息矩阵）。奇异 ⇒ 某些参数方向没有约束（不可观）或强相关 ⇒ 该方向代价几乎不变，解方程时沿该方向的分量被放大到无穷 ⇒ 步长爆炸。

**4.** 因为 L2 把离群点的巨大残差也算进总分。本篇里 GN 的总 L2 = 0.695 < Huber 的 0.698，但 GN 的内点 RMSE 是 0.0903，Huber 是 0.0420 —— 前者为了迁就 3 个离群点牺牲了 37 个内点。

**5.** λ → ∞ 时 `δ ≈ −Jᵀr/(λ·diag)`，退化成**步长极小的梯度下降**。所以当 GN 步"迈大了要摔"（cost 上升）时，增大 λ 就等于把步子收小，先保命再谈快。
