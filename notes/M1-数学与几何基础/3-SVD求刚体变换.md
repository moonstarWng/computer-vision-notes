## 0. 先补一个工具：SVD 是什么

**全称**：Singular Value Decomposition，**奇异值分解**。

一句话：**任意矩阵都能拆成“旋转 × 缩放 × 旋转”。**

```
A = U · Σ · Vᵀ
     │   │   │
     │   │   └─ 旋转（正交矩阵）
     │   └───── 缩放（对角，奇异值 s₁ ≥ s₂ ≥ … ≥ 0）
     └───────── 旋转（正交矩阵）
```

### 0.1 一个具体例子（2×2 剪切）

```
A = [[1, 1],
     [0, 1]]

U = [[ 0.851, -0.526],        Σ = diag(1.618, 0.618)
     [ 0.526,  0.851]]

Vᵀ = [[ 0.526, 0.851],
      [-0.851, 0.526]]
```

几何上是三步：

```
先转 58.3°（Vᵀ） → 沿两个主轴分别缩放 1.618 和 0.618（Σ） → 再转 31.7°（U）
```

**“剪切”看起来没法用旋转解释，其实是“转一下、拉一下、再转一下”。**

### 0.2 SVD 能干什么（不只用于点云）

| 用途 | 怎么用 |
|---|---|
| 解最小二乘 | `lstsq` 内部就是它（比正规方程稳） |
| 求伪逆 | `pinv(A) = V Σ⁻¹ Uᵀ` |
| 求秩 / 判退化 | 看有几个奇异值不为 0 |
| 求条件数 | `s_max / s_min` |
| PCA / 主方向 | 对数据或协方差做 SVD，最大奇异值方向 = 主方向 |
| 点云平面 / 法向量 | 最小奇异值对应的方向 = 法向 |
| 低秩近似 / 压缩 | 只保留前 k 个奇异值 |
| **Kabsch 求 R** | 本篇的主角 |

### 0.3 SVD vs 特征值分解（EVD）

| | SVD | EVD |
|---|---|---|
| 适用 | **任意矩阵**（长方形也行） | 方阵（最好对称） |
| 形式 | `A = UΣVᵀ` | `A = QΛQ⁻¹` |
| 正交性 | U、V 都正交 | 一般不正交（对称时才好） |
| 奇异值 | 非负，`s_i ≥ 0` | 可以为负或复数 |
| 典型用途 | 最小二乘、伪逆、配准 | PCA（对称协方差）、振动模态 |

> PCA 两条路都行：对数据矩阵做 SVD，或对协方差矩阵做 EVD，主方向一致。

### 0.4 澄清一个误解：SVD 不是“把点云拟合到函数”

本篇的**模型**是刚体变换（形式是已知的）：

```
q ≈ R·p + t
```

要拟合的是它的**参数** `R, t`。SVD 只是在解这个优化问题时用的**闭式工具**：

```
min Σ‖R·p + t − q‖²
      ↓ 化简（§2~§3）
max tr(R·H),   H = Σ p̃·q̃ᵀ
      ↓ SVD
H = U·Σ·Vᵀ
      ↓
R = V·diag(1, 1, det(VUᵀ))·Uᵀ
```

**SVD 本身不“拟合”任何东西**，它只是把一个 3×3 矩阵拆开，让最大值一眼可见。
如果模型不是刚体（比如软包装在变形），SVD 也救不了。

顺带：`H` 的奇异值还能判断退化（共线/共面），见 §6。

## 1. 问题定义

给两组**一一对应**的点：

```
源点云  P = {p₁ … pₙ}      目标点云  Q = {q₁ … qₙ}      pᵢ, qᵢ ∈ ℝ³
求：R ∈ SO(3), t ∈ ℝ³，使
      min  Σ ‖R·pᵢ + t − qᵢ‖²
```

这就是 ICP 的"配准步"、手眼标定的内层、拼接点云的核心。
**注意前提**：对应关系是已知的（同一个 `i` 是同一个物理点）。**找对应**是另一件事（最近邻 + RANSAC），不在这里。

**为什么能闭式解**：因为目标函数对 R 是二次型，而且约束只有一个"R 是旋转"——这类问题有解析解，不需要迭代。

---

## 2. 第一步：t 有闭式解

把目标对 t 求导并令 0：

```
∂/∂t Σ‖R pᵢ + t − qᵢ‖² = 2 Σ(R pᵢ + t − qᵢ) = 0
→  n·t = Σ qᵢ − R Σ pᵢ
→  t = q̄ − R·p̄            （q̄、p̄ 是两组点的质心）
```

**几何意义**：最优平移 = "把旋转后的源质心搬到目标质心"。
所以 t 不用优化，它是 R 的函数 —— **问题从 6 维降到 3 维**。

---

## 3. 第二步：去质心，只剩 R

把 `t = q̄ − R p̄` 代回，残差变成**去质心坐标**：

```
R pᵢ + t − qᵢ = R(pᵢ − p̄) − (qᵢ − q̄) = R·p̃ᵢ − q̃ᵢ
```

目标函数展开（`‖Rp̃‖ = ‖p̃‖`，因为旋转不改变长度）：

```
Σ‖R p̃ᵢ − q̃ᵢ‖² = Σ‖p̃ᵢ‖² + Σ‖q̃ᵢ‖² − 2 Σ q̃ᵢᵀ R p̃ᵢ
                = 常数 − 2·tr(R·H)
```

其中

```
H = Σ p̃ᵢ q̃ᵢᵀ            （3×3，行向量写法：H = Pᵀ Q，P、Q 已去质心）
```

> 推导用了一条迹技巧：`Σ q̃ᵀ R p̃ = Σ tr(R p̃ q̃ᵀ) = tr(R Σ p̃ q̃ᵀ)`。

**于是"最小化残差"变成"最大化 tr(R·H)"** —— 常数部分跟 R 无关，直接扔掉。

---

## 4. 第三步：SVD 一步到位

对 H 做奇异值分解：

```
H = U · S · Vᵀ            S = diag(s₁ ≥ s₂ ≥ s₃ ≥ 0)
```

代进去：

```
tr(R·H) = tr(R U S Vᵀ) = tr(Vᵀ R U · S) = Σ sᵢ · Mᵢᵢ,    M = Vᵀ R U
```

`M` 是正交矩阵，对角元满足 `Mᵢᵢ ≤ 1`，所以 `Σ sᵢMᵢᵢ ≤ Σ sᵢ`，**取等号当且仅当 M = I**：

```
M = I  →  Vᵀ R U = I  →  R = V·Uᵀ
```

**完整公式（背下来）**：

```
H = P̃ᵀ Q̃
U, S, Vᵀ = svd(H)
d = sign(det(V·Uᵀ))
R = V · diag(1, 1, d) · Uᵀ
t = q̄ − R·p̄
```

**验证**：`RᵀR = I` ✓，`det R = d² · det(VUᵀ) = +1` ✓（下一节解释为什么需要那个 `d`）。

---

## 5. 为什么必须乘 det 修正（题库 Q1）

`V·Uᵀ` 一定是正交矩阵，但**不一定是旋转** —— 它的 det 可能是 −1。

```
det(V·Uᵀ) = +1  →  是旋转，直接用
det(V·Uᵀ) = −1  →  是**反射**（镜像），必须改成 diag(1,1,−1)
```

**为什么会出 −1**：如果两组点本身是镜像关系（某处 y/z 轴约定反了、点云被翻过），那么"完美拟合"的解就是反射。数学上 `tr(RH)` 的最大值会落在 det = −1 的那一侧。

**实测**（代码在 §7）：

```
数据 Q = P 沿 z 镜像
不加修正：det ≈ −1.0，残差 1.15     ← 拟合更好，但它不是旋转！
加修正：  det = +1.0，残差 6.96     ← 残差变大，但几何上是对的
```

> **这不是"精度问题"，是"解的类型错了"。**
> 残差小但 det = −1 的矩阵，意味着你算出来的是"照镜子"，而机器人只能转、不能镜像 —— 实机上表现为**动作整体反了**。

**所以工程流程永远是**：SVD → 看 `det(VUᵀ)` → 修正 → 再过一遍 `check_rotation`（`1-旋转.md` §1.5）。

## 6. 什么时候解不出来（退化）

看 H 的奇异值 `S = diag(s₁, s₂, s₃)`：

| 点的分布 | rank(H) | 现象 | 不可观的自由度 |
|---|---|---|---|
| 一般（不共面） | 3 | 唯一解 | 无 |
| **共面** | 2 | `s₃ ≈ 0` | 法向的 ± 二义（哪一面朝上） |
| **共线** | 1 | `s₂ ≈ s₃ ≈ 0` | **绕这条线任意旋转都最优** |
| 全部重合 | 0 | H ≈ 0 | 全部（等于没给信息） |

**共线的实测**（10 个点全在 x 轴上）：

```
S = [4.074, 0, 0]
沿 x 轴额外转 0 / 0.3 / 1.0 / 2.5 rad，残差都是 0.0（1e-16）
解出来的 R 与真值差 0.236 rad  ← 它只是选了其中一个合法解
```

> 这就是"残差为 0 但解错"的最干净例子。**残差小 ≠ 解唯一。**

**工程对策**：
- 检查 `s₂/s₁`、`s₃/s₁` 是否小于阈值（如 1e-6）；
- 点云分布要"张开"：至少 3 个不共线点，最好覆盖三个方向；
- 退化时**加约束**（已知重力方向 → 只用 yaw；平面场景 → 2D 配准）；
- 或者多视角/多帧联合，让别的观测把这个自由度钉住。

## 7. 代码

```python
import numpy as np

def kabsch(P, Q):
    """P, Q: (N,3) 一一对应的点，求 R,t 使 R·P + t ≈ Q"""
    p_bar, q_bar = P.mean(0), Q.mean(0)
    H = (P - p_bar).T @ (Q - q_bar)          # 3×3
    U, S, Vt = np.linalg.svd(H)
    V = Vt.T
    d = float(np.sign(np.linalg.det(V @ U.T)))   # det 修正
    R = V @ np.diag([1.0, 1.0, d]) @ U.T
    t = q_bar - R @ p_bar
    return R, t, S, d

def rodrigues(w):                             # 只为造测试数据
    th = np.linalg.norm(w)
    if th < 1e-12:
        return np.eye(3)
    k = w / th
    K = np.array([[0, -k[2], k[1]], [k[2], 0, -k[0]], [-k[1], k[0], 0]])
    return np.eye(3) + np.sin(th) * K + (1 - np.cos(th)) * (K @ K)

# ---------- ① 正常情况：加噪声 ----------
rng = np.random.default_rng(1)
P = rng.normal(size=(30, 3))
R_true = rodrigues(np.array([0.3, -0.5, 1.1]))
t_true = np.array([1.0, -2.0, 0.5])
Q = P @ R_true.T + t_true + rng.normal(0, 0.01, P.shape)

R_est, t_est, S, d = kabsch(P, Q)
print("R 误差", np.abs(R_est - R_true).max())    # 0.0019
print("t 误差", np.abs(t_est - t_true).max())    # 0.0034
print("奇异值", S.round(3))                       # [27.5 23.7 12.1]
print("det 修正 d =", d)                          # 1.0

# ---------- ② 镜像数据：det 修正救场 ----------
Q_mirror = P * np.array([1, 1, -1]) + t_true      # 沿 z 翻一面
R_fix, t_fix, S_m, d_m = kabsch(P, Q_mirror)
print("镜像 d =", d_m, " det =", round(np.linalg.det(R_fix), 6))   # -1.0, +1.0

H = (P - P.mean(0)).T @ (Q_mirror - Q_mirror.mean(0))
U, S2, Vt = np.linalg.svd(H)
R_raw = Vt.T @ U.T                                # 不做修正
print("不修正 det =", round(np.linalg.det(R_raw), 6))             # -1.0
print("修正后残差  ", round(np.linalg.norm(P @ R_fix.T + t_fix - Q_mirror), 3))   # 6.962
print("不修正残差  ", round(np.linalg.norm(P @ R_raw.T + t_fix - Q_mirror), 3))   # 1.146

# ---------- ③ 退化：共线点 ----------
P_line = np.outer(np.linspace(-1, 1, 10), np.array([1.0, 0, 0]))
Q_line = P_line @ R_true.T + t_true
R_l, t_l, S_l, d_l = kabsch(P_line, Q_line)
print("共线奇异值", S_l.round(6))                 # [4.074 0 0]
for th in [0.0, 0.3, 1.0, 2.5]:
    R2 = R_l @ rodrigues(np.array([th, 0, 0]))
    print(f"  绕 x 多转 {th}: 残差 {np.linalg.norm(P_line @ R2.T + t_l - Q_line):.2e}")
```

**真实输出**（`py -3`）：

```
R 误差 0.001901870872726974
t 误差 0.0033769621511415826
奇异值 [27.496 23.68  12.143]
det 修正 d = 1.0
镜像 d = -1.0  det = 1.0
不修正 det = -1.0
修正后残差   6.962
不修正残差   1.146
共线奇异值 [4.074074 0.       0.      ]
  绕 x 多转 0.0: 残差 8.38e-16
  绕 x 多转 0.3: 残差 8.38e-16
  绕 x 多转 1.0: 残差 8.38e-16
  绕 x 多转 2.5: 残差 8.38e-16
```

**读法**：
- ① 噪声 0.01、30 个点 → R 误差 2e-3，符合"误差 ∝ 噪声/点云尺度"的直觉；
- ② 镜像数据下，不修正的残差**更小**（1.15 < 6.96）但 det = −1 —— 这就是 Q1 的坑；
- ③ 共线时任何绕轴旋转残差都相同 → 1 个自由度彻底不可观。

## 8. 和 ICP / Umeyama 的关系

| 场景 | 方法 | 差别 |
|---|---|---|
| 对应点已知、无尺度 | **Kabsch（本篇）** | 闭式解，一步 |
| 对应点未知 | **ICP** | 交替"找最近点 → Kabsch"，迭代到收敛 |
| 需要估尺度（单目/SfM） | **Umeyama** | 多一个 `c = tr(D·S)/σ_p²`，`t = q̄ − c·R·p̄` |
| 有离群匹配 | RANSAC + Kabsch | 随机采样 3 点 → 求解 → 数内点 |

**Umeyama 一句话**：R 的求法完全一样，尺度 `c` 是"沿主轴投影的比值"，t 也跟着乘 c。
（细节见 Umeyama 1991 原论文；工程里 `cv2.estimateAffine3D` / Open3D 的 `TransformationEstimationPointToPoint` 都是它的变体。）

## 9. 坑清单

| # | 坑 | 后果 | 解法 |
|---|---|---|---|
| 1 | 忘了 det 修正 | 得到镜像，实机动作反 | `diag(1,1,det(VUᵀ))` + `check_rotation` |
| 2 | 对应关系错 | 解出来乱七八糟，残差还"看起来"可以 | RANSAC / 匈牙利匹配 / 先验索引 |
| 3 | 没去质心 | t 完全错 | 先算质心，再 `t = q̄ − Rp̄` |
| 4 | 点云共线/共面 | 某方向不可观，残差 0 但解错 | 查奇异值比 + 加约束 |
| 5 | 单位/手性不一致 | 结果整体镜像或放大 | 统一单位；`det` 检查 |
| 6 | 用 float32 累加 | 大坐标下精度掉光 | 去质心 + float64 |

## 10. 自测（对应题库 Q1）

1. **Q1**：为什么两个点云的刚体变换能用 SVD 求？不乘 det 修正项会出什么？
2. 为什么 `t` 可以一步写出来，不用优化？
3. `H` 的奇异值 `[4.07, 0, 0]` 说明什么？此时有几组解？
4. 残差 1.15 的解和残差 6.96 的解，你选哪个？为什么？

## 11. 参考答案

**1.** 因为目标函数展开后是 `常数 − 2·tr(R·H)`，最大化 `tr(RH)` 的问题在对 H 做 SVD 后有闭式解 `R = V·diag(1,1,det(VUᵀ))·Uᵀ`。不修正时，若数据是镜像关系，SVD 会给出 det = −1 的**反射矩阵**：残差更小，但它不是旋转，实机上等于"动作镜像"。

**2.** 目标对 t 是二次函数，`∂E/∂t = 0` 直接给出 `t = q̄ − R·p̄`（N 个方程相加后 t 的系数是 N）。t 始终等于"把旋转后的源质心搬到目标质心"。

**3.** 点全部共线（rank 1）→ `s₂ = s₃ = 0`。此时**绕这条线转任意角度都是最优解**，解集是一个连续的 1 参数族（不是唯一解），需要额外约束才能定下来。

**4.** 选 det = +1 的那个（残差 6.96）。因为残差 1.15 的解 det = −1，是反射，物理上不可实现 —— 除非你确认数据被镜像了，那就该去修数据源，而不是接受反射。
